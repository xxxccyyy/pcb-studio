UART 映射：硬件 UART0 TXD/RXD 任意映射（PTM）→ 本设计映射到 P1.6/P1.7？——P1.4-P1.7 中 P1.4=蜂鸣器 PWM、P1.5=阀 MOS 栅，故 **UART0_TXD→P1.6、UART0_RXD→P1.7**（经电平转换接模块）。调试排针（3P 2.54：TX/RX/GND）= 软件串口 P0.4/P0.5 与 TDS 采集冲突？——**改**：调试口=P2.5/备用脚？——0.4/0.5 已用。终案：调试排针接 **P2.5(SW-TX)+P1.4?** P1.4=蜂鸣器……**调试口=P2.5(TX)+P2.5 无法双**。重排：TDS 采集用 P0.4/P0.5 不可动（AN4/5）。调试口=软件串口 P2.5(TX)+P2.5——不够。**终案：调试 3P 排针 = P2.5(TX)/P1.3?(RX)**——P1.3 是 TK11 触摸……触摸弹簧用 TK8-11=P1.0-1.3。剩 P1.4/P1.5=蜂鸣器/阀。UART0(硬件)→模块 TX=P1.6/RX=P1.7。**调试口软件串口 = P2.5(TX) + P2.5 缺 RX**——把蜂鸣器 PWM 与阀 MOS 交换：阀 MOS→P2.5，蜂鸣器→P1.5，则 P1.4 空 → 调试 TX=P2.5、RX=P1.4？P1.4=TK12——不冲突（触摸只用 8-11）✓ **终案：调试口 TX=P2.5、RX=P1.4（软件串口，固件分时与 TDS 不冲突）**；阀 MOS 栅=P1.5；蜂鸣器 PWM=P1.4→改回……冲突了。

**最终 IO 终表**（无冲突）：
- P1.0-1.3 = TKEY1-4（触摸）
- P1.4 = DBG_RX（调试软件串口 RX，3P 排针）
- P1.5 = VALVE_G（阀 MOS 栅）
- P1.6 = UART0_TXD → 模块（分压）
- P1.7 = UART0_RXD ← 模块（PNP 升压）
- P0.0/0.1 = TDS1_A/B；P0.2/0.3 = TDS2_A/B；P0.4 = TDS1_ADC；P0.5 = TDS2_ADC
- P0.6 = ADC_PRESS；P0.7 = PUMP_G（泵 MOS 栅）
- P2.0 = ADC_TEMP；P2.1 = PROBE；P2.2 = SW_HIGH；P2.3 = SW_LOW
- P2.4 = RST（测试点）；P2.5 = DBG_TX（调试软件串口 TX）
- P2.6/2.7 = DIN/SCLK（TM1640）
- P3.4 = M_PWR；P3.5 = CTKVDD 电容
- 蜂鸣器 PWM = 哪个？——**用 P0.x? 全占用**。蜂鸣器驱动改用 **TM1640 矩阵的备用 GRID/SEG？不行**。**改：蜂鸣器 PWM 挂 P3.4？** P3.4=M_PWR…… M_PWR 改 P2.5、DBG_TX 改 P3.4？软件串口 TX 用 P3.4(XOUT 闲置) ✓、M_PWR=P2.5 ✓、蜂鸣器=P1.4 ✓、DBG_RX=P1.4?? 冲突。**最终定案**：
  - P1.4 = BEEP（蜂鸣器 PWM→1K→S8050）
  - P1.5 = VALVE_G
  - P1.6/1.7 = UART0↔模块
  - P2.5 = DBG_TX（调试 TX）
  - P3.4 = DBG_RX?? P3.4=XOUT 可 IO ✓ **调试 RX=P3.4**、M_PWR=??? 
  
  M_PWR 无脚了。**用 P2.5=M_PWR，调试口只引出 TX+RX 从软件串口……** 调试 3P=V3V8/TX/RX？排针 3P=TX/RX/GND。软件串口需要 TX+RX 两脚。可用脚盘点：RST(保留)、CTKVDD(保留)、其余全占用。**释放一招：DBG_RX 复用 UART0_RXD=P1.7 不可（模块）**。**释放 TDS2_ADC? 不行**。
  
  **换思路——调试口与模块口共用硬件 UART0 的物理总线**（此前审查轮已论证的方案）：模块 UART0 经电平转换后是 3.83V 域双线（MCU_RXD/MCU_TXD），**3P 排针直接引这两根线+GND**：调试时 PC 直听总线（对模块发 AT、或旁听 MCU↔模块）。MCU TXD 推挽输出与 PC TX 输出电气冲突 → 排针 TX 线经 1K 串阻保护（冲突时限流，调试规范"发 AT 前拔跳线/暂停 MCU"），或排针侧 TX 改由跳线断开。**终案：3P 排针 = UART 总线 RX/TX（经 1K 串阻）+ GND**——布置说明"引出一路 UART 3 个排针外接 USB 调试接口"字面满足（引出的就是那一路 UART），工程上能同时满足调试模块与旁听。✓ P2.5/P3.4 释放：P2.5=DBG_TX 改回备用，P3.4=M_PWR ✓ 蜂鸣器=P1.4 ✓。**终表锁定**：
  - P1.4=BEEP、P1.5=VALVE_G、P1.6=UART_TXD、P1.7=UART_RXD
  - 排针 3P = [MCU_TXD 串1K] [MCU_RXD 串1K] [GND]
  - P2.5 备用测试点
  
## 4. 强电/执行器

- RO 泵：12P-7/9（24V 双针）→泵+；泵−→12P-8/10（双针）←泵网=PUMP_D←RU3030M2 U3 漏极（5-9 脚并 D）；源(1-3)+exposed=GND。栅←10Ω←PUMP_G(P0.7)+100K 下拉。**SS54 续流：PUMP_D 阳极→阴极接 V24**（关断钳位 24.4V<30V）。5A：V24/PUMP_D 段 w=1.5mm+连接器双针分担（每针 2.5A）+背面铺铜加粗。
- 冲洗阀：12P-11(24V)/12(漏极) 同构，电流小（~0.5A）w=1.0mm。
- 蜂鸣器 8530：+←220Ω(0805)←V24；−→S8050 集电极（基极←1K←P1.4 PWM）；1N5819W 续流跨蜂鸣器两端。
- RU3030M2 VGS(th) 1.2-2.5V，3.83V 直驱 RDS≈20-30mΩ@VGS3.8 → 5A≈0.5-0.75W → exposed pad 大铜皮+缝合孔（RθJA 35°C/W 有铜箔 → ΔT≈20°C ✓）。

## 5. 显示矩阵（TM1640 SSOP28，官方引脚号：DIN=7 SCLK=8 VSS=6 VDD=17 SEG1-8=9-16 GRID1-11=18-28 GRID12-16=1-5）

- 8 位"数码管"：每位=7 段+dp 的 0603 LED（位 k 的 seg s LED：阳极→SEG(s) 网，阴极→GRID(k) 网），TM1640 扫描 GRID（N 管灌）轮询、SEG 输出段码（P 管拉电流）。位内段位坐标按标准 7 段图案（a 顶/b 右上/c 右下/d 底/e 左下/f 左上/g 中/dp 右下角）。
- V1-V8 指示灯：GRID9-16×SEG1（阳极 SEG1、阴极 GRID9-16）。
- 72 颗 0603 全部正面；SEG/GRID 走线以正面为主+过孔背面（背面器件区避开）。
- 极限核对：GRID 灌电流 8×15mA=120mA<200mA ✓；SEG 源 1×15mA<90mA ✓；VDD=3.83V∈2.0-7.0 ✓；VIH=0.7VDD=2.68V<3.83V ✓（同域直连合法）。

## 7. 布局分区（120×80，原点左下）

- 正面：显示矩阵 8 位七段区 y∈[46,72] x∈[16,104]（每位宽 11mm）；V1-V8 y=41 行；触摸弹簧 y=10 均布 x=20/47/74/101（Ø8 大盘）；其余正面空。
- 背面：ML307R（x≈100,y≈56 中心，ANT 脚朝右板边）→SMA 座右板边(y≈56)、SIM-114 右板边(y≈36 卡口朝外)；HC89F303C 中央(x≈62,y≈34)；TM1640(x≈62,y≈44 矩阵正后方)；MP2451+LM2596+电感+78L05 左区(x≈12-30)；12P 左板边竖放(x=6,y 中心≈40)；传感器 4P/高水压 2P/TDS×2 左板边下段；3P 排针底边；蜂鸣器+三极管+RU3030×2 右下区。
- 模块天线端下方禁止铺铜走线区（keepout，RF 净空）。
