## 二、L39 零格焊盘（本轮核心，十轮最难缠残留的真根因）

- **机制**：元件中心量化到 0.6 格**界**，焊盘偏移固定（SOIC 1.27 节距）——旋转后 0.5mm 短边
  横向时，焊盘 x 区间 [c−0.25, c+0.25] 可能不含任何格心（格心在 0.3 奇数倍线上）→
  `padCells` 为空 → RMST/Prim 的源格集合为空 → **焊盘对本网完全不可达**，协商器无能为力。
- **伪装史**：同一 bug 在不同板上呈现为不同"残留"——R6 n59「影响区墙 1 格 slalom」（L17）、
  R6 n67「电源 highway 物理限制」（L18）、R10 期间的多板小残留。四轮间种子/轮数/锚定/
  maxIter 全部实验均无效，因为**放置量化每次都复现同样的零格集合**。
- **修复**：autoPlace 写回阶段，薄于栅格的轴向若中心相位距最近格心线 > 半宽 → 半格微移
  （≤grid/2，制造上无差异）落到格心线。锚定薄焊盘由 spec 门拦截（零格覆盖 problem）。
- **效果**：n59 **41/47 → 47/47**（15.1s，较失败轮还快——不再浪费协商）；n67 **52/66 → 66/66**；
  薄焊盘重灾板复测（n110/n143/n145/n151）零回退；259 项回归全过。

## 三、方法复盘："先验证再优化"的三次兑现

1. **L18 证伪**：直接跑铺铜几何（inPour 逐焊盘）——5 分钟推翻两条轮次积累的错误归因。
   若直接实现契约变更，会永久性地把"铺铜未覆盖的真开路"报成"已连接"——**假绿**。
2. **L17 松弛实验**：旗标化（默认关=零行为变化）+ 插桩——实验无效本身成为证据
   （跨墙路径从未提交 → 阻断不在影响区）→ 顺藤摸瓜到 src.length===0 → padCells。
3. **A* 优化**（上轮）：走线几何逐位一致才允许落地。

**通用规则**：性能/正确性优化的前提是根因的**几何级证据**（padCells/inPour/格点占有图/剖析采样），
"跑了某补救无改善"只证明该补救无效，不证明预想根因成立——本轮 L17/L18 双双因此翻案。
