# 深度优化报告——0.14.9 障碍感知启发式（2026-11-16b）

> 定位：0.14.8 报告 §5 留档方向①的执行轮。结论先行：**机制成立、速度 2.2-2.5×、
> 协商不动点在截断态硬板变差 → 以 opt-in（`obstacleH` / CLI `--obstacle-h`）交付，
> 默认关闭（与 0.14.8 位级一致）**。本轮同时给出该权衡的机制解释与完整实测表。

## 1. 设计

0.14.8 剖析确认 `fillDistanceMap`（目标距离场）与 astar 调用 1:1、占 12-14%，且旧
h "无视障碍"在拥塞板严重低估（iCEBreaker 每次 A* 平均展开 4600 格 ≈ 全板 19%）。
本轮把 h 升级为**障碍感知**：

- `computeH(goalSet, net, hard)` 每次调用构建本网"无条件可通行"掩码 `passMask`
  （会话级 Uint8Array 复用，TS≤8M 启用，判定链与 `passable`/`enterOK` 逐字段同源：
  prefL → blocked → scoped(cls) → fixedOwner → padOwner → viaInf → pairBand →
  hard-usage），`fillDistanceMap` 只松弛掩码内格。
- **可采纳性**：可用路径集收缩 → h 仍 ≤ 真实代价；**支配性**：新 h 逐点 ≥ 旧盲 h。
  【0.14.9 深检修正】一致性当时声称成立，深检推翻——掩码场在"跨层掩码不对称"处
  非一致（探针 40 板 43240 处、最大超出 76.5 格；盲场 0），first-pop 终止下
  obstacleH 模式可能接受轻度次优路径 = 硬板质量偏移的第二机制候选。详见
  docs/深度检查报告-0.14.9.md；"展开集不增"的经典结论以一致为前提，本场为
  经验性成立（实测 2.2-2.5×）。
- 排除项（有意不 gate，保持可采纳）：viaLegal（换层可用性被高估→h 更小）、软阶段
  usage（可借道付罚）、hist/nearPen/presFac（软代价）。不可通行种子只置 0 不向外
  松弛——进入该格本就非法，跳过仍可采纳且更紧（墙围死源即时判失败，等价于旧口径
  穷举失败后的 null）。
- astar 入口 `gen++`/ownStamp 戳位前移到 computeH 之前（掩码 hard-usage 判定需要
  本网成员戳；gen 只被四个戳数组消费、computeH 只写 hMap，先后交换无交互）。

## 3. 机制解释（留档为下一算法轮的假设）

盲 h 的高原探索有一个**副作用红利**：不同网在等代价 Plateau 上按插入序选择**不同**
的等代价路径——协商阶段天然获得路径多样性。障碍感知 h 把每网的 h 场变得相同且
陡峭，等代价路径选择**趋同**进同一条地理最短走廊（"漏斗"效应）——单网看每条边
仍最优，全网看冲突集中，协商拆-重布反复回到同一漏斗，收敛到更差的不动点。
这与 PathFinder/Freerouting 实践一致（协商路由里路径多样性 > 单路径最优；tie
保持松散是特性不是缺陷）。h2-stm32 的 DRC 改善（−14）与硬板连通退化并存也与此
自洽：走廊引导让可行走廊内的板更干净，让"必须分散"的板更拥挤。

## 4. 交付决策：opt-in

- **默认关**：`obstacleH` 未传 = 0.14.8 位级一致。证据：400 组随机板×配置差分
  （冻结 0.14.8 参考）全流程逐态一致 0 失败；search-regression SHA-256 金标准
  **无需重录**继续通过；全量 npm test exit 0（80 核心 + 285 node:test + 48 书籍 +
  17 CLI + 39 模糊 + 7 深检 + 48 优化锁）。
- **`--obstacle-h` opt-in**（route/autopcb，CLI 白名单 + 引擎 opts 透传含两条并行
  路径）：适用场景——速度敏感的迭代流（2.2-2.5×）、以 DRC 为先的板（h2 型）；
  不适用——协商未收敛的截断态硬板（fable/icebreaker 型连通回退）。
- 期间发现并修正一个潜伏测试假设：joint-reroute 的 Fable 存档测试断言"连通不得
  回退"，强于 0.14.1 起文档化的接受准则"字典序 [−drcE, conn]（DRC 优先）"——
  obstacleH:on 下首次出现"修 2 DRC / 少连 2 网"的权衡按契约被接受。默认路径恢复
  位级一致后该测试回归通过（测试未改，留档该发现）。

## 5. 永久锁（优化验证 44→48）

- 45a 可解板质量中性：obstacleH 开/关连通一致 + DRC 0（1/2/4 层 × 斜向开合）
- 45b 障碍剪枝正确性：环形禁布区围死源开/关均如实失败（掩码无幻路径），可达网布通
- 45c 掩码复用无残留：obstacleH:on 双跑逐字一致
- 45d `--obstacle-h` 旗标注册（route/autopcb 接受、place 拦截）

## 6. 边界与不夸大

- 单机单跑实测非统计显著性结论；"漏斗/多样性"是当前证据下最自洽的机制假设，
  不是被证明的定理——下一算法轮可按此设计"带多样性保持的感知 h"（如逐网 h 偏置、
  候选走廊多样性机制）再做 A/B。
- obstacleH:on 未跑浏览器链路（GUI 未暴露该开关，worker opts 透传已由 45d/全量
  回归覆盖解析与引擎两层）。
- 默认路径本轮新增改动仅 gen++/戳位前移（computeH 只写 hMap，无交互）+ computeH
  签名扩展，位级差分 400 组背书。
