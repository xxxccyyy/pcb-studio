# 第六轮实测报告：4 档 × 5 项目（N53–N72）

> 日期：2026-11-08 · 引擎：第五轮修复版 + 本轮 3 项引擎级修复
> 测试规格：20 个全新设计维度，与前五轮无重叠；**教训先实验验证再记录**

## 〇、一句话结论

20 项目中 **15 全绿**（100% 布通 + DRC 0 错），4 个残留均有定位。本轮落地 **3 项引擎级修复**（逃逸口袋罚、孔边距三处口径统一、美化精确距离），均经 A/B 对照 + 255 项回归验证。新增能力边界事实：**0.4mm QFN-56 首次全连通**、**LQFP144+底层贴装 134 焊盘 31 分钟全绿**（第五轮同规模板 2.1 小时仍残留 7 错）、以太网 PHY 载板（QFN+MagJack 双差分）交付级全绿、**BGA-64 电气连通 100% 但 DRC 未收敛（边界如实记录）**。

## 二、已验证教训（先实验验证再记录）

### L12 逃逸口袋：退火罚金盲区 → 已修复（本轮最重要）

- **现象**（n54）：4 通道对称触摸板恒定 1 通道 2 焊盘未连通，28/30。跨 5 种子、2/4/6 轮、连接器锚定**逐位复现**，纯参数不可救。
- **定位**（diag-seal.mjs 格点占有图）：U4-2（TO-92 中脚）上下左右 4 个正交方向全部被外网影响区/禁行区覆盖，只余 2 格口袋；R4-1 同样。**布局"合法"（无重叠/不出板/间距够）但几何上不可达**——布线器如实报 unreachable。退火罚金只感知合法性，对"可逃逸性已死"零感知。
- **修复**（engine.mjs autoPlace cost）：焊盘 4 个正交方向全被堵（边距 < halfClr + 2·grid，与布线器影响区严格同口径；板边同判；斜向不算——布线器斜移需两个正交格空闲）→ 罚 300000/焊盘。在现有 O(pairs) 循环内顺带计算，零额外复杂度等级。
- **A/B**：n54 28/30 → **30/30 complete / DRC 0 / 20.5s → 2.9s（快 7 倍）**。254 项回归全过。
- **泛化**：布局优化器罚"重叠/出板"只保证合法，还须罚"不可逃逸"；可达性判据必须与布线器模型同口径（halfClr + 栅格），否则又是三处口径分裂。

### L13 孔边距三处口径不一致（L7 家族第 4 例）→ 已修复

- **现象**（n66）：布线器把过孔放在 THT 焊盘孔边 0.00mm 处，DRC「孔边距」判违规。布线合法 ≠ DRC 干净。
- **根因**：DRC 孔边距检查**同网不豁免**（制造正确性口径——钻孔可能切伤相邻孔铜壁），但布线器 viaLegal 只查异网影响区；planStitching 避让清单排除同网焊盘；autoReturnVias 同网孔也无孔边距检查——三处过孔放置逻辑全部漏同网孔距。
- **修复**（engine.mjs）：buildModel 预计算 `viaHoleBlocked`（孔心距 < holeR + viaDrill/2 + 0.2 的格，恰界允许），viaLegal 直接查表；planStitching / autoReturnVias 补同网 THT 孔边距判断。
- **A/B**：n66 1 DRC 错 → **0 错**（26.8s → 11.3s）。回归全过。
- **泛化**：同一条物理规则的判断点（布线器/DRC/缝合孔规划）必须逐处核对口径——这是 H1/L7 家族第四次以不同面目出现（罚金归零、恰界误报、判距容差、同网豁免）。

### L14 细间距降 clearance 前先算实际铜边间隙（n64 / n68 双向 A/B）

- **现象**：spec 盲目选 clearance 0.08 → DFM「间距 0.08 低于极限 0.1」。
- **实验 A（n64，0.95mm 节距 SOT-23-6/焊盘 0.55）**：实际相邻铜边间隙 = (0.95−0.55)/2 = 0.20mm，halfClr(0.1+0.15) = 0.175 < 0.20 **0.1 就够**。A/B：0.08 → 0.1 DFM 错清零，仍 100% 布通（3.5s）。
- **实验 B（n68，0.4mm QFN-56）——反向验证**：clearance 0.05 → 0.1 全面变差：341s → **2333s（6.8×）**、via 24 → 58、complete → partial 且新增 1 处走线-焊盘间距错。halfClr 0.10 → 0.15 封死更多侧向走廊 → 强制换层（via 暴涨）→ 协商更慢且过孔场自带间距违规。
- **结论**：细间距下「放宽 clearance 更安全」的直觉是错的——halfClr 耦合占主导。0.4mm QFN 双层的实际工作点就是 clearance 0.05（低于嘉立创 0.1 极限 = **工艺边界之外**，可制造需 4 层 + 多层 0.09 极限）；0.95mm 级别 0.1 足够。**降/升参数都用 `边间隙 = (pitch − padW)/2` 实算，别按感觉。**

### L15 工具收紧后旧 spec 会暴露（n54 环宽族）

- **现象**：to92 助手封装（pad 1.1 / hole 0.7 / pitch 1.27）第五轮 DRC 0 错；本轮现行 DRC 报 8 错（铜边间隙 0.17 < 0.2）。
- **归因**：焊盘铜边间距检查是第五轮之后加强的（docs/pcb-design-quality.md）——旧 spec 通过 ≠ 几何正确。
- **修复**：孔径-环宽-间隙三联动解：1.27 间距下 **hole 0.6 / pad 1.0**（环宽 (1.0−0.6)/2 = 0.2 ✓ 间隙 0.27 ✓）。
- **泛化**：THT 封装三约束必须联立解 `pad ≥ hole_d + 0.36`（环宽）、`pad ≤ pitch − clearance`（间隙）→ `hole_d ≤ pitch − clearance − 0.36`。封装助手应内置该校验。

### L16 锚定不是万能药（n59/n69 双反例）

- **实验**（n59，5 变体 A/B）：不锚 41/47；J1/J2/J3 贴右缘横放锚定 32/47（修正出板后 40/47）；竖放锚定 35/47；maxIter 300 → 41/47 不变。**每种锚定都更差或持平**——网被拉长、平行扇入变难。
- **实验**（n69）：锚定功率级 6 DPAK + 端子 → 51/59 不变。
- **修正第五轮认知**：「连接器一律板边」在退火已经给出合理布局时可能有害（n59 退火布局比人工锚定好）。**锚定先看退火布局的诊断再决定；spec 布局没有明确优势时不要锚。**

### L17 协商器能力边界：影响区墙 + 1 格 slalom（n59 残留，未修）【第十轮修正：真因是 L39 零格焊盘，见下】

- **定位**：THT 排针影响区覆盖节距的 99%（r0.85 + halfClr0.4 vs pitch 2.54）→ 连接器排是**连续影响区墙**；退火又把 SOIC-24 行与之共线对峙（错位 0.2mm）→ 失败网的唯一逃逸是墙上方 1 格高的绕障 slalom。overuse=0（无冲突可协商）+ 几何路径存在但被影响区封死 → 协商无从发力。
- **已排除**：种子 ×5、轮数 2/4/6、maxIter 300、三种锚定——41/47 为当前引擎最优。
- **Roadmap**：失败网 A* 无解时，对"墙区"做定向松弛（临时允许跨已布线网影响区并计入协商代价），而不是标记 unreachable 后放弃。
- **诊断工具沉淀**：`diag-seal.mjs`（焊盘周边 5×5 格点占有图）一次定位此类问题——值得固化为 `ai/pcb.mjs` 诊断子命令。

### L18 电源 highway 的铺铜契约缺口（n67，未修）【第十轮修正：几何复核证伪，见下】

- **现象**：USB Hub 5 连接器 15 个 GND 焊盘，route 后 3 个未连通；铺铜+缝合孔后 DRC 仍报未连通。
- **根因**：连通性契约只认走线（result.nets[].connected），铺铜热焊盘连接不计入——电气上已连接，账面上未连接。
- **处置**：如实记录为契约缺口（改进候选：DRC 对「焊盘在铺铜区内且热焊盘开窗」的焊盘豁免未连通），本轮不动契约。**操作规程**：GND 大网的焊盘连通别依赖铺铜兜底，route 阶段就要连通主干。

### L19 功率拓扑难度：DPAK tab 场（n69 残留）

- 三相半桥 6× DPAK（tab 6.6mm 宽）+ 采样电阻场：51/59，失败集中在门极网（GL1/GL3）与采样网（SW/AMPU/SIG）——**大铜 tab 之间的走廊拥塞**（非口袋：焊盘局部自由，通道被 tab 场吃掉）。锚定无改善（L16）。
- **经验**：功率板的难度单位是"tab 宽度 vs 通道数量"；spec 级解法是把功率级一字排开、门极走线从 IC 侧直进（本 spec 已如此，但退火打乱了相对方位——锚定又无效，需「元件组锚定」能力，记 roadmap）。

### L20 新能力边界事实（正收益）

- **0.4mm QFN-56 打通（带工艺边界声明）**：n68 RP2040 94/94 全连通（341s / 24 via / grid 0.2 / 线 0.1 / 距 0.05 / 孔 0.45·0.2）——低于第五轮 L1 对照表最细档（0.5mm）。但 clearance 0.05 低于嘉立创 0.1 间距极限（DFM 如实报错），放宽到 0.1 则 6.8× 时长且不收敛（L14 实验 B）——**算法可布通 ≠ 可制造，0.4mm 双层在工艺边界外**。
- **以太网 PHY 载板交付级**：n70 QFN-32 + MagJack 双差分 + RMII 65/65 / DRC 0（1026s）——差分 pair 标签 + 三参数联动正确时，混合信号载板可直接交付。
- **隔离带禁布生效**：n65 横穿板中央的 2mm 隔离带（keepouts）下 64 焊盘 100% 布通——隔离拓扑可全自动化。

### L21 美化通道的采样检查不可靠 → 已修复（n72 抓出）

- 弦拉直/45° 切角的间距审查用**固定点/步进采样**近似线段-障碍物距离。擦边接触的凹陷区可以比采样间距短任意多——**采样永远不能兜底几何判断**。n72 实测：产线段距焊盘 0.1722mm（要求 0.175），5 个采样点全部合法。
- **修复**：chamferOK / segClearOK 的焊盘/禁布区/过孔检查全部改精确闭式解（segmentRectDistance / segDist）。走线-走线原本就是精确 segSegDist，未受影响。
- **A/B**：n72 1899s/1 错 → 631s/0 错（同种子轨迹）；254 项回归全过；机制锁测试 15 固化。
- **泛化**：几何审查里「采样点检查」只能用于快速预筛，**最终判断必须是闭式解**——这是 H1/L7/L21 一脉的第四课（罚金归零、恰界误报、判距容差、采样漏检），全部是「近似判断当精确判断用」的变体。

## 五、超难档长任务（n71 BGA / n72 LQFP144）

### n71 BGA-64 CPLD 载板（旧引擎首轮：5845s）

- **结果**：98/98 焊盘**全部连通**，但协商**未收敛**——overuse 48、DRC 88 错（间距冲突 48 / 走线间距 40 / 孔边距 2）。
- **定性**：N10/N28/N30「连通可到 100% 但 DRC 不干净」家族的 BGA 版本，且更严重。BGA 内圈球只能从 4 球对角通道逃逸，**通道数 < 内圈球数 = 结构性拥塞**——协商式撕线重布在通道饥饿下每轮只是换一批球占通道，压不到零。
- **孔边距 2 错**：旧引擎口径缺口（L13）所致。
- **新引擎重跑（5591s）**：98/98 连通不变，**孔边距错清零**（口径修复生效）、DRC 88→52、overuse 48→32、via 81→74——但 32 处间距冲突残留，**结构性未收敛确认**（两引擎一致）。
- **BGA 双层结论**：本工具可做到**电气连通 100%**，做不到 DRC 干净——通道饥饿是物理约束（内圈球逃逸通道数 < 球数），非 bug。交付需 4 层或 BGA 专用 escape room 定向扇出（Freerouting expansion rooms 思路，路线图既有项）。作为「学习/工具级布线器」的能力边界如实记录。

### n72 LQFP144 + 底层贴装（188p/24n，grid 0.25，135k 格点）

- **首轮（新引擎，并行进程）**：134/134 **全部连通**、1899s、via 117——但 DRC 1 错（走线距焊盘 C4-1 过近 0.1722mm < 0.175）。
- **根因（本轮第 3 项引擎修复的来源）**：违规段是 45° 美化/弦拉直产出的**离栅格点**——chamferOK 固定 5 点采样、segClearOK 步进采样（每 0.125mm）对「擦边接触」漏检：距离剖面在两采样点之间凹陷 0.0028mm，采样永远不可靠。
- **修复**：两类检查的焊盘/禁布区/过孔判定全部改**精确线段距离**（segmentRectDistance / segDist 闭式解）。
- **修复后 A/B**：**complete 134/134 / DRC 0 / overuse 0 / 631.5s / via 88**——同种子轨迹下时长 1/3、过孔 -25%（修复后弦拉直几何更干净，后续轮次收敛更快）。
- **附带发现**：底层贴装 SMD（3 颗 bottom 0402/0603）全流程正常——布线/DRC/导出的层语义正确。
- **性能对比**：本板（134 可布焊盘）631s 全绿 vs 第五轮 n52（166 焊盘 LQFP100+TSOP44）7703s 残留 7 错——逃逸口袋罚 + 口径统一两项修复在超大板上的复合收益显著。
