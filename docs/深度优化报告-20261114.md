# 深度优化报告（2026-11-14）—— 热点侦察驱动的位级一致优化轮

> 方法论延续 0.6.x / 2026-11-12 轮：**先侦察后动手、全部位级一致改造、11 案例差分对拍逐字节守门、全量回归收口**。
> 本轮起点是 0.14.1/0.14.2 门图立项关闭后的空档：三路并行侦察（历史报告遗留项 / 引擎残留热点 / 质量侧边界）
> 产出 26 处未优化热点清单（带 file:line 与位级风险评估），本轮落地第一梯队 12 处 + 第二梯队 2 处。

## 1. 侦察与对拍基建

- **侦察**（3 个并行探索代理，报告要点收敛于本轮改动与留档）：
  ① 7 份历史优化/检查报告的遗留项提取（已证伪方向清单防重踩：L18/L17/启发式图缓存/F2 冻结/cell 放粗/morph 字并行）；
  ② engine.mjs 全函数审读（区分已优化区与未动区，产出 B1~B5/C1~C9 热点清单）；
  ③ 质量侧边界（门图决策定案，本轮不做质量试验）。
- **对拍架**：`.scratch/diff-perf-20261114.mjs`——11 案例（3 内置示例 routeBoard 全链、m1-p01 4 层量产板、
  fable-03 栅格全链/形状补线/铺铜/铜皮探针/DRC 全口径、place-555、apr-emcu 布局布线循环），
  产出 JSON `sha256` 前后比对即位级守门；剔除墙钟字段 `timeMs`（buildResult/routeBoard/shape/apr 四处写入）。
  基线 hash 两轮独立采集完全一致——引擎确定性核实。
- **微基准**：`tests/bench-hotloop.mjs`（新增，不入测试套件）——optimize 热循环（3 示例+拥塞压力板）、
  密板 checkDRC(dfm)、fable-03 形状管线、emcu autoPlace、computePour+pourContains 探针，5/7 样本中位。

## 4. 位级一致验证与差分架的实证价值

- **11 案例 × sha256 全一致**贯穿全程：第一梯队（t1）、T2-8（t28）、T2-9（t29）三次独立对拍全部逐字节一致。
- 差分架两次抓出**真 bug**（未流入交付）：
  1. **pour slab yhi 水平边漏检**：恰在 yhi 的水平边 `floor(rows)` 双侧越界，clamp 只夹了 r1 侧——
     r0>r1 该边被分配进 0 个 bin，pourNear 漏报（fable-03 板顶 8/2000 探针不一致，修复后 0/2000）。
  2. **pairCoupleStats 端点序假设**：bbox 快筛初版假设 `os.ax≤os.bx`，右到左的段轴距算反被误跳过——
     pair-compact 两测试失败当场定位（修法：oSegs 构建时预计算 min/max bbox）。
- 全量回归：`npm test` EXIT=0（80 核心 + 242 node:test + 48 书籍 + 17 CLI + 39 模糊 + 7 深度校验 + 22 优化锁定）；search-baseline 位级守门随套件通过。

## 5. 未做留档（收益/风险比不足或不可测）

1. **超小板 checkGeoSpacing 排序开销**：e555 级（S≈50 段）排序+分配反超紧双循环 ~3.7ms。
   可加 N<256 走原循环的门槛（两路输出位级一致，门槛安全）；本轮为控复杂度未加，密板收益远超小板付出。
2. **B1-3 A* 过孔环缓存**：推演收益仅 2×/过孔格（环检查结果依赖 (cur,ns) 层对，每对只在扩展时算一次，
   正反向重复），且需 L² 键空间内存——留档。
3. **B4-5 shpBuildGraph 轴区间二分**：边界语义微妙（ε 偏移的严格不等式），killEdges 内 gap 计算才是主导——留档。
4. **T2-8 收益的适用面**：fable-03 TS≈3.5 万格全量重建本就 ~ms 级，补丁收益在 n130 BTB（TS≈百万级，
   500 网×30 轮）类板上才能兑现——本轮基准板未覆盖该档位，如实注明。
5. **T2-10 snapshot/restore diff 化**：收益集中在 jointReroute 2^n mask 枚举与 optimize 拒绝路径；
   本轮对拍板面上 jointReroute 多为 no-op 门直接跳过，收益不可测——留档。
6. **T2-11 scanOveruse 增量化**：T1-1 落地后 optimize 热循环已 -13~-24%，usage 全扫 O(TS) 占比进一步缩小——不立项。
7. **C-2 五处段扫描共享增量段索引 / C-6 worker 零拷贝**：结构性手术，留 roadmap。

## 6. 结论

- 两梯队 14 处位级一致优化全部落地：**形状管线 -33%、autoPlace -65%、布局布线循环 -45%、协商热循环 -13~-24%、DRC -24%、大铜皮查询 -93%**；
- 11 案例差分对拍逐字节一致 + 全量回归全绿——既有全部质量数字（布通率/线长/过孔/DRC）不变；
- 侦察清单剩余项（B1-2 全量、B4-6 逐网、C-2/C-6）已标注收益适用面，后续轮次按板型档位择机。
