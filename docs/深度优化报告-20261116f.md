# 深度优化报告 20261116f —— 人工形态美化（humanize）：让 AI 布的板像人布的

> 目标：用户命题「让 AI 用它画图像是人在画图一样」。本轮不动物理口径（连通/间距/工艺），
> 专攻**输出形态**——把格点布线器的机器味残渣清零，使走线呈现人工布线的斜线形态。

## 1. 问题定义：什么叫"机器味"

对 5 块真板（fable-01/02/03、h2-stm32、atmega328p）fresh-route 输出做几何审计
（`.scratch/audit-human.mjs` / `.scratch/audit-fresh.mjs`），定义四类机器味指标：

| 指标 | 定义 | 人工布线形态 |
|---|---|---|
| **kink（斜线残渣）** | 方向非 0°/45°/90° 的走线段 | 人工走线只出现轴对齐与 45° |
| **stairs（台阶）** | E,N,W 型折返（本应一根斜线） | 人工用 45° 斜穿 |
| **tiny（碎屑段）** | <0.3 格的走线段（过孔孪点除外） | 人工最短段 ≈ 半格 |
| **segs（顶点数）** | 折线点数 | 同拓扑下越少越干净 |

审计还复测了绕行比（路径长/端点直线距）——它是布线拓扑质量指标，本轮不作为优化对象。

## 2. 根因定位（三处，全部在后处理 beautifyResult）

### 2.1 切角不辨角型 → 22.5° 斜线（kink 的唯一来源，211 处）

`beautifyResult` 的切角阶段对**每一个拐角**无差别斜切：切点 A=V−d·u_in、B=V+d·u_out，
d=min(maxCh, lV/2, lN/2)。对横↔斜过渡的 **45° 角**（引擎八方向搜索的正常产物），
弧长切点落在两条不垂直的腿上，切角段方向 = atan2(0.707·d, l−0.707·d) ∈ {22.5°, 67.5°}——
把一根干净的 45° 折线切成两段 22.5° 斜线。**45° 角本身已是人工形态，切它只会变丑**。
冒烟实验（`.scratch/smoke2.mjs`）：40×24 空板单网，横段接斜段，输出中段方向 157.5°——
与 git stash 对照确认为存量行为（非本轮引入）。

### 2.2 拉直候选缺斜线 → 台阶保留

`straightenPath`（弦拉直，KiCad mergeStep 同思想）的替换候选只有 {直连, 2 段正交狗腿}，
**没有 45° 斜线候选**。E,N,W 台阶（拐角代价 30+30=60，达到 ≥60 拉直门槛）即使可以
坍缩成一根斜线（线长 min·√2+(max−min) < dx+dy，拐角 10 < 30），也只能退化成 L 形狗腿。

### 2.3 切角尺度偏碎 + 无残渣防线

maxCh=min(2g,1.2)（0.25 格时 0.5mm）——人工切角通常 1mm 上下；且切角吃掉腿后对
残余段无下界约束（leg < maxCh 时 d=min(...) 可吃掉腿部 90%+，给下一拐角留碎屑）。

## 3. 改动（全部收敛在 beautifyResult，搜索层零改动）

1. **切角只切真 90° 角**：`|dot|>1e-6·lV·lN` 即跳过（正交判定用格点整值精确成立；
   斜-斜 90° 角 dot=a·b−a·b=0 精确命中）。45°/135° 角原样保留。
2. **straightenPath 增加 45° 斜线候选**：|dx|≈|dy| → 单斜线直连；否则单 45° 角两段
   （斜线在前/在后两个 mid）。排在正交狗腿**之前**（线长与拐角代价两项均严格优），
   斜段间距由 segClearOK 把关，失败回退狗腿——保持"绝不退步"接受准则。
3. **maxCh=min(3g,1.5)**：0.25 格时 0.75mm，切角尺度对齐人工。
4. **防残渣双保险**：切角后两腿残余 ≥0.5g（`d=min(..., lV−minRem, lN−minRem)`）；
   切角后近重复点合并（<1e-4 同层，换层孪点除外）。

## 5. 对 AI 代理的意义

- **render 目检更可信**：AI 交付前"看一眼"不再看到 22.5° 斜线残渣与碎屑段，
  目检注意力可以集中在真正的拓扑/布局问题上。
- **SVG/Gerber 顶点数 −25%**：交付文件更小，制造文件更接近人工 EDA 输出。
- 证据分级不变：kink/stairs 指标是 deterministic 级（纯几何），AI 可自证。

## 6. 边界与遗留

- **绕行比未动**：atmega/h2 平均 1.25-1.35 的绕行比来自协商拓扑（让路代价），
  属布局/拥塞问题，不是美化层可解——留给布局-布线反馈循环。
- **平行通道 jog 对齐**（多根平行走线的转折位置对齐成"梳齿"）：需跨网协同几何，
  风险面大，本轮不做（立项记录）。
- **网格对齐焊盘的逃逸 stub**：raw 路径端点落在焊盘角（格点搜索语义，非本轮引入），
  焊盘覆盖保证连接（DRC 连通口径），视觉被焊盘吞没——不动。
- 禁布区/铜皮/泪滴与美化无交互（美化只动本网折线，全程 segClearOK 把关）。
