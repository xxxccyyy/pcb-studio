# 两轮优化的独立正确性复查（2026-11-08）

## 审计范围与结论口径

对照本会话保存的两份优化前代码，复查全部算法改动，而不是只根据测试通过就判断正确。范围包括第一轮的 A* 数值堆、邻居缓冲、无过孔影响图快速路径，以及第二轮的布局状态恢复、原布局候选、代价写回、焊盘铜间距、物理孔距和板边检查。

最初完整测试 **243 项全部通过**，但独立边界审查仍发现下面的问题。这说明旧测试覆盖不充分，不能据此声称所有输入都正确。审计也区分新改动引入的问题与旧代码遗留的不一致。

## 发现及处置

| 问题 | 来源 | 影响与修正 |
|---|---|---|
| 同网、同坐标、同孔径的 PTH 与 via 被当成两个物理孔 | 第二轮混合孔检查新引入的误报 | 已在检查模型中合并同一物理孔，同时继续逐焊盘检查环宽；新增反例保证不同网络或不同孔径不会通过合并隐藏冲突。 |
| 显式 `holeR:0` 与制造模型不一致 | 既存导出漏洞，第二轮未测到 | 检查器排除零孔径，但旧 Excellon 仍可产生 `C0.000` 工具；现已跳过零孔径，并消除相同输出坐标/孔径钻孔操作的重复记录。 |
| 缺省 `holeR` 的通孔焊盘在 IPC-D-356A 中被分类成表贴 | 既存导出漏洞，第二轮未统一到此导出器 | IPC 现与 DRC、Gerber/EasyEDA 使用相同的 `viaDrill/2` 缺省半径，输出通孔记录及孔径；显式零孔径仍保持无孔记录。 |
| 锚定焊盘仍在最后写回时被保留四位小数 | 既存精度问题，前述锚定测试未覆盖 | 移动量虽只有约 0.000044 mm，但不符合精确锁定语义；现在不量化锁定焊盘，补六位小数位置/尺寸回归。 |

## 第一轮：A* 的独立差分证据

独立审查器抽取新旧实际内核并执行：

- **200,000 次混合堆操作**，包括大量相同优先级、小数成本、单元素/排空/103 次重置；**93,475 次出堆状态序列一致**。
- 多种窄行/窄列/普通网格、1/2/4 层、正交/斜向组合，穷举 **8,064 个邻接状态**；邻居元组及顺序一致，最大恰为十槽，状态索引均合法。
- 三种栅格下 **1,050 次过孔集合切换**，涵盖空、占用、重叠不同属主；**250,250 个影响格点**同时匹配旧版和独立距离/属主集合 oracle。
- **100 块非内置随机板**，覆盖 1/2/4 层、正交/斜向、不同过孔成本、混合线宽、hs/pair、禁布区、固定手动线/缝合孔；**1,105 个逐步结果**一致，每板另测两轮优化、空/满快照恢复、单网重布。
- 这些随机板含 57 块有过孔、57 块未完全布通；也比较了失败结果，而不是只筛选成功结果。

上述结果支持这些性能改动的行为等价性，没有发现第一轮引入的回归。优先级保持 JS Number、同代价堆顺序保持不变，typed buffer 的状态范围在现有四百万状态上限内安全。会话级缓冲仍要求搜索非重入；现有调用链为同步搜索，未来改为递归或并发时必须重新审查。

## 第二轮：布局与规则的补充验证

主线程额外对 **100 组布局**使用独立代价计算，覆盖禁布区、拥塞热点、四十次迭代、三次重启、部分元件锚定，核对最终代价、封装内部距离及锚定位置。另用六位小数锚点复现写回舍入，修复后坐标变化为零。

焊盘间距、按层隔离、孔径/板边边界仍由专门回归覆盖；本次针对同物理孔复用、显式零孔、默认孔径以及导出内容补交叉验证，不只检查 DRC 的消息数量。

## 修复后的最终验证

已重新构建独立单文件应用并运行 `npm.cmd test`：**250 项检查全部通过**（80 核心、71 node:test、48 书籍规则、15 CLI、17 畸形输入、7 导出校验、12 优化验证）。相比审计前新增 7 项回归：1 项精确锚定、6 项物理孔/导出一致性。独立单文件与源码一致性检查也通过。

新增反例确认：合并物理孔不会隐藏不同网络短路、不同孔径冲突或小焊盘环宽不足；合并后仍按过孔较大的铜环检查板边。三个内置示例仍完整布通且 DRC 无错误。

结论是：**已修复本次确认的四类问题，未发现其余受审改动在上述覆盖内有回归；不是对整个 PCB 软件的全面正确性证明。**

## 不应夸大的结论

- 差分等价不证明旧算法本身在所有 PCB 上正确；测试通过也不是形式化证明。
- 第一轮耗时表是当时 Windows / Node 的本地中位数测量，不是所有板子或浏览器上的保证；MCU 的 2.2% 差异不足以声称稳定提速。
- 本次未做真实浏览器内存/交互复测、实物制造、外部 EDA 对账或 SI/PI 仿真签核。
- 当前模型仍不完整支持任意板框、槽孔、器件庭院/装配实体以及高压爬电距离。板厂的每类孔径能力、插件适配等仍需制造审核。一个已复现但本次未扩修的既存规则缺口：全局 `viaDrill:0.4`、某插件焊盘 `holeR:0.04` 时，实际钻孔为 0.08 mm，但当前钻孔下限检查只检查全局值，不能据 DRC 通过认定该插件孔可制造。**【后续已修，2026-11-08】** checkDRC 逐孔补「插件孔孔径」错误（钻孔直径 < 机械钻孔极限 0.15mm，即 `JLC.via.double.drill`），manufacturing-rules 新增 1 项回归；顺带修复同文件的既有笔误 `JLC.via.single.double.drill`（不存在的嵌套路径，导致 advise 的 VIA 极限建议从未触发、消息会打印 undefined）。
