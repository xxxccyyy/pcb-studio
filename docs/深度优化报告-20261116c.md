# 深度优化报告——0.14.10 组合一致场转正（2026-11-16c）

> 定位：0.14.9 深检（深度检查报告-0.14.9.md）留档方向的执行轮——修复障碍感知启发式
> 的两个机制缺陷（非一致场次优路径 + 漏斗效应），实测后**转正为默认启发式**。

## 1. 修复一：分离场 → 组合图单元 BFS（一致性根除）

0.14.9 的掩码场 = 分离计算（各层 mask BFS + 层轴 viaH 传播），深检证明其在"跨层
掩码不对称"处非一致（43240 处/最大超出 76.5 格）→ first-pop 终止可能接受次优路径。
0.14.10 把 mask 模式改为**组合图单元 BFS**：平面 8 邻 + 换层 2 邻（双端 mask 门控）
全部计 1——场 = 组合图精确最短路度量：

- **可采纳**：每条场路径对应一条放松的真实路径（平面 mask 恰=真实可通行、diag 计
  1≤√2、换层计 1≤viaCost，前提 viaCost≥1——<1 为既有退化域，盲口径 viaH=1 同样越界）
- **一致**：A* 全部可遍历边 ⊆ 场图边集且真实权重 ≥ 1 → 对 A* 代价 Lipschitz →
  first-pop 终止即每边最优。探针复测：**一致性违反 43240 → 0**（40 板 × 410 组态）
- mask=null 盲口径逐位不变（默认路径零风险期 + 基准对照）

## 2. 修复二：掩码缓存（routeNet 内不变性）

mask 是 {net 恒等字段, model 静态, viaInf, usage-异网, pairBand, hard} 的纯函数；
routeNet(N) 内部 own 提交经 usage+1/ownStamp=gen 配对抵消（缓存构造时该格 usage−0、
真值 usage−1=同值）→ routeNet 内跨 astar 调用掩码逐位不变 → 以 (epoch, net.i, hard)
缓存。失效点 7 处（ripNet/rebuildViaInf/patchViaInf/restore/adoptShared/pairBand
置位与清除；commitRoutes 与 optimize 回滚经 rebuildViaInf 覆盖）。探针：223 次缓存
命中逐 astar 重算比对 **0 陈旧**；59236 次 astar 不变量校验全过。

## 4. 转正决策（默认开 + 逃生门）

- **默认开**：质量五板全面 ≥ 盲口径（持平或更好，无一回退）+ 一致性可证 + 40 板
  探针 + 全量回归（80 核心 + 285 node:test + 48 书籍 + 17 CLI + 39 模糊 + 7 深检
  + 48 优化锁全过）+ m1×20/m3-qfn 语义门全过 → 满足项目行为变更转正口径
  （compactPairs/jointReroute 先例）
- **逃生门**：`opts.obstacleH:false` / CLI `--no-obstacle-h` → 盲口径
  **逐位恢复 0.14.8**（fable-03/icebreaker digest 实测一致）
- **金标准**：search-neighborhood-baseline.json 重录（15 例 11 变），reason 注明
  0.14.10 组合一致场 + 变更清单
- 已知代价：路由结果与 0.14.8 不同（协商路径改变）→ 已交付项目的重跑对账遵循
  0.14.7 批次4 的重交付先例

## 5. 边界与不夸大

- 五板 + m1×20 + qfn + 示例的质量证据，非全板统计结论；`--no-obstacle-h` 逃生门
  覆盖未测板型的回退需求
- 速度收益 1.37-1.88×（组合场比分离场更精确 → 展开略多，2.2-2.5× 降至 1.4-1.9×，
  换取质量持平/更优 + 一致性证明——值得的交易）
- 漏斗效应假设未再单独验证：一致场走廊结构未变而质量恢复，说明分离场次优边是
  主要机制；"多样性下降"是否仍有残余贡献，留待后续有需要时做受控实验
