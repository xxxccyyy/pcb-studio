## 一、方法论感悟：为什么"每页都读"是值得的

1. **规则的可信度分层**：本次研读最大的收获不是某条具体规则，而是确立了"规则必须有出处"的纪律。
   工具的 rules 知识库现在按 `可靠/有条件/勿信` 三层组织，每条标注书名+页码（`book-backed`），
   与 `deterministic`（工具几何计算）、`datasheet-backed`（板厂参数）并列——AI 代理引用结论时能自证。
2. **同一事实的多书互证**：3W 间距在 PEI（杂散电容距离平方衰减）、黑魔书（容性/感性耦合模型）、
   Bogatin（串扰章节）各有物理推导，角度不同结论一致——这种互证让我们敢于把"3W"从谣言清单
   移到"有条件可靠"，并写清楚它的失效条件（两层板、差分对内）。
3. **译本也有错**：黑魔书华为译本 ch1 两处把"上升时间减半→dI/dt 增至4倍"误写为"减小为1/4"
   （笔记 ch01-02 已标注）。逐页读+物理直觉复核，比"信书"更接近权威。
4. **工具级产出**：读到的每一条规则都问一句"能不能变成检查项/代价项/规则库条目"——
   本次落地：IR-drop 求解器、传输线 1/6 判据、趋肤效应计算、介电常数预设、30+ 条规则库条目。

## 二、各书核心贡献（按对本工具的影响排序）

### 《高速数字设计·黑魔书》(Howard Johnson) 华为译本 12章 —— 布线器物理层的根基【全书读毕】
- **Fknee=0.5/Tr 与 1/6 判据**（ch1）：信号带宽由上升时间决定，不是时钟频率。
  走线超过 Tr·v/6 就必须按传输线处理。→ 工具新增 `nets[].tr` 字段 + `criticalLineLen()` + advise TERMINATE 建议。
- **串扰的容性/感性分解**（ch1）：容性前向同向、感性前向反向，都正比于 1/Tr；感性耦合通常占主导。
  → 3W 检查与 hsCrosstalkScan 的物理依据；间距加倍串扰 1/4（ch11）。
- **地弹 V=L·dI/dt**（ch2/ch9）：回流路径电感是根源；连接器共模电感、多插地降 1/(1+N²)。
  → 回流地孔检查的 book-backed 依据；rules 回流_换层对策层级（ch7 四层优先级）。
- **过孔**（ch7）：过孔电容典型 0.5pF（1ns 边沿仅 27ps 影响）——"过孔的敌人是电感不是电容"；
  `viaLoopInductanceNanohenry()` 落地（0.3mm 孔/1.6mm 板≈1.3nH，与书算例吻合）；深宽比 ≤6:1。
- **电源系统**（ch8）：PDN 三频段模型（体电容/MLCC/平面+片上）、五步法 Xmax=ΔV/ΔI、
  平面电容 FR-4 0.01in≈100pF/in²。→ rules 去耦_PDN 组。
- **传输线**（ch4）：微带公式 Z0=(87/√(εr+1.41))·ln(5.98h/(0.8w+t))——与本工具 impedance() 同式互证；
  εeff=0.475εr+0.67；90°拐角电容≈2×线宽 fF——直角无害论的定量注脚。
- **时钟分发**（ch11）：时间裕度不等式、多分支始端匹配 Rs=Z0−N·Rdrive、低阻线对电容敏感度低
  （20Ω 是 50Ω 的 1/2.5）→ 时钟网规则库。
- **晶振**（ch12）：抖动四噪声源电源最麻烦；滤波电路布局参数（走线<0.1in、过孔 0.035in）。
- 详见 [书籍研读/04-黑魔书笔记-ch*.md ×6](书籍研读/00-总览.md)。
- **诚实记录**：华为译本存在数处笔误（ch1 两处 dI/dt 倍数、ch7 式7.7 系数、ch8 单位），
  各册笔记已按物理关系复算勘误；OCR 缺失的公式常数按书中算例反推并标注。

### 《Practical Electronics for Inventors》1056页 —— 无源器件与电源的物理直觉
- **SPICE 节点电导矩阵**（p276-278）：→ 工具新增 `powerDrop()` IR-drop 求解器（drop 命令），
  把电源网走线当电阻网络解每焊盘压降——区别于普通 DRC 的确定性供电质量度量。
- **趋肤效应**（p183/p291）：→ `skinDepth()`/`acTraceR()` 内置计算，载流检查表补充 AC 电阻口径。
- **热阻网络 ℜ=L/(kA)**（p63-68）：覆铜+缝合孔=散热路径的定性依据 → rules。
- **EMC 要点清单**（p402-403）：地平面开槽、环路面积、悬空铜皮——与我们既有 DRC 检查项一一对应，互证。
- **保护链拓扑**（p424-473/p442/p452/p524-553）：TVS 钳位、续流二极管、LED 并联禁忌 → rules 布局规程组。
- 详见 [书籍研读/05-实用电子学笔记-*.md](书籍研读/00-总览.md)（9 册）。

### 《Right the First Time Vol.2》(Lee Ritchey) 309页 —— 高速 PCB 实务【研读中 3/5】
- 已读部分（p1-186）最有价值的发现：
  1. **"技能在工程师不在工具"**（ch2）——Ritchey（Koloa 布线器作者，布过 2000+ 板）论自动布线：
     好坏取决于约束规则，这正是本工具 rules 知识库+锚定+禁布区的路线背书；
  2. **PDN 实务**（ch3）：库仑桶 C=I·Δt/ΔV、磁珠 30 年未用之证伪、Y5V 偏压失容（50%电压→10%容量）、
     信号层覆铜作平面电容（500pF→4nF 修复 EMI 实例）→ rules 工程方法论组；
  3. **制造实务**（ch4）：1oz=36µm、蚀刻 ±0.5/±1mil、盲孔深径比 1:1、via-in-pad 填铜对策；
  4. **层叠/材料**（ch4.6/ch5）：er 随构造与频率 3.63~4.69@1GHz；微带经验公式不可信、带状线公式可信
     ——对工具阻抗估算器的诚实校准（已写入 DIELECTRICS 注释与 fabChecklist）；
  5. **实验证伪清单**（ch6/ch7，TDR+近场实测）：过孔桩线 <3.125Gb/s 无关紧要（主项是电容不是 stub）、
     直角无酸陷阱、跨平面割缝条件性无害（共地+PDN 达标）、"换层必加地过孔"未获实验支持
     （前提：平面贴近+旁路充分）、EMI 主要来自 Vdd 纹波而非时钟、20H 与 λ/20 证伪
     ——工具 rules 的可靠/有条件/勿信三层据此校准（回流地孔检查降为"提醒级最佳实践"并注明前提）；
  6. **差分信令**（ch8）：100Ω=两根50Ω各自端接、紧耦合迷思、等长容差=边沿时间换算 → 差分_预留组。

### Bogatin《信号完整性与电源完整性分析 第3版》521页(扫描+OCR) —— SI/PI 的系统框架【研读中：附录+ch1-7 已读，ch8-13/附录D 在读】
- 扫描版 521 页经 PyMuPDF 渲染 + Windows 内置 OCR 逐页转为文本后研读；OCR 错字规律已被
  研读代理总结（"巧"≈5、"佣/開"≈000 等）并用书中算例反推核验公式。
- **附录A（102条设计规则）/附录B（100条经验法则）**（主研）：量化边界全部落进 rules
  的 Bogatin附录速查六组（带 A.xx/B.xx 编号）；串扰 1W/2W/3W=5%/2%/1%、保护线 −50%/−90%、
  平面电感 33pH/mil、趋肤 2µm@1GHz 等成为 hsCrosstalkScan/GUARD/载流的直接依据。
- **第1章**：SI 十条基本原则总纲（瞬时阻抗恒定）——rules 工程方法论第一条；
- **第2-4章**：BW=0.35/RT 与 Fknee=0.5/Tr 双口径、上升边 RSS 合成（换慢工艺器件的隐患）、
  方块电阻 0.5mΩ/sq 心算校核、趋肤 20MHz 起 R∝√f → rules 高速判据/载流组；
- **第5-6章**：**净电感地弹公式 V=(L−M)dI/dt**（回流孔靠近=增大互感 M）；
  回流孔间距阈值挂钩孔长（<孔长才有效）→ rules 回流组；δ=66/√f(MHz) µm 与 skinDepth 互证；
- **第8章**：反射与端接——TERMINATE 建议按此校准为"优先源端串联（R≈Z0−驱动内阻）"；
  1/6 判据与式(8.13) 等价且更保守；四条突变门限（容性 <4pF×RT(ns)、感性 <10nH×RT(ns) 等）入 rules 口径；
- **第9章**：损耗公式全验算（介质损 α=2.3·f·Df·√εr、FR-4@1GHz≈0.1dB/in）→ 新增
  `dielectricLossDbPerIn()` + DIELECTRICS 增加 Df 字段；
- **第10章**：串扰实测与附录B互校（1W 口径 6.5% vs 5%，2W/3W 一致）；**浮空防护线会恶化串扰**
  ——GUARD 建议改为"必须两端+沿途接地，上升边空间延伸内 ≥3 孔，微带短路防护≈−84%"；
- **第11章**：差分对量化地基（紧耦合 Zdiff 仅降 10-12%、错位预算 ΔL≤0.2UI×v）→ rules 差分_预留组；
- **第12章**：S 参数章明确了"工具级近似够用"的诚实边界（代数一阶估算可做，眼图/谐振谱引导外部工具）；
- **第13章**：PDN 系统教材——五个回路电感解析式（走线/过孔对/方块/径向扩散/孔间扩散，mil 制）
  全部实现为零依赖 JS 函数族并按书中算例回归（tests/books-insights）；
  "容值不重要"设计空间判据 Ztarget×A<0.7 Ω·in²、FDTIM 标准档位算法进入 rules 去耦_PDN 组。

### 《PCB Design for Real-World EMI Control》(Archambeault) 中文版 137页【全书读毕】
- **返回路径是 EMC 第一考量**（贯穿全书）：三大中断源=跨割缝/换层换参考/跨板连接器，缝补电容 0.5in 内跨缝。
- **去耦反谐振实测**（ch8）：大小容值并联在 75-200MHz 可能反而恶化——分布式去耦统一容值、
  封装内取最大；密度上限受安装电感限制（1个/in² 也只到 400-600MHz）。
  → rules 去耦_PDN 组（与 PEI/Bogatin 的"并联覆盖宽频"形成诚实对照：并联可行但必须管理反谐振峰）。
- **电容角色三分**（ch8/ch11）：换层贯通孔旁必须低 ESR；远端分布电容可用有损耗电容阻尼平面谐振
  （65/35 搭配降 20dB）→ rules 回流_换层对策层级。
- **换层组合白名单**：相邻参考面最简、3-5/5-7/7-9 靠电容桥接、3-9 禁用 → rules。
- **I/O 滤波**（ch9）：贴连接器 ≤1cm、π 型（C1 数字地/C2 机壳地）、共模滤波器外侧挖空参考平面。
- ** EMC 工具定位自证**（ch14）：本书把"设计准则检查器+快速计算器+准静态估算"列为 EMC 工具箱正途
  ——本纯 JS 工具（DRC+计算器+经验公式）正合此道。
