## 1. KiCad Push-and-Shove【源码实证】

### 1.1 核心洞察（三条最值得记住的设计）

1. **"推挤"的原子操作是"绕壳"而非"平移"**：`ShoveObstacleLine` 完全建立在 `LINE::Walkaround`（pns_line.cpp:291-659）之上——把障碍线绕着推挤者的间隙壳（hull）序列重新走一遍。hull 是八边形（45° 模式）或 bbox（90° 模式，pns_walkaround.cpp:187-194）。任何范式只要能"以任意多边形为临时障碍做一次受约束重路由"，就能实现推挤。
2. **过孔是唯一的"力传播介质"**（pns_shove.cpp:1522-1525 注释）：走线端点不能自己动，一切纵向推挤都转化为过孔拖拽 + `DragCorner`。为此 KiCad 在宽度变化点/T 型点自动插"虚拟过孔"（`FixupVirtualVias`，pns_node.cpp:1276-1362），防止推挤从变宽点抄近道。
3. **rank 单调递减的自组织优先级**：head rank=100000（pns_shove.cpp:2508）；每被成功推挤一次，新线 rank=推挤者 rank−1。"新来的撞上 rank 更高的旧线 → 旧线被再挤一次"——无需全局重排网络顺序，被反复挤压的线自动让位。这正是 PathFinder 拥塞协商在形状域里的最小实现。

### 1.2 算法细节存档

- **事务化世界**：`NODE::Branch()` O(1) 写时复制分支（pns_node.cpp:163-194），推挤全部在分支上做；失败 `delete` 分支即回滚；成功 `Commit` 合并。springback 栈（pns_shove.h:196-212）保存每帧受影响区 bbox，`reduceSpringback` 在下次 Run 前弹出"不再与 head 碰撞"的旧帧——帧级撤销基础设施。
- **主循环 = 显式线栈**（pns_shove.cpp:1883-1926）：推出新线就压栈，栈顶继续找最近障碍（`NearestObstacle` 按**沿路径弧长**排序，pns_node.cpp:399-433）；迭代上限 250 / 时间上限 1000ms（pns_routing_settings.cpp:43-44）。
- **重试机制**：推不动就把壳再吹大 1000 内部单位重来，共 3 次（pns_shove.cpp:524,628）；绕壳 4 种变体 {正序 CW, 正序 CCW, 逆序 CW, 逆序 CCW}（:338-341）；solid 不可推只可绕，两次尝试 rank 策略不同（+10000 强推 / −1 跳过，:827-833）。
- **间隙语义**：判定用 `clearance + halfW_A + halfW_B − 1`（"-1"使"恰好贴着间隙"合法，pns_item.cpp:280）；配合 clearance epsilon（规则值−ε）保证推挤出的线永不再撞 hull 主人；同 net/自由盘返回 −1（完全不判）；孔-孔、板边、net-blind 物理间隙各自独立成类（pns_kicad_iface.cpp:910-1028）。
- **降级链**：推挤失败 → SH_TRY_WALK → walkaround（CW/CCW/SHORTEST 三策略并行，聚类 margin=2×clearance+width，长度膨胀 >10× 早退，pns_walkaround.cpp:147-149,377-381）。
- **推挤后优化**：MERGE_OBTUSE（OE_LOW，1 遍）/ MERGE_SEGMENTS（2 遍，遍间反转队列顺序 pns_shove.cpp:2096）+ 限制在受影响 bbox 内（RESTRICT_AREA）+ rootLine 对照防过度优化。

### 1.3 优化器（pns_optimizer）【源码实证】

- **拐角代价表**（pns_optimizer.cpp:44-57）：135°=10、180°直线=5、45°折返=50、90°=30、掉头=60。
- **mergeStep**（:850-917）：对跨度 (n, n+step) 用 `BuildInitialTrace` 生成两个姿态的 2 段狗腿旁路，无碰撞且**拐角代价严格下降**即接受（纯拐角判据），first-improvement + 步长递减。mergeObtuse（:511-585）延长两钝角段至交点消除"之"字抖动；mergeColinear（:628-650）共线合并。
- **Smart Pads**（:1111-1229）：焊盘 8 方向 breakout（正交长=半径+线宽、对角长=w+min(sx,sy)/2），只重排线端前 3 个顶点，禁止出口角=ACUTE|RIGHT|HALF_FULL，同代价取 breakout 更长者（长条焊盘沿优势方向先走一段）。
- **fanoutCleanup**（:1274-1321）：两端都是 pad/via 且总长 <10×线宽 → 整线替换为单拐点狗腿。
- **KEEP_TOPOLOGY 约束**（:429-474）：替换段与原段构成的环内查异网 SOLID joint，有则拒绝——**禁止优化把走线抄近路跨过原本绕行的焊盘**（拓扑同伦检查）。
- **Tighten**（:1550-1708）：3 段 U 形窗口二分内移，接受准则=新旧走线对称差面积（shovedArea）更小——"最小扰动"度量。

## 2. gEDA/pcb toporouter【源码实证】

Anthony Blake 的博士工作，实现 SURF 橡皮筋布线系统论文（Dayan & Dai, UCSC 1991-1997【文献】），代码自标 *EXPERIMENTAL*（toporouter.c:36）。

- **拓扑即几何载体**：每层一张约束 Delaunay 三角剖分（GTS 库），三角形的边=橡皮筋，路径"挂"在边上的有序链表里（edge_routing），拐角=路径跨边的公共顶点。障碍=约束边（板框/方形焊盘轮廓/已有走线）。
- **容量而非阻挡**：`candidate_vertices`（toporouter.c:3478-3547）按 flow/capacity 判定一条边还能不能挤进一条线：`Σ(相邻占用者两两 min_spacing) + 新网两个接入间距 ≤ 边长`。三角形内部容量=顶点到对边垂足的"门户宽度"（:3237-3279）。这是对"二元占用"模型最有价值的补充。
- **簇=连通分量作端点**（:2640-2720, 7234-7243）：union-find 标签，布通即合并；A\* 以簇为端点（源/目标候选=簇内全部引脚，多端点重启 :4312-4316）。
- **ROAR ripup**：LEASTINVALID 模式先放行后修复——允许新线穿越旧线但按被穿线的 score×n² 计价（:4644-4652）；冲突线 checkpoint（记录每顶点在边链表中的索引）→ 拆除 → 重布 → 失败精确回滚（:7147-7231）。
- **detour 评分**（:6857-6862, 7439-7441, 7536-7574）：每网记录空板独布分 ideal，每轮对 `score−ideal` 最大的网重布，"新总分不降则回滚"——比 history cost 更直接的收敛信号。
- **净序**：pairwise 干扰矩阵——每两网 (i,j)：摆上 i 独布 j，比较 j 的分与独布分；fail 少者先布，刺头留给 ROAR（O(n²) 次布线，:6913-7026）。
- **拓扑→几何**：speccut 拓扑切角（发现抄近路机会时临时加边，:6406-6554）→ 橡皮筋绷紧：每个原拐角变成半径=min_spacing 的圆弧，弧间公切线连接（:6041-6260）——自由角度输出，无 45° 约束。
- **space_edge 弹性匀距**（:4390-4458）：同一条边上多条路线的一维弹簧松弛，每轮朝欠间距合力方向移动 10%，最多 100 轮。
- **已知粗糙点**：过孔只能打在焊盘/引脚/已有过孔上（无自由过孔）；导出时整条线画在同一层（:6568，实验性 bug）；蛇形数学齐备但未接线（:5745-5789 空壳）。

## 3. OpenROAD FlexDR（TritonRoute）【源码实证】

IC 详细布线工业标准，与我们的范式同源（网格+协商），最有"可直接抄"价值的工程细节：

- **策略表驱动迭代**（FlexDR.cpp:1750-1822）：65 行参数表 `{窗口尺寸, 偏移, 每网重布上限, DRC代价, marker代价, 固定障碍代价, 衰减, 撕线模式}`——迭代 0-2 全拆全布，之后只拆违例网；代价逐轮 ×2 递增；穿插全拆刷新轮；**违例清零立即停**（:2206-2208）。
- **代价公式**（FlexGridGraph_maze.cpp:581-644）：`cost = 边长 × (1 + gridCost偏track + DRC邻近 + marker历史 + fixedShape障碍) + 软墙(32×20×minWidth) + 转弯恰+1 + via2via/via-转弯非法间距惩罚`。**过孔代价 = z 高度差按 4×pitch 累积**（没有单独 via 常数项）。
- **历史代价三件套**（FlexDR_init.cpp:2070-2283）：每个违例 box 覆盖的所有网格边 hist+=10（空间化，而非只加被占边）；**每布完一个网全体 hist ×0.95~0.999 衰减**（防旧伤永久锁死）；8bit 饱和整数。
- **DRC 驱动撕线**（:2302-2618）：只拆违例的 aggressor 网，victim 只重新检查；`canRipup` 上限=每网重布次数（3→8→16→32→64 逐轮放宽）；`canAvoidRipup` 硬度计数保护 NDR/时钟网（3/100/10 次，drNet.h:33-45）。
- **多引脚网**（FlexDR_maze.cpp:2271-2525）：src 选"离重心最远的 pin"，之后每次连"离当前连通域包围盒最近的 pin"；**连通后把整条已布路径的每个格子设为 src**；pin 格允许被穿（feedthrough）。
- **h 函数**（FlexGridGraph_maze.cpp:228-314）：对目标 pin 的 **AP 包围盒**求 L1 距离（不是单点）+ Z 高度差 + 必需转弯数 + "沿当前层走到底必非法"的预测惩罚。
- **worker 窗口 + best 回滚**（FlexDR_end.cpp:682-716）：7×7 gcell 窗口外扩 MTSAFEDIST；worker 内每网保存 best 快照，**结果比输入差就整体丢弃**；边界以"边界 pin"（跨边界线段切点+层）缝合。
- **收尾**：min-area 补片按"左右哪侧代价干净"选方向（FlexDR_maze.cpp:3556-3712）；每轮后同层重叠合并 + 拓扑 A\* 连通性检查（穿 pin 罚 5，FlexDR_conn.cpp:302-436）；marker 打 recheck 标记自动进下一轮。
- **平局裁决**（FlexWavefront.h:43-80）：cost → 离重心近 → **高层优先** → pathCost 大（DFS 式沿一条线走完）→ 坐标 → 方向逐位。

## 4. pcb-rnd autorouter（Harry Eaton 矩形扩展）【源码实证】

基于 1985 DAC 论文 *A Method for Gridless Routing of Printed Circuit Boards*（Finch 等）【文献】——迷宫网格与形状推挤之外的第三条历史路线。

- **扩展矩形**：搜索单元是"从桥盒向一个方向一路伸到板边的最大空盒"（`Expand`，autoroute.c:2073-2207），盒间共享边=图的一步；BreakManyEdges（:2516-2786）按顺时针把新盒四边切成新边，**对角"角扩展"只在两邻边同时自由处生成**（:2657-2680）——"转不过弯的角不会生成角边"。
- **mtspace 转弯空间**（mtspace.c）：判定"圆盘（过孔半径+clearance）能否塞进缝隙"——候选区减去膨胀障碍后**剩余条带宽 ≥ 2×(radius+clearance)** 才行（:255-295）；两阶段惰性分裂查询，偶/奇数轮分树。
- **奇偶轮协商**（:4131-4144）：`LastConflictPenalty=(400×pass/passes+2)/(pass+1)`（后期越来越贵）、`ConflictPenalty=4×Last`、罚金×线龄（早轮铺下且存活的老线更便宜撞）；`hi_conflict=MAX(8×(passes−pass+1),6)` 早期宽松后期收紧；**证明"只有罚金调度、无逐格历史项"也能收敛**。
- **惰性过孔搜索**：扩展区内先用乐观下界挂"假边"（g+ViaCost+到目标下界，:3378），弹出时才做真正的圆盘_fit 查询并展开到每个其它层组——绝大多数连接到不了换层决策点，省掉全部枚举。
- **ViaCost 折扣**（:1709-1711）：目标恰在孔位所在层时返还一半 ViaCost——防止"明明一步就到却被过孔价吓退"。
- **努力上限**：`max_edges=(800|2000)×(pass+1)×layers`，注释值得原样记住："surprisingly it helps to give up and not try too hard to find a route! This is not only faster, but results in better routing."（:3805-3808）。
- **净序**：首轮按 bbox 面积升序，后续轮按上轮总代价升序——"最简单的先布、难的垫后，避免白撕"（:4242-4265, 4424-4430）。
- **其它**：BLOAT=Clearance+ceil(Thick/2)；斜线障碍按 ≤32 段离散化（:885-905）；折线膝点必须落在相邻两路径盒的并集内（:3122-3137）；共线段合并队列（:3002-3043）；平面（PLANE）内穿行零代价、热焊盘一步直达。

## 5. 本轮移植进本工具的改进（全部有测试覆盖）

| 改进 | 源码依据 | 本工具位置 |
|---|---|---|
| **弦拉直**（U 形/阶梯段→直连或 2 段狗腿，接受准则=线长不增→拐角下降，保持本网焊盘/过孔接触，防自交） | KiCad pns_optimizer.cpp:850-917（mergeStep）、:628-650（mergeColinear）、:429-474（KEEP_TOPOLOGY 思想）、:44-57（拐角代价表 30/5/10/50/60） | `beautifyResult()` 内 `straightenPath()`，斜切前执行 |
| **历史代价衰减**（每协商轮 hist×0.99，防旧伤永久锁死区域） | FlexDR_init.cpp:2262-2283（markerCostDecay 0.950/0.990/0.999） | `createSession` opts.histDecay，`step()` 协商段 |
| **冲突驱动重布排序**（占用冲突格的网络优先重布，与失败网同级） | FlexDR_init.cpp:2302-2618（DRC 驱动撕线：aggressor 优先） | `step()` 计算 net.conflicted，`sortNets()` 排序键 |

实测：555 示例 129.5→128.2mm、单片机示例 296.8→294.1mm（beautify 后），DRC 全干净、最小间距恰在限值上；单元测试 **45/45 通过**（新增 4 项：U 形拉直/被阻挡保持绕行/同网焊盘接触保持/hist 衰减布通）。

**实现中踩过的坑（记录供后鉴）**：
1. 弦拉直初版按 KiCad 的"纯拐角代价"接受，结果 MCU 板线长**反增 1.7mm**——原始路径含 45° 斜段，斜段楼梯（5.66g）比曼哈顿狗腿（8g）更短。修正为字典序（线长第一、拐角第二）。KiCad 自己不踩这个坑，因为它的 BuildInitialTrace 本身是 45° 感知的。
2. step 上界差一（`length-2` 应为 `length-1`），全跨度（首→尾）永远扫不到——U 形测试抓住。
3. 旁路端点就在本网焊盘中心，间距检查必须跳过同网焊盘（接触保持由专门检查负责）。

## 6. 评估后暂不移植的技术（留档）

| 技术 | 来源 | 不移植原因 |
|---|---|---|
| 推挤（shove）本体 | KiCad | 需要精确几何 hull/绕壳/事务回滚一整套；栅格模型下 PathFinder 已覆盖其协商职能，收益/成本比低 |
| 虚拟过孔（宽度变化点防穿越） | KiCad FixupVirtualVias | 单一线宽模型暂无变宽场景 |
| Smart Pads / fanoutCleanup / 差分对 / 蛇形 | KiCad | 设计数据模型无差分对与等长约束；Smart Pads 需要焊盘形状 breakout 分析，留待 BGA 场景 |
| CDT 拓扑布线本体 | toporouter | 稳健 CDT 实现代价极高（退化情形处理 ~250 行）；栅格已保证 DRC |
| 边容量 flow/capacity | toporouter | 我们的栅格每格已能表达"单线占用"；多线共格共享在 PCB 间距规则下本就不合法，容量模型收益主要在通道内并排——已由栅格分辨率隐式覆盖 |
