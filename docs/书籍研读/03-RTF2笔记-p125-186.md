## 分章笔记

### 6. 第6章（续）信号完整性与板结构（p125-133）

**6.2a 信号跨平面割缝（p125-126）**
- 2000 年 18 层测试板实验（图 6.1/6.3）：走线跨 10mil 平面割缝，TDR（Tek 1502C，上升沿 125ps）无可检测扰动；再用近场探头+频谱仪沿缝扫描，辐射能量无变化。结论：信号质量与 EMI 都不因跨割缝而劣化（前提见 6.4）。
- 对照实验：双层板上下都是实铜、介质厚 32mil（层间电容几乎为零），导线跨顶面缝→缝上方近场能量增强；在缝两侧焊电容接到对面实铜后辐射消失。差别只在有无跨缝的 AC 回流路径。
- 割缝宽度由隔离电压决定：极端需求 1700VDC，常用层压板耐压 >1000VDC/mil（约 39,370 VDC/mm），2mil 即够；工艺下限 0.5oz 铜约 3mil（1oz 加倍）；实践取 10mil（0.25mm）即可，无需更大。
- 边栏例外：四层 PC 主板类产品，两平面难以在高速信号全部频段互相充分旁路，此时应避免跨割缝布线，并让每个单端信号同层起止。

**6.2b 换层时回流如何在平面间穿行（p126-130）**
- 同一测试板上四种结构（L9→L10、L2→L17，带/不带地过孔）TDR 波形完全相同，无可检测不连续——"换层必须加地过孔"的通行建议未获实验支持。
- 回流换平面的路径 = 离散旁路电容 + 平面间电容，快边沿时后者主导。容抗表（100pF/1nF/10nF）：30MHz 时 53/5.3/0.53Ω，100MHz 时 16/1.6/0.16Ω，1GHz 时 1.6/0.16/0.016Ω（未计安装寄生电感）——1nF 在 100MHz 已以 0.16Ω"短路"两平面。
- 多平面对场景：各地平面经每个器件的地引脚和旁路电容互连；旁路电容应均匀分布在整个板面。每路电源去耦做到十几毫欧以内，则所有平面（电源与地）在开关沿频段互为低阻——这正是"高速信号可以走任意平面上方"的根据。
- 去耦设计失败 → Vdd 纹波耦合到其上方信号，是很多系统 EMI 与"软故障"的主要来源。
- "换参考平面必出 EMI"的说法：作者 20 年数百块多层板、内层间任意换层，全部通过网络/医疗设备的最严苛 EMI 认证；EMI 需要 RF 源+天线两个要素，换层两者都不创造（前提是电源系统设计到位）。
- 方法论：未经硬件验证的仿真不能作为布线限制的依据——模型可能失真，或扰动"可见但不显著"。

**6.3 端接电阻取值（p130-131）**
- 逻辑电平降到 3.3V 以下后：过冲击穿输入的风险下降，但噪声裕量缩水（3.3V HSTL CMOS 裕量 1.15V，1.8V CMOS 仅 430mV）→ 下冲取代过冲成为主要矛盾。
- 走线阻抗工艺容差 ±10%：50Ω 名义值实际交付 45-55Ω 都合格。
- 并联端接取容差高端 +10%：50Ω 系统用 55Ω，100Ω 差分对用 110Ω，ECL 的 55Ω 同理——保证最坏情况只有过冲型反射且幅度可接受（正反射不侵蚀噪声裕量，负反射才侵蚀）。
- 串联端接：目标是半幅入射、接收端加倍；须保证 Zout+Zst ≤ Z0−10%（50Ω 系统 = 45Ω），使 T0 时刻分压比恰为 1:1。

**6.4 维护电源/地平面完整性（p131-132）**
- 6.2"跨割缝无害"的前提是旁边有第二条连续平面。若成千上万过孔的隔离盘在平面上重叠，会在所有平面同一位置撕出长缝——严重 SI/EMI 问题（图 4.63 反例）。
- 规则：布线阶段就设置过孔最小间距，保证电源/地层隔离盘永不重叠，孔间始终留有铜 web，使平面"看起来连续"。

**对本项目的启示**
- DRC 应新增"平面隔离盘重叠/铜 web 断裂"检查：对电源/地层做孔投影重叠检测，web 最小宽度按 3mil（0.5oz）校核；这比笼统的过孔间距规则更贴近失效机理。
- 布线器的换层策略不必强制"换层即伴随地过孔"；但可对层数 ≤4 或旁路信息缺失的板型输出"避免跨电源割缝、单端同层起止"的保守提示。
- 阻抗估算器/规则输出可附端接推荐值：并联 = Znom×1.1；串联 Rst ≤ Znom×0.9 − Zout（Zout 可按驱动器模型估计）。

### 7. 第7章 EMI 与 EMC（p133-152）

**7.1-7.3 EMI 是什么、从哪来（p133-134）**
- 频段定义：传导 EMI 150kHz-30MHz；辐射 EMI 30MHz-1GHz 或 5×最高时钟频率（取大者）。EMC = 不被其它产品的辐射/传导干扰。
- EMI 两个必要条件：RF 能量源（发射机）+ 辐射面（天线）；去掉任一即消除。现代电路工作频率早已越过 30MHz，磁珠降速法不再可行——3.125Gb/s Serdes 电源引脚串磁珠后波形严重劣化（图 7.1，厂商评估板实测）。唯一出路 = 消灭意外天线。
- 天线双向性：贴近平面的走线既不辐射可检测的 EMI，也不易受外界 EMI（FM 收音机靠近金属板信号消失的演示）。
- 好天线 = 伸出 PCB 的东西：PLCC 引线框、去鼠标/显示器的未屏蔽线缆、经连接器对接的两块板（构成偶极天线）、插座里的 PGA/BGA。坏天线 = 不伸出的东西（PCB 内走线）。
- 天线三处置：屏蔽（屏蔽层是法拉第笼的延伸，须低感 bonding；产品无笼时接到逻辑地）、出口低通滤波（须覆盖 30MHz-1GHz → 只能靠极低感电容，最佳是 PCB 平面构成的 patch 电容；勿把 EMI 频段内的有用信号如 USB 一并滤坏）、法拉第笼。

**7.4-7.6 法拉第笼、"地"的辨析、散热（p134-136）**
- 笼对 EMI 是反射不是吸收。逻辑地与笼只允许一处连接：多点连接会把地网络上的电压梯度印到笼上，使其变成天线——这就是"EMI 从裂缝漏出"的真实机理。例外：背板地平面整体作为笼的一面时可全周 bonding，前提是该平面不载功率、无电压梯度（48V 电源改走信号层空隙，平面专职做传输线搭档）。
- 严禁：插件板上下边缘铜条接卡导轨、把面板接逻辑地、背板专设"chassis ground"层、板边镀铜（就 EMI 而言）。
- 四种被混称"地"的东西辨析：安全绿线（UL 防触电，与 EMI 无关）、机壳地、逻辑地、模拟地（模拟地应与 ADC 所用逻辑地直连，分开既不改善性能也不改善 EMI，常常更糟）。作者主张 EMI 讨论中弃用"ground"一词，只用 Faraday cage（符号 F）。
- 散热开孔：孔径 ≤1/4 英寸（6.35mm）的孔网/筛网/蜂窝可 containment 至 10GHz（作者实测结论）；筛网/蜂窝须全周 bonding 到笼。

**7.7-7.9 信号与电源进出笼（p136-142）**
- 光纤进出最省事（无导电通路）；屏蔽缆：屏蔽层接连接器壳 → 壳接笼，勿接逻辑地。
- 10Base2 类要求屏蔽层对笼 1700VDC 隔离（无 DC 连接）：分立电容无法兼顾耐压与全频段低感 → 用 PCB 平面做平行板电容（图 7.6：板端 1 英寸区域四层全部割开，外两层铺铜接面板螺钉为极板A（笼侧），内两层分割出极板B接同轴屏蔽，约 370pF/线，8mil 介质耐压 >8000V，外层 80mil 隔离槽）；修复前后发射谱对比显著（图 7.5/7.7）。分立方案失败根源 = 寄生电感。
- UTP 以太网：中心抽头变压器，平面电容从中心抽头接笼泄放共模噪声（图 7.9）。
- 未屏蔽控制线（风扇、键鼠）：出口处信号层 patch 铜皮对地平面构成低通滤波（图 7.8，太比特路由器风扇线实例）。
- 传导 EMI（150kHz-30MHz）用常规分立 LC 滤波即可；48V 电信系统在每模块入口装滤波模块，勿让潜在 EMI 有机会离开模块。
- 机笼六面构成：卡笼两侧板 + 背板地平面（板边镀铜条 bonding 到法兰）+ 上下蜂窝 + 面板 EMI 衬垫（编织网泡沫或簧片）。7kW 太比特路由器按此一次通过 EMI。
- 跨箱屏蔽缆注意：两端地电位差（数伏 AC 常见）会驱使大电流流入屏蔽层 → 一端 DC bonding、另一端平面电容 AC bonding（370pF 在 30MHz 低阻、工频高阻，恰好满足两头），或两端均 AC 连接但都须极低感。

**7.10-7.12 其它笼形式、逻辑地接笼位置、EMI 能量来源（p142-145）**
- 手机：塑料壳内真空镀金属膜并接逻辑地；低成本盒子：冲压金属壳；打印机类无法加笼 → 扩谱时钟。
- 逻辑地接笼的位置：选在未屏蔽线出口一侧（让驱动器与笼同电位），且只接一处；不允许 DC 连接时用平面电容做 AC 连接。整排 RJ-45 壳全接笼可行，前提是地平面完整无切割；切勿在输出变压器下切地平面。
- EMI 能量来源的颠覆性结论：不是时钟。PCMCIA 双速网卡（33MHz 时钟）发射谱中无任何时钟谐波；能量来自旁路不足造成的 Vcc 纹波。>100MHz 的开关电流只能由平面电容供给（引 Hubing 论文）；该卡把信号层填铜使平面电容从 500pF 提到 4100pF 后即通过 EMI——没有其它办法能压到限值内。
- 机理链：CMOS 输出接逻辑 1 时相当于短接到 Vdd，Vdd 纹波沿这些线出板辐射。5V CMOS 驱动 12 英寸线的开关电流谱含 85MHz-900MHz 分量，与时钟谐波无关；谱形由电流梯形波（即边沿速率与线长）决定 → 器件快慢批、改线长都会改变谱线。这也是整改前后谱"对不上号"的原因，以及标准要求 6dB 裕量的原因（无法保证送测样机是最差个体）。

**7.13-7.16 传导 EMI、扩谱时钟、无效规则、建模（p145-148）**
- 扩谱时钟：逐周期调制时钟展宽频谱，要求时钟周期内有移动边沿的余量；适合打印机等无法加笼的产品。
- 已被实验证伪的 EMI 规则清单（p146-147）：直角走线致 EMI、外层走线致 EMI、跨割缝致 EMI、电源引脚磁珠、ASIC 下磁珠+隔离岛（剥夺其平面电容访问权，高概率高 EMI+逻辑失效）、20H 规则（实测板缘几乎无可检测辐射，内缩反而略糟）、分割地平面（把板变成偶极天线）、逻辑地多点接机壳、λ/20 间隔接机壳、旁路电容直接接 IC 电源引脚（正确做法见 Vol.1：先接到平面）、板边镀铜、板边地过孔排、edge guard ring（真实用途是防静电，与 EMI 无关）、插件板装到"机壳地"背板上。
- EMI 预测建模（对整机 3D 全频段仿真）远超现有与可预见工具的能力；务实做法 = 把电源系统与传输线环境做好，同时消灭源与天线。
- 合规（p148）：FCC Rule 15 Class A/B 与欧盟 EN 55022（CISPR A/B）为两大体系，规则相似但不相同；荣誉制+抽查重罚（作者前东家被按每台 $10,000 罚款）；建议项目组配置专职合规人员（含 RoHS、安全等）。

**7.18-7.19 UTP 为何不辐射、跨箱分布式系统（p148-151）**
- UTP 不辐射的本质 = 两线紧绞 + 等幅反相信号 → 数倍于线距之外两场抵消为零。关键不是"差分"这个名分，而是等幅反相 + 小间距（空间中相距远的等反相双线仍会泄漏）。
- 对内失配 < 最小位周期的 2.5% 则无可检测 EMI：2.4Gb/s 位周期 416ps ≈ PCB 中 2.4 英寸（6.1cm）→ 匹配到 60mil（1.5mm）即可，属易满足的工程指标。
- 电磁双向性推论：UTP 不对外辐射 ⟺ 外界也难以在差分上感应干扰（外界只能感应共模，由差分接收器抑制）。
- 无行间屏蔽的高密度差分连接器（如 FCI AirMax VS）正是利用场抵消：前提是两线同时同相翻转，一旦错位就有短时不抵消窗口 → 串扰进邻对。因此驱动器到连接器一段必须紧长度匹配（3D 模型仿真结论：带隔板连接器 2.4Gb/s 下 60mil 足够）；出连接器后按 8.3 的计算容差。
- 差分对长度匹配不是越紧越好（见第8章迷思4），但"到连接器为止"的段是硬约束。

**对本项目的启示**
- 项目的"回流地孔检查/缝合孔"定位应与书中结论对齐：缝合孔服务于接地连续与跨层回流（正当），但不应在文档中宣称"板边过孔排/guard ring 用于 EMI"——那正是被证伪的规则（p146-147）。
- AI 无头接口可输出 EMI 导向建议：电源纹波抑制（平面电容/填铜估算）、屏蔽缆 AC bonding 的平面电容需求（约 370pF、8mil 介质）等，都是可从板图直接推导的量。
- 差分对邻线串扰检查应按差模耦合解读：靠近差分对的攻击线在两根线上耦合量差 10 个百分点量级（12% vs 1-2%），差值直接进信号，不能按"共模抵消"豁免。

### 8. 第8章 GB/s 及以上信令（p152-171）

**8.1-8.2 差分信令机理（p152-155）**
- 130nm 及以下工艺使 >1Gb/s 数据流轻易可得；单端 LVCMOS 在高速率难稳定（固定 Vref 比较、地偏移、跨板跨箱），笔记本屏线铰链无回流路径即典型困境 → 高速率几乎全部差分（Infiniband/PCIe/XAUI/LVDS/USB/SATA/Next-DDR2 等）。
- LVDS 机理：驱动端 H 树开关夹在两个 4mA 电流源之间浮动（容忍地偏移）；接收端是电流开关（被误称"差分对"），CMOS 只需 50mV 差即可完全切换；50Ω 线 + 50Ω 端接 → 单端 200mV、差摆 400mV（LVDS 标准）。
- "100Ω 差分阻抗"的真相：要求是两根 50Ω 线各自 50Ω 端接到 Vref；Vref 净电流为零故常省略连接，看似对间 100Ω。2.4Gb/s 及以上时边沿错位期间需要瞬态补充电流 → 两端接中点接约 10pF 到地以保住边沿。
- 差分路径 = 交叉检测器：接收器在两波形交叉点判定逻辑状态。设计规则应聚焦"保住交叉"（等长、等阻抗、把交叉保持在线性段内）。

**8.3 差分信令四大迷思（p156-160）**
1. 并行走线提供共模噪声抑制——错。攻击线距 5mil 时：近端线耦合 12%，远端线仅 1%（broadside）/2%（side-by-side）→ 差值是差模耦合，直接进信号。PCB 中平面参与场分布，永远做不到空间中那种等场强共模。broadside 另有层对位难题 → 不应使用。
2. 紧耦合有益——错。紧耦合 = 高串扰；且为维持 100Ω 差分必须减线宽 → 皮肤效应损耗上升（5mil/5mil 紧耦单线 70.7Ω，10mil/15mil 松耦单线 54Ω）。更危险的是紧耦对进入 1mm 间距 BGA 扇出被迫拉开时，差分阻抗跳到约 140Ω（2×70.7）→ 大反射。处方：选一个"几乎互不降低阻抗"的最小间距（如 10/15 松耦例），并保证对内永不低于它。
3. 一根线的回流走另一根——错。约 2% 走对内，主体回流走各自下方平面并紧贴走线（引 Johnson & Graham 的电流密度结果）；开关瞬态电流用于充放对地寄生电容。
4. 过严长度匹配有益——错。LVDS（笔记本用途）2 英寸失配仍可工作，工程师却常要求 100mil 以内，无谓增加布线难度。容差 = 最快到达边沿的时间换算成长度：LVDS 400ps → 约 2.4 英寸；2.4Gb/s → 300mil。
- 补充规则：两线分走 GND 与 Vdd 平面时，Vdd 纹波会成为差模噪声 → 两线走同一平面（纹波变共模）或把纹波压进容差。两线允许不同层、允许各自穿 BGA 引脚场，只需同阻抗、同长度、差模噪声在预算内（噪声预算 + 2D 场求解器定间距，进布线规则）。

**8.4 速率升级实验：5.2Gb/s 链路（p160-165）**
- 模型：超算机架间链路 = 8" FR408 带状线 ×2（5mil 线，Er=3.8，损耗 0.015，50Ω）+ 4 米 Infiniband 缆（损耗 0.0005，Er=1.8）；4 个布线过孔各 0.65pF；用 4 端口网络分析仪实测验证仿真模型（图 8.11，吻合良好）。
- 眼图方法：伪随机码流按单个位周期叠加显示，中心六边形 = 幅度/时间容限，越开越好。
- 逐级提速：100MB/s 时边沿 <100ps（为 5.2Gb/s 预留）虽有滚降与反射但眼全开；1GB/s 时反射叠加+损耗压幅，眼刚好够开；2.4GB/s 时幅度不达标+抖动，主因 = 介质损耗+皮肤效应，过孔反射开始侵蚀抖动；4.8GB/s 时全要素下信号远不达标。
- 关键结论：≤2.4Gb/s 过孔不构成任何问题；>2.4Gb/s 过孔寄生电容反射成为链路速率/长度的限制因素。压接连接器孔（26mil 直径、250mil 长，约 2pF）影响更明显，但该速率下仍可用预加重补回。
- 逐项消融（关掉损耗/关掉过孔电容）定位劣化源的方法，值得借鉴为仿真器设计模式。

**8.5-8.6 预加重与后均衡（p166-167）**
- 预加重 = 去加重：同一过程的两种记账方式（翻转后首比特加能，或以加能后为基准衰减后续比特），结果相同。15% 预加重即可救回 5.2Gb/s 链路的幅度与抖动。
- 不能直接全程用高幅度：无损耗短路径会接收端过驱 → 抖动与误码。
- 后均衡（接收端高通反向补偿）偶用于 >6Gb/s；缺点 = 先全频段衰减再放大 → 噪声一并放大、SNR 劣化、占硅面积，是最后手段。

**8.7-8.8 低损材料判据、皮肤/介质损耗取舍（p167-168）**
- 没有安全的 rule-of-thumb 判断"何时需要低损材料"；唯一可靠方法 = 全路径仿真（实际连接器+驱动/接收模型+叠层）。
- 33 英寸路径 2.5GHz（≈5Mb/s 段）灵敏度分析：线宽 5→10mil（2:1）仅改善约 1dB；FR-4→Nelco 4000-13 改善 2dB；→Nelco 4000-13SI / Isola IS620 改善约 4dB。
- 结论：超过 5mil 的走线宽度基本无必要（甚至 6.125Gb/s）；优先投低损材料。低损材料允许细线 → 达到 50Ω 所需介质更薄 → 背板更薄 → 压接孔寄生电容更小，形成正反馈。

**8.9-8.11 连接器长度匹配、差分端接、AC 耦合（p168-170）**
- 长度匹配分段执行：驱动器→连接器段紧匹配（防连接器处场抵消失效），出连接器后按 8.3 计算容差。
- 差分并联端接取 110Ω（= 50Ω 系统 55Ω 的对间值），理由同 6.3：落在阻抗容差高端，杜绝下冲型反射。
- AC 耦合：0402 封装 0.01uF，内层走线经 12mil 钻孔安装；1MHz-6GHz 实测 DC 耦合 vs AC 耦合路径损耗到 3GHz 无可检测差异，以上差异也轻微 → 至少到 9.6Gb/s，AC 耦合不是显著劣化源。

**对本项目的启示**
- 差分规则引擎应默认松耦合：引入"最小耦合间距"参数（互降阻抗 <1%），扇出区允许对内分离，阻抗检查按"两根 50Ω"而非"耦合后 100Ω"建模——阻抗估算器可直接按单线口径输出。
- 长度匹配容差公式化：容差 = min(位周期×2.5%，最快边沿时间×传播速度)；到连接器段另设紧档（默认按 60mil@2.4Gb/s 当量缩放）。
- RMST/差分对布线允许"异层换位"：只要两线同长同阻抗，这与书中"不必同层"结论一致，可显著降低 BGA 扇出难度。

### 9. 第9章 仿真与仿真器（p171-178）

- 虚拟样机流程（图 9.1）：原理图 → 布局规划（含热分析）→ 逻辑仿真/仿真 → 时序仿真 → SI 分析（含电源平面仿真）→ PCB 布线 → 布后 SI/时序检查 → Gerber 数据检查 → 制造输出；实际是工具间多环迭代而非线性流。
- 论断：DVT（样机验证）比不测还糟——通过 DVT 造成"设计已稳定"的错觉，却覆盖不了量产器件速度散布。
- 每工具一个库、库间无链路，新器件须逐工具建条目；库管理是仿真成功的核心，必须由技术人员主理（p172 边栏）。
- 原理图工具两项硬要求：为每个 net 提供 class 字段（挂技术表，控制布线行为）+ 支持逐 net 录入时序信息。
- SI 工具价值最大的两个时点：第一张原理图之前（验证设计规则与器件组合的可行性）和布线开始前（验证候选拓扑的时序与信号质量）；布线过程中分析困难，布完再分析="马跑了才关厩门"，通常不如重来。
- I/O 模型：SPICE 晶体管级首选（含封装寄生与相邻驱动互作用，但厂商不愿提供）；IBIS 行为模型（V/I 曲线时间基准）为替代——限制：封装寄生不准、无相邻互作用、不能模拟预加重；对绝大多数仿真精度足够。
- 无源模型分档：简单 TL 模型（Z+长度+速度，够做端接计算）→ 2D 截面模型（需串扰/损耗时，均匀截面+长度即可精确定义）→ 3D 模型（连接器、封装）→ S 参数黑盒（插损+相移、反射 vs 频率；来源为 VNA 实测或 3D 求解器）。
- 工具清单（2006 年时点，仅列类目）：SI——ADS（2.5D）、Allegro PCB SI、HFSS（3D）、HyperLynx LineSim/BoardSim、ICX、Pspice/Hspice；电源分配——Delta I、Plane Builder、Speed 2000、SI Wave；时序——ICX、Primetime；逻辑仿真/仿真——Xtreme/Palladium、Vstation Pro、Hammer、Chipit；布线——Specctra/CCR、Veribest PCB、PCAD；CAM/Gerber 检查——CAM350、Gerbtool 等（通常在板厂前端工程部，也可前置到设计部门收尾）。

**对本项目的启示**
- pcb-autorouter 的架构恰是图 9.1 的微缩版：net class 规则 → 布局（退火）→ 布线（A*/PathFinder）→ DRC/Gerber。书中强调的"规则在布线前成形、布后只做检查"应固化为工具流水线次序，而不是布线后补算 SI。
- "布后检查 + Gerber 检查"两个收尾环节对应项目已有的 DRC+嘉立创 DFM 与 Gerber 导出；可对照 9.10 补足 Gerber 级检查项（间距、层间对准、网表一致性）。
- 库概念对应项目的器件/规则预设：单一代码库内保证规则参数与封装数据一致即可，书中"多工具多库不同步"的坑在纯 JS 单体里天然规避。

### 10. 第10章 IC 封装设计（p178-186，本段未完，止于 10.5 表 10.1）

**10.1-10.2 概况与封装演进（p178-181）**
- CMOS 功耗集中在翻转时刻（idle 只有泄漏）：芯片漏电流 mA 级而高活动负载电流可达数十 A；高端芯片数千封装引脚、信号引脚 >1000，大量同时翻转 → 数十安培、亚纳秒边沿的 I/O 电流且持续数 ns（长线 + DC 端接），与片内几百 ps 的时钟尖峰性质不同。
- 封装演进：1964 IBM ECL 小罐（100mW、亚 ns）→ 60 年代中期 DIP（16 脚）→ 70 年代初 QFP（Amdahl 84 脚、100 ECL 门、4W 带散热柱）→ BGA（EIT HyperBGA 2092 球）→ 陶瓷柱栅阵列（1924 脚）。
- 陶瓷封装：粘土片冲孔+丝印导电浆料叠烧，烧结收缩 17% 须预先放大图形；Er≈10（高电容、信号低速）、丝印导体偏阻性 → 长线衰减；顶部 flip-chip + 底部 90/10 高铅球，球滚动释放与 PCB 的 CTE 失配。有机封装 = 小型多层 PCB（1/2oz 铜，环氧玻纤/Teflon/聚酰亚胺积层），Er≈4 + 铜导体 → 高速信号质量与电源压降俱佳；材料 CTE 与 PCB 相近。
- 互连：wire bond 每根几 nH 电感，限制极快 I/O 与电源；flip chip（IBM 60 年代首创）用 97/3 高铅球（熔点高于组装共晶焊料），每球约 50pH，可覆盖整个芯片面，回路电阻电感都更小。

**10.3 案例研究：三种封装同一信号（p181-182）**
- Caspian 26 层线卡（12 信号 + 12 电源/地 + 2 表面 pad），SPI-4.1 64bit@200MHz HSTL 串行端接源同步总线；在接收芯片 BGA 下过孔上用 4GHz 示波器测量。
- 实测对比：Xilinx Virtex-2 Pro（FF1517）时钟抖动 1.6ns、数据上约 800mV Vddq/地弹；Xilinx Virtex-4 改进封装后抖动 97ps；IBM ASIC HyperBGA（1657 球）同样良好。
- 根因：封装内电源分配差 → 每个时钟沿核电压跌落（幅度随逻辑活动变化）→ 时钟树延迟波动 → 抖动（源同步无 PLL 也不可救）；地弹另因信号引脚回流路径与 Vddq 配电不足。（该分析促使 Xilinx 为 Virtex-4 成立封装开发团队。）

**10.4 封装要求（p183-184）**
- 机械/热应力：有铅共晶 183°C 熔点、回流峰值 220°C；RoHS 无铅 SAC（95.5Sn/3.8Ag/0.5Cu）218°C 熔点、峰值 260°C。
- 热循环：芯片活动性造成 ~10°C 的百万次小循环 + 环境 0-55°C（电信）+ 结温至 100°C；铝互连电迁移概率 ∝ T(°K)^4，>100°C 结温应避免；CMOS 驱动强度随温度每 +1°C 降约 0.2%。
- 散热分档：2W 容易；5-10W 可靠 PCB 铜平面散热（热路径合理时）；25-50W 需散热器+几百 lfm 风速；>100W 需热管/液冷。
- 核电源：>50 万 DFF 由同一时钟树驱动 → 几百安培、几百 ps 宽的核电流尖峰；90nm 核压 ~1.2V、50W 芯片平均电流 42A → 电源分配阻抗须在全频段极低。
- 单端 I/O（Vddq 通常 1.8V）：50Ω 线半幅驱动即 0.9V/18mA 每驱动器，100bit 总线 = 1.8A 数百 ps；物理定律要求回流等量经封装电源引脚进入芯片 → 封装感抗/阻抗大 = 地弹耦合进静默线。片上/封装去耦救不了单端 Vddq（回流等于驱动电流，无法就地消除），必须极低感配电。差分信号两引脚等量反向电流 → 封装电源引脚净回流为零，天然优势。

**10.5 核负载电流估算（p184-186，未完）**
- ECL 恒流易算（SPICE 逐单元+表格求和）；CMOS 只在翻转时耗电，任一时刻活动门仅约 1%，唯一每个时钟周期都全动的是时钟树 → 按活动因子分档用电子表格汇总。
- 表 10.1 案例：0.13um CMOS、约 1.5 亿晶体管（半数在 SRAM）、>55 万 DFF、核 1.5V@500MHz；HSPICE 逐单元仿真（DFF 典型负载 100fF）。结果：idle 态每个时钟上升沿耗电 18.5nC，考虑 300ps 时钟偏移（正态分布）→ 电流脉冲半宽 150ps、峰值 123A；重载 32.54nC → 峰值 217A；2ns 周期对应平均功耗 idle 13.9W / 重载 24.4W（尚未计入逻辑门与 SRAM 翻转）。

**对本项目的启示**
- 表 10.1 的"电荷法"（逐单元电荷 × 活动因子求和 → 除以脉宽得峰值电流）是可移植算法：载流计算器可加"芯片核峰值电流估算"入口，为 IR-drop/powerDrop 与去耦检查提供输入。
- 单端 Vddq 回流必须经封装引脚的结论，再次支撑项目把"电源引脚/地引脚回流路径"作为检查项；差分对的地弹豁免可直接写进检查规则。

## 可操作改进建议

1. 【DRC 新增平面完整性检查】（p131-132）检测电源/地层上过孔隔离盘重叠导致的铜 web 断裂；web 最小宽度按铜厚校核（0.5oz ≥3mil，1oz ≥6mil），布线阶段即以过孔最小间距规则预防。
2. 【换层策略校准】（p126-130）布线器不强制"换层必伴随地过孔"（实验证明无差异）；仅当板型 ≤4 层或旁路信息缺失时提示"避免跨平面割缝、单端同层起止"。回流地孔检查保留为可选项并注明适用场景。
3. 【端接推荐公式】（p130-131, p169-170）阻抗估算器/规则输出附加：并联端接 = Znom×1.1（差分对跨接 110Ω）；串联端接 Rst ≤ Znom×0.9 − Zout。
4. 【差分松耦合默认】（p156-159）规则引擎引入"最小耦合间距"（互降阻抗 <1%），默认按松耦合建模（单线口径 50Ω 检查）；BGA 扇出区显式允许对内分离，禁止紧耦合对进入扇出区（防差分阻抗跳变至 ~140Ω）。
5. 【差分长度匹配分段】（p151, p160）容差 = min(位周期×2.5%, 最快边沿时间×传播速度)；"驱动器→连接器"段单独收紧（默认 60mil@2.4Gb/s 当量），出连接器后用计算容差。
6. 【低损材料预设】（p167-168）层叠/阻抗估算器材料库增加 Nelco 4000-13、Nelco 4000-13SI、Isola IS620 等损耗参数；高速检查输出建议"线宽 >5mil 无必要，优先低损介质"。
7. 【过孔寄生分级警告】（p162-165）对 >2.4Gb/s 等级网络输出过孔寄生电容估计（普通布线孔 ~0.65pF、压接连接器孔 ~2pF）与残余桩长提示；≤2.4Gb/s 降级为信息级。
8. 【电源目标阻抗判据】（p128-129, p144）载流/powerDrop 增加目标阻抗检查：开关沿频段内每路电源 <10-20mΩ；EMI 建议中输出"信号层填铜提升平面电容"（案例 500pF→4100pF 即通过 EMI）。
9. 【net class 规则体系】（p172-173）按图 9.1 与 9.2 节，AI 无头接口的规则输入统一为 net class（线宽/间距/层限制/长度/走线方向），布后 DRC 与 Gerber 检查逐类核对并输出违规清单。
10. 【芯片峰值电流估算入口】（p184-186）载流计算器增加"电荷法"峰值电流估算（时钟树 + DFF 数量 × 活动因子 × 单元电荷，脉宽取时钟偏移/2），为去耦与 IR-drop 检查供数。
11. 【检查项用途澄清】（p146-147）文档中将板边过孔排、guard ring 从"EMI 手段"中除名（已证伪）；缝合孔/回流地孔只声明其接地连续与回流用途，避免向用户传播无效规则。
12. 【差分串扰解读】（p149-150, p156-157）3W/串扰扫描对差分对的邻线报告按"差模耦合 = 两线耦合量之差"解读并给出警示，禁止以"共模抵消"为由豁免靠近差分对的攻击线。
