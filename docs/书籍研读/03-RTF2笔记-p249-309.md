## 分章笔记

### 附录2 电源系统测试（p254-p264）

作者给出判定电源子系统设计合格的三类实测：
1. 裸板平行平面电容测量；
2. 装上全部旁路电容后，电源系统阻抗-频率曲线；
3. 整机最坏工况下的电源纹波实测。

**平面电容测量（p254）**
- 每个电源电压各测一次，低频测试，用普通电容表即可，接入点任意。
- 平面电容主要支撑单端传输线（如内存总线）的开关电流，频率范围约 100MHz-1GHz。
- 两个必须预留的误差源：(1) 层压板介电常数随频率升高而下降，直流/低频测得的电容值会大于高频实际值，设计时应按 DC 到 1GHz 的 Er 变化量放大；(2) 平面间距（尤其半固化片压合）公差是最大变量。综合下来，平面电容设计值应比开关事件所需至少大 50%。

**阻抗-频率测量（p254-p255）**
- 被测阻抗远小于 1Ω，频段 10kHz-1GHz；被测结构 = 平面对电容 + 全部旁路电容 + 离散电容寄生电感与平面电容的相互作用，因此需要一块只装旁路电容的专用测试板。
- 最省钱的仪器方案：频谱仪 + 跟踪信号源。50Ω 同轴馈入平面对，因被测阻抗远小于 50Ω，注入电流近似恒流，频谱仪测得的电压正比于该频率下的阻抗（也可用网络分析仪）。
- 25Ω 定标法（引自 Vol.1 第 34 章）：两根 50Ω 电缆接到同一平面对时输入端等效 25Ω；把跟踪源直连频谱仪输入时的读数定标为 25Ω 并置于屏幕顶部，此后每低 20dB 阻抗低一个数量级：-20dB=2.5Ω、-40dB=0.25Ω、-60dB=25mΩ、-80dB=2.5mΩ。
- 仪器参数（以 Agilent E4401B + 跟踪源为例，p255-p258 逐步截图演示设置）：起始 10kHz、终止 1GHz、分辨率带宽 3kHz、视频带宽 3kHz、衰减 10dB、参考电平 0dBm、横轴对数、扫描 2.765s、自动扫描耦合选 SR（激励-响应模式而非 SA）、源幅度 0dBm 并打开源；测试前先做电缆直连校准（=25Ω）。

**测试接入与探头（p260-p261）**
- 接入必须把杂散电感降到最低：最好在制造时给每个电源平面预留两对低感测试点。探头自制：短段 SR141 半刚同轴，一端 SMA 公头，另一端用硬线（作者用缝衣针）作触针。
- 测试点焊盘规格（图12）：捕获焊盘 44mil 方/圆、隔离盘 50mil、钻孔 30mil；方形焊盘接电压平面、圆形接地；平面上禁止用热焊盘（thermal relief）连接；丝印在方盘旁标注电压名；每个电压平面放两处、相距至少 1 英寸。
- 无预留测试点时：拆掉两颗 0603 电容，把同轴直接焊在其焊盘上；用 BNC 转接头方便插拔。两个接线点距离要求很宽松——只要两条路径不共享同一段电感即可。

**结果解读与最坏纹波（p262-p263）**
- 数据可 CSV 导出进 Excel 画阻抗曲线。实例：某轨 70MHz 处阻抗接近 0.5Ω，过高，会造成间歇性失效；成因是旁路电容的寄生电感与该电源轨的平面电容发生谐振、出现阻抗峰。
- 纹波测试在满装配、可运行的整板上做。逻辑板两种最坏情形：(1) 最宽的单端总线全部同时从 0 翻到 1；(2) 处理器从"待机"切到"满载"。bring-up 代码里要写好反复触发这两种情形的程序，同时用带宽足够的示波器测每路电源纹波。

**为什么要求全频段低阻抗（p263-p264）**
- 设计良好的电源子系统应从 DC 到最高有用信号频率分量（约 1GHz）都保持低阻抗，即使负载本身用不到这么高的频率。目的是让电源平面与地平面之间对任何频率的信号都呈低阻，走在电源平面上方的信号不会感到过大的纹波耦合——这样布线可以走任意平面层，不必强制"只在接地平面上方走线"。
- 附：测试电缆/转接头采购清单（Pasternack，SMA-BNC 转接、RG188A/U 50Ω 同轴等）。

**对本项目的启示**
- powerDrop 与载流计算器偏 DC/热视角，本节补上频域视角：电源报告可增加"平面电容估算（DC 值 + ≥50% 裕量）"与"电容 ESL × 平面 C 谐振峰扫描"。
- 层分配器不必把电源平面一律划为布线禁区，可按平面阻抗给评分。
- 热焊盘策略对"电源测试点"是例外：必须实连。

### 附录3 通用 PCB 制造规范（p265-p288）

一份可当模板的完整制造规范（Rev B，2006-07-31）。要点按主题归纳：

**流程与质量条款（p269-p270）**
- 文件优先级：采购单指令 > 制造图/CAD 数据 > 本规范 > 引用文件。厂商须 ISO 9002 以上、在 AML 名单内、接受定期审核。
- 首件检验：按 ANSI/ASQC Z1.4-1993 General Level I 抽样，11 项检验（尺寸、弓扭、Hi-Pot、可焊性、外观按 IPC-6012 3.3.x、金相切片按 IPC-TM-650 2.1.1（不得用 coupon、不得从待交付阵列上取样）、离子污染、TDR 阻抗报告、100% 电测证明、UL 证明等），报告与样本保存 ≥1 年；首件未获批不得批量出货。量产按 S-1 抽样出产线测试报告。

**CAD 数据管控（p272-p273）**
- 制造前必须做 Gerber 对 IPC-D-356 网表的比对，不一致必须先解决；每层按 README 参数跑 DRC，冲突在开工前澄清。
- 允许厂商自行改动仅限：工艺补偿、breakaway 区标记、文字与可焊面保持 0.006" 间隙、载具区补铜（距成品轮廓 0.015-0.050"）、不得删除堆叠条纹；厂内不得加 thieving。
- 泪滴条款（5.2.2）：厂商原则上不加泪滴，确需补时不得造成开短路且必须通报——言下之意设计端应自己做好泪滴。

**材料与叠层（p273-p274）**
- FR-4 按 IPC-4101；最小介质厚度 0.002"；Tg ≥170°C（TMA 法）；默认内外层均 0.5oz 铜箔；Er 按制造图。
- 全板玻纤经纬方向一致；不得有起泡/分层/白斑/织纹显露/粉圈；层间对位 ±5mil；板边保留堆叠条纹验证层序。
- 信号层/平面开口处至少 2 布布纹、树脂含量 ≥55%；信号层玻璃布仅限 106/1080/2116/3313 四种（提高钻孔精度与均匀性）；相邻平面之间允许单布、树脂 ≥42%。

**机械与导体公差（p274-p275）**
- 工具孔位置 ±3mil、孔径 +2/-1mil 且必须一次钻成（不允许二次钻）；一般特征位置 ±5mil；导体到板边 ≥20mil；非镀孔/槽 ±5mil；基准点圆度 0.6mil 内、同板多点互差 ≤1mil。
- 线宽/线距公差取较小者：相对 Gerber +20%，或 ±1mil（½oz 铜箔）/±2mil（1oz 铜箔）；边缘粗糙度 ≤0.5mil 峰谷/每 0.5 英寸；SMT 焊盘（≥25mil 间距）±1.4mil、（<25mil 间距）±1.0mil；镀孔 ±3mil、镀槽 ±5mil。
- 环形盘按 IPC-6012 Class 3；无走线进入焊盘时允许孔壁与焊盘相切；任一功能孔出现 breakout 即单板拒收，多板 breakout 可整批拒收。弓扭 ≤0.007 in/in；胶渣 100× 切片下不可见；钉头 ≤2 倍铜箔厚、负蚀刻 ≤5mil。
- 修补限制：内层禁补；外层仅允许焊接法补 >6mil 线宽的线，每面 ≤2 处、全板 ≤3 处；绿油修补每面 ≤3 处、每处 ≤1 英寸或 0.125 平方英寸。离子污染 ≤6.45μg NaCl 当量/平方英寸；可焊性按 J-STD-003 但浸锡 20s、全润湿 ≥95%。

**电镀与表面处理（p277-p279）**
- 总铜厚 ≥1mil、蚀刻因子 1:1、延伸率 ≥10%；孔铜平均 ≥1mil，每孔 ≤1 个且 ≤5% 孔壁面积的空洞，夹杂致铜厚减少 ≤20% 且不得两侧同面，内层与孔壁分离=拒收。
- HASL：SN60/SN63、最多 2 次；孔内 0.1-3.5mil；≥25mil 间距焊盘 0.1-1.5mil、<25mil 间距 0.1-1.0mil 且同阵列互差 ≤0.6mil（焊盘中心两轴各 6 点测量）。
- 金手指：镍 200μin（+300/-100）；金纯度 ≥99.7%、努氏硬度 140-200、平均 ≥30μin 且单点 ≥20μin、粗糙度 ≤20μin CLA、分界线露铜 ≤5mil、镀瘤不得使指间距缩小 20% 以上。
- ENIG：镍平均 ≥100μin（单点 ≥80）；金平均 4μin（3-10μin）。OSP 仅指定两种（ENTEK CU-106A 0.35±0.05μm、Ronacoat），OSP 后不得烘烤、3 个月内出货。板面电镀金镍 150-600μin + 金 5-15μin（焊点金体积目标 <5%），可选钯 5-15μin，插座接触区可二次选镀 ≥20μin。

**绿油与字符（p280-p282）**
- 默认绿色；指定四家牌号（Electra、Enthone×2、Taiyo）；只允许一层绿油；铜面上固化厚度 0.4-1.2mil；测试盘、基准点、SMT 焊盘、工具孔必须开窗；露铜特征间绿油桥 ≥4mil。
- 堵孔（≤0.020" 过孔，终镀后用绿油堵，盖帽与主绿油搭接 >4mil、增厚 ≤1mil、不得破裂）、盖掩（桶内进油可接受，破洞率 ≤5%）两种工艺；BGA 防锡流入的替代法 via damming：第二道绿油只在 BGA 焊盘外画环，环宽等于焊盘到过孔那段走线长。
- 字符最厚 1mil、OSP 前印、不得上 SMT/PTH 焊盘与金手指、耐 288°C/30s；激光字符（Hysol 50-202BC）固化 0.7-1.1mil；对位以工具孔为基准 ≤10mil。

**电测（p282-p283）**
- 100% 裸板开短路测试（覆盖所有层，用随数据提交的网表），测试电压 ≥40VDC，导通判据 ≤10Ω；禁止 golden board（对照板）法。
- 硬治具双面同测；SMT 焊盘不得用邻近过孔代测；样机或 <50 块的订单允许飞针。Hi-Pot 按 IPC-TM-650 2.5.7 Condition B；绝缘电阻 ≥500MΩ@500VDC。
- 阻抗受控层公差 ±10%；优先在制造图上的阻抗测试线上测，没有才允许用 coupon；测量假设 Er=4.1、边沿 <200ps；按 AQL 抽测且每次读数都把参考阶跃幅度计入；推荐自动采集 + SPC 上下控制限；要求把阻抗结果反馈到前端工程（对合格/不合格板做切片分析闭环）。

**包装运输（p283-p285）与术语表（p286-p287）**
- 板须清洁、干燥、冷却后包装；含 coupon 的阵列不收；外箱 ≤50 磅；单板独立包装、同向摆放，最内包限同一料号/PO/工厂；数量上限按板面积：>60 平方英寸 25 块、20-60 平方英寸 250 块、≤20 平方英寸 360 块、PCMCIA 1200 块；真空包装或热封袋 + 无硫干燥剂/湿度卡；无硫纸箱、禁聚苯乙烯填充。
- 术语表：Tg 的解释值得记住——超过 Tg 后树脂体积膨胀速率远高于铜与玻璃，会给孔铜施加应力导致失效。

**对本项目的启示**
- 这是"交付端"的规则金矿：DRC/DFM 默认容差（边距 20mil、层对位 ±5mil、镀孔 ±3mil、绿油桥 4mil、环盘 Class 3 禁 breakout）、叠层材料约束（Tg、玻璃布、树脂含量）、阻抗 ±10% 与 TDR 条件，都能直接入库。
- Gerber 导出环节应补 IPC-D-356 网表输出，使交付包支持工厂 100% 电测。

## 可操作改进建议（编号 + 页码）

1. （p254）电源平面对电容估算按 DC 值计算并加 ≥50% 裕量（Er 随频率下降 + 半固化片间距公差），用于 powerDrop/电源报告的平面电容输出。
2. （p262）新增 PDS 谐振峰扫描：对每路电源计算旁路电容 ESL 与平面电容合成的阻抗-频率曲线，按 20dB/十倍程定标报出阻抗峰（如 70MHz≈0.5Ω 即间歇失效风险）。
3. （p260）DRC 增加电源测试点检查：平面测试点必须实连（禁热焊盘）、每电压平面两处、间距 ≥1 英寸、方/圆盘区分电源与地并丝印电压名。
4. （p263-264）层分配策略放宽：若电源平面对阻抗足够低，允许信号在电源平面上方走线；层评分不把电源层一律设为禁区。
5. （p263）载流计算器的"最坏工况"档按书中两条定义取值：最宽单端总线同时翻转、处理器待机→满载。
6. （p273-275）DFM 默认容差库补充通用制造值：导体到板边 20mil、层间对位 ±5mil、镀孔 ±3mil、线宽公差 min(+20%, ±1mil@0.5oz)、绿油桥 ≥4mil、弓扭 0.007in/in、Tg ≥170°C。
7. （p275-276）环形盘检查按 IPC-6012 Class 3 并禁止 breakout；布线后处理自动补泪滴（规范允许厂商补救，但设计端自加更可控）。
8. （p272-273, p282-283）Gerber 交付包增加 IPC-D-356 网表输出，支持工厂 100% 电测（≥40VDC、导通 ≤10Ω、禁 golden board）；交付包内注明阻抗测试线位置（优先于 coupon）。
9. （p283）阻抗估算器输出按 ±10% 制造公差给出区间，并在报告中注明 TDR 测量条件（Er=4.1、边沿 <200ps）。
10. （p298-299）焊盘堆栈生成器内置附录 7 公式：按板厚与目标深径比（8:1/10:1）自动算最小钻孔、hole shadow、捕获盘、隔离盘。
11. （p303）过孔深径比分级评分：≤8:1 良好、≤10:1 顶级厂、更高报"手工级不可制造"；布局时优先低 AR 孔。
12. （p297）过孔钻孔直径向标准钻头表对齐（按 0.05/0.1mm 步进取整），避免非标孔。
13. （p300-301）测试点检查增加"全 SMT 板需表贴接地环（Keystone 5016/5018、TP-107 类）"提示与推荐封装。
14. （p273-274）叠层编辑器材料约束：信号层玻璃布仅限 106/1080/2116/3313、信号/平面开口树脂含量 ≥55%（至少 2 布）、平面对之间允许单布 42%。
15. （p293-296）在 docs 建立参考文献页：收录 107 条中的核心书目与 20H/纤维编织 skew/CAF/ENIG 黑垫专题，作为阻抗、串扰、材料参数的论证出处。
