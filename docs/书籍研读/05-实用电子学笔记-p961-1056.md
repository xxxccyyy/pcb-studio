## 分章笔记

### 第15章 电机（p962-975，书页933-946）

**15.1 直流电机基础（p962-963）**
- 直流电机是两引脚器件，常见转速 3000-8000 rpm，典型工作电压 1.5-24V；换向靠反接电源极性。
- 电压低于额定值约 50% 电机停转；超出约 30% 有过热损坏风险。调速最优手段是 PWM 斩波而非线性降压。
- 关键参数"堵转电流（stall current）"：带载后电流可飙升到空载的 10 倍以上，选驱动器件必须按堵转电流设计。扭矩单位 lb/ft、g/cm、oz/in。

**15.2 调速电路（p963-964）**
- 反面教材：用电位器或晶体管线性限流调速——能量全烧成热量，器件熔毁。
- 正确思路与开关电源同源：只发短脉冲，器件不承受持续电流应力。给出三例：UJT弛豫振荡器+SCR；CMOS与非门振荡+功率MOSFET（空出一个与非门输入即得开/停控制端）；555（7、6脚间加二极管进入低占空比模式）+MOSFET。

**15.3 换向与H桥（p964-965）**
- 换向方案三选：DPDT开关、晶体管驱动DPDT继电器、互补达林顿对（TIP102/TIP107）推挽。
- H桥是核心结构（双极型版与MOSFET版各一），两输入端禁止同时有效，否则电源对地短路（直通）。
- 直接买驱动IC更省事：LMD18200（3A、12-55V、内置钳位二极管/短路保护/过热报警输出）、L293D（便宜但电流小、功能少）。

**15.4 RC舵机（p965-967）**
- 三线：电源、地、控制线。内部 = 直流电机 + 减速齿轮 + 电位器反馈 + 控制电路；行程约 180°（或210°），电位器物理限位决定。
- 控制协议：脉宽 1.5ms = 中位；更宽 → 逆时针，更窄 → 顺时针；周期 20-30ms。不同品牌行程对应的脉宽范围不同（1.0-2.0ms 或 1.25-1.75ms）。供电常见 4.8V 或 6.0V。
- 遥控场景：FCC 为航空模型保留 72MHz 频段 11-60 信道（免执照）；持业余无线电执照可用 50MHz；27MHz 频段部分频率地面/航空通用。
- 改装技巧：拆除电位器反馈、用分压电阻"欺骗"控制电路处于中位，舵机即变 360° 连续旋转电机。

**15.5-15.6 步进电机分类（p967-969）**
- 步进 = 数字控制的无刷电机，每个时钟脉冲转一步；分辨率 0.72°-90°/步，通用型常见 15°、30°；可整周旋转，低速大扭矩（打印机送纸、望远镜跟星）。
- 变磁阻式：铁磁转子 + 多线圈对定子，线圈尾端公共接电源，各相线依次接地步进。
- 永磁式三种：
  - 单极（unipolar）：带中心抽头，5线（内部共抽头）或6线（独立抽头）；抽头接电源，两端交替接地反转磁场。
  - 双极（bipolar）：无抽头，每线圈对需一只H桥换极；控制更难但同等体积扭矩更大。
  - 通用（universal）：4独立绕组8线，并联=单极、串联=双极。
- 三种激磁时序：整步；强力步（power stepping，两相同开，扭矩约1.4倍、功耗2倍）；半步（相邻两相同开，转子停在两极之间，步距角减半）。

**15.7 驱动电路（p970-972）**
- 驱动器 = 功率开关 + 保护：输入加TTL缓冲级，防晶体管 c-b 击穿把电机电压灌进逻辑电路；每只开关管并续流二极管吸收线圈感性反冲（单极式反冲可从中抽头两侧泄出，需多加二极管）。
- 集成方案：ULN2003 达林顿阵列（7路、内置保护二极管、TTL兼容）+ 7407 缓冲；MC1414。
- 双极步进必须用H桥；H桥输入端加 XOR 逻辑防止两输入同为高（防直通）。
- H桥IC选型表：L293（1A/绕组、36V）、L298（2A）、LMD18200（3A、内置保护二极管）。

**15.8 环形分配器/translator（p972-974）**
- translator 产生激磁时序：可用 4017 十进制计数器（Q4 接复位改成四相）、4027 双JK触发器 + 4070 XOR（带方向、强力步）、74194 移位寄存器 + 555 时钟 + DPDT 换向开关。
- 经典一体化芯片 SAA1027：内置计数器+译码+驱动，供电 9.5-18V，最大输出 500mA，RX 引脚电阻设定输出级基极电流；M 脚控制方向、R 脚复位、C 脚计数。
- 现代做法：单片机直接生成时序（Arduino 有现成库）。

**15.9 未知步进电机识别（p974-975）**
- 引线数判型：4线=双极；5线=单极共抽头；6线=单极独立抽头；8线=通用。
- 手转轴：转动顺滑无卡顿=变磁阻式；有明显齿感=永磁式。
- 欧姆表解码：同一绕组两端=低阻R；抽头到端=R、端到端=2R；不同绕组间=无穷大。5线型先靠"测谁都得R"找出公共抽头 e，其余靠试接驱动器验证。

**对本项目的启示（第15章）**
- "堵转电流"是载流计算器值得内置的电机负载模型：电机类网络按堵转电流而非额定电流选线宽，并提示用户。
- PWM/开关型负载（电机、H桥）在布线器中的对应规则：大电流开关回路面积最小化、栅极/基极驱动走线尽量短、续流二极管紧贴线圈端——可作为"开关网络"权重的布线启发式。
- 防直通逻辑（H桥两输入互锁）与本项目无关，但"驱动级与逻辑级之间加缓冲隔离、防止电机电源串入逻辑"对应PCB上驱动地与逻辑地的隔离摆放，可写入DRC提示文案。

### 第16章 音频电子学（p976-991，书页947-961）

**16.1 声音三要素（p976-978）**
- 频率：人耳 20Hz-20kHz，最敏感 1-2kHz；强度：随距离平方衰减，用分贝表示 dB = 10·log10(I/I0)，I0 = 1e-12 W/m²，人耳动态范围 0-120dB。
- 音色：基频 + 整数倍谐波（泛音）叠加，复音 = 傅里叶级数 Σ(系数×sin/cos(n·ω0·t))；乐器音色由各谐波强度分布决定。

**16.2-16.3 麦克风及其规格（p979-980）**
- 动圈式：坚固、无需供电、低输出阻抗、频响平滑，PA/录音通用。
- 电容式：两块极板构成"声敏电容"，需外置极化电压 + 低噪声高阻放大器。
- 驻极体式：永久极化塑料膜 + 内置FET放大器，需经 1-10kΩ 电阻馈入 1.5-10V 电源——这是最常用的PCB贴装麦克风。
- 规格：灵敏度（dB，基准声压 1 dyn/cm²）；频响（语音 100-3000Hz 足够，Hi-Fi 需 20-20kHz）；指向性；阻抗分级（<600Ω 低阻、600-10k 中阻、>10k 高阻）。

**16.4 音频放大器（p980-983）**
- 选音频专用运放而非741：高压摆率、高增益带宽积、低失真低噪声。型号清单：NE5532/5534/5535、OP-27、LM833、OPA134/2134/2604、AD842/845/847/797、LT1057/1115、LM4562、HA5112 等。
- 反相放大：增益 = -R2/R1，输入阻抗≈R1；同相放大：增益 = R2/R1+1，输入阻抗极高。
- 单电源偏置三要点：R3=R4（10-100k）把输出直流工作点抬到 +V/2；输入端 C1 交流耦合隔直防饱和；输出端 C3 隔直，容值 C3 = 1/(2π·fC·RL)；旁路电容 RC 滤掉电源噪声防窜入同相端。
- D类（数字）功放原理：三角波与输入比较 → PWM → 互补MOSFET大电流开关 → 低通滤波还原音频。效率极高适合数百瓦级；参考IC：NCP2704、LX1720。
- **PCB相关规则（p983，本区间唯一一条明确PCB布线规则）**：60Hz 哼声一路经电源进入放大器（对策：电源滤波电容尽量加大），另一路通过与板上走线/导线间的互感耦合进来（对策：所有PCB走线和导线尽量短；导线加屏蔽层且屏蔽层接地）。

**16.5-16.6 前置放大与混音（p983-984）**
- 前放：LM358 双运放驻极体前放（R5 控增益）；2N3904/2N3565 单管前放；高阻/低阻动圈麦克各有运放前放电路。
- 混音器 = 求和放大器：各输入经电位器（音量）+ 隔直电容汇入运放反相端叠加。

**16.7 阻抗匹配：从"匹配"到"桥接"（p984-985）**
- 电子管时代讲究最大功率传输（等阻匹配）；晶体管/运放时代改为最大电压传输：负载阻抗 ≥ 10×源阻抗，称"桥接（bridging）"。不遵守时等阻抗直连会损失约 6dB。
- 例外：射频电路仍做真正匹配；传电流信号时源阻抗应大于负载。
- 高阻源接低阻负载的损失公式：dB = 20·log10(RL/(RL+RS))；经验上 ≤6dB 可接受。

**16.8-16.9 扬声器与分频网络（p985-988）**
- 扬声器按标称阻抗当作纯电阻负载处理：换 4Ω 喇叭电流翻倍；2×8Ω 并联 = 4Ω；串联电阻凑阻抗会损害音质，匹配变压器贵且有失真。
- 频段划分：低音单元 <200Hz；中音 500-3000Hz；高音单元更高；全频单元音质逊于三分频系统。
- 无源分频（功放后、喇叭前，便宜、傻瓜化、不可调、吃功率）vs 有源分频（功放前的运放滤波器，信号小易处理、损耗小）。
- 一阶三分频元件公式：C1=1/(2π·f2·Rt)，L1=Rm/(2π·f2)，C2=1/(2π·f1·Rm)，L2=Rw/(2π·f1)（f1、f2 为 -3dB 交叉点，R 为各单元标称阻抗）。实用二分频例（1.8kHz/8Ω）：L=0.57-0.65mH、C=8µF、串阻 2-7Ω。

**16.10-16.12 功放IC与报警器件、杂项电路（p988-990）**
- LM386：4-15V 供电，增益内置 20，1、8脚间加RC网络可提到 200，推 8Ω 小喇叭。LM383：8W/16W 功放，推 4Ω 或 2×8Ω，内置过热关断，必须加散热器否则未到满功率就保护。
- 蜂鸣器类（Sonalert、压缩蜂鸣器、直流蜂鸣器）只管报警不需频响；逻辑电平经1k驱动，音量用100k电位器调。
- 杂项：晶体管对/555/UJT 音调发生器、节拍器、警笛、LM386+驻极体喊话器、741+继电器+JK触发器声控开关。

**对本项目的启示（第16章）**
- p983 的哼声对策直接映射到布线器：模拟小信号网络（麦克风、传感器输入）应设为"短走线优先"权重；并支持"地保护走线（guard trace，即接地屏蔽层）"沿敏感网络伴走——与本项目已有覆铜/地孔能力天然衔接。
- 互感耦合的物理来源（长平行走线）可作为 3W 检查的补充文案：对音频/小信号类网络，除 3W 间距外还应避免与功率/PWM 网络长距离平行。
- 桥接规则（10×）可作为阻抗估算器的输出提示项；D类功放案例再次强化"开关回路最小面积"布线权重。

### 第17章 模块化电子（p992-1000，书页963-971）

**17.1 有IC就别用分立搭（p992-993）**
- 动手设计复杂分立电路前先查有没有现成IC，可同时降成本与器件数；找料用 Octopart。
- IC清单示例：HT9200 DTMF发生、ISD1932 录音、TDA7052/TDA2003 音频功放、L298 双路2A H桥、S202T01F 固态继电器、MAX1551 锂电充电、L297 步进控制器、MAX6958/LM3914/LM3404 LED驱动、DS1302 时钟、24C1024 EEPROM、SST25VF010A SPI Flash。

**17.2 转接板与模块（p992-996）**
- 转接板（breakout）= 把难焊的SMD引脚引到 0.1in 间距，常顺手加去耦电容/稳压/电平转换；模块（module）集成度更高，界线模糊。原型期用模块验证概念，定型后再去掉模块做正式设计。
- **PCB相关论断（p994）**：射频是独立学科，高频下 PCB 布局至关重要、设计不比普通数模简单——所以普遍直接买 RF 模块，整板贴装或插排针。
- RF 模块常识：433/315MHz 收发对（超便宜、速率 ≤8kb/s 常见 2kb/s、开阔地约100码、一般单向收发分离）；蓝牙模块（3.3V 贴片，常叠在电平转换板上变 5V TTL 串口）；XBee/XRF（Digi 插座标准已成事实接口，透明串口透传）；GSM/GPRS 模组（串口AT指令，短信+数据）。
- 音频模块同理：为避开地环路和60Hz哼声，功放/前放/MP3解码等也买模块（如 XMA2012 2×3W D类）。

**17.3 即插即用原型（p997-999）**
- .NET Gadgeteer：主控板 + 传感器/执行模块用线缆拼装，Visual Studio 图形化连线自动生成骨架代码。模块清单覆盖加速度计、GPS、摄像头、CAN、WiFi、电机驱动等约30类。

**17.4 开源硬件（p999-1000）**
- 开源硬件 = 原理图与PCB设计文件公开（多为 EAGLE 格式），任何人可复刻；原创者靠社区声望和咨询支持（halo effect）获益。代表：Arduino、BeagleBoard、MIDIbox、RepRap/Ultimaker/MakerBot、Chumby、Open EEG。

**对本项目的启示（第17章）**
- "高频关键电路不做通用自动布线，改为模块/禁改区"是行业惯例：布线器可提供"预布线锁定区（keepout + locked route）"，把 RF/晶振/天线网络整体保护，等价于书中用成品RF模块绕开RF布局难题。
- 转接板"顺手加去耦电容"的惯例，可变成布局算法规则：在模块/IC电源引脚附近自动放置去耦电容占位。
- "原型用模块、定型去模块"提示工具支持同一板子的双版本BOM/布局导出。

### 附录A 配电与家庭布线（p1002-1007，书页973-978）

> 注意：本附录是市电/强电内容，不是PCB设计。但其接地与负载思想对PCB地网络设计有类比价值，故详细记录。

**A.1 电力配送总览（p1002-1003）**
- 输电链：电厂三相发电机 10kV → 升压 220kV 远距输电 → 一级变电站降至 66/33kV 区域线 → 再降至 16/4kV 局部线 → 杆式变压器降至 240/120V 单相进户；工业侧 480/270V、208/120V、240V 等三相制式。
- 用交流而不用直流：变压器可便捷升降压；高压小电流输电降低 I²R 线损。
- 工业用三相的两大理由：三相电机随相位节律平稳运转；任一时刻至少一对相间有电压，没有单相的"供电空窗"。

**A.2 三相电细节（p1004-1005）**
- Y形接法（4线）：3相+中性线；相电压Vp（相-中）与线电压VL（相-相）满足 VL = √3 × Vp（书印作"约1.73倍"，即矢量合成）；线电流滞后线电压30°；三相负载平衡时中性线电流为零。
- Δ形接法（3线）：无中性线，相电压=线电压；线电流 = √3 × 相电流。
- 常见制式：480/277V Y、208/120V Y、120/240V 单相中心抽头、240V 三相Δ、240/120V 四线Δ——后者存在 187V"stinger leg"野相，商用禁用；误把120V负载接上去会烧毁负载（技术员常见事故）。

**A.3 家庭布线（p1005-1006）**
- 进户三线：A相（黑）、B相（黑）、中性线（白）；相-相 240V、相-中 120V（各地名义值有差异）。
- 主配电盘：经电表接入，主断路器分断，中性线接中性排（neutral bar），地排（ground bar）接接地棒或建筑钢筋。**主盘内中性排与地排相连（合二为一）；子盘内两者严禁相连（中性线悬浮），地线从主盘单独引来**；金属导管可当地线，但计算机、生命支持等关键应用须在导管内另敷专用地线；跨建筑子盘须另打接地棒。
- 120V 回路：单极断路器挂A或B母排，黑线接断路器、白线接中性排、地线接地排并接设备外壳。
- **负载均衡（balancing the load）**：120V 回路应尽量均分到 A、B 两相母排，使主断路器容量最大化。
- 240V 负载：双极断路器跨接 A、B 母排；120/240V 兼容设备用四线电缆（多一根中性线）。
- 安全与合规：动手前拉总闸；对待检回路断路器贴胶带标记；**各地规程不同，施工前咨询当地电气检查员**。

**A.4 各国电压频率（p1006-1007）**
- 美国 120V/60Hz 单相、208/120V 三相；多数国家 230V/50Hz 单相、415V 三相。中国 220V/50Hz、I 型插头。
- 跨国使用设备注意电压与频率双重差异：变压器只解决电压，10Hz 频差对电视/录像机等仍致命。
- 附国家速查表（澳240V、英230V/G型、日100V 50/60Hz 等）。

**对本项目的启示（附录A）**
- **"中性线与地线仅在一点（主盘）相连，子盘分离"**是强电版单点接地法则，与PCB回流设计同构：本项目"回流地孔检查"可引用该思想——每个功能子域的地回流应回到唯一汇聚点，禁止子域间随意搭接地桥形成环路（书中索引亦列"ground loops→noise，p47"，在别章展开）。
- "关键应用在导管内另敷专用地线"对应PCB：关键网络（模拟参考地）应有专用地孔回链，而非借邻近任意铺铜搭桥。
- "A/B相负载均衡"对应多相VRM/双电源布局的负载分配提示，也可写进载流计算器的说明文案（按相均衡以放大总容量）。
- I²R 输电线损与高压输电思路，可作为载流计算器输出"抬电压降流"建议的理论出处。

### 附录B 误差分析（p1008-1011，书页979-982）

- 术语：误差（error/uncertainty）≠ 错误（mistake），计算错误须先修正再谈误差。三大误差来源：①被测量真实波动（如温度改变电阻，须查数据手册温度系数）；②仪器误差（校准、输入阻抗负载效应）；③人为误差（示波器屏读精度仅约5%）。
- 定义：绝对误差Δx、相对误差Δx/x、百分比误差100%·Δx/x；"公差（tolerance）"与后两者同义（长度用绝对误差、电阻用百分比）。
- 不确定度传播四规则（独立高斯分布时平方和开方，保守估计取绝对值相加）：
  1. 加减：绝对不确定度合成 Δz = √(Δx²+Δy²)；两数相近相减时相对误差急剧放大——**实验设计应避免测两个大数求差**。
  2. 乘除：相对误差相加（保守）或平方和开方（高斯）。
  3. 幂运算：相对误差乘指数 n，即 Δz/z = n·Δx/x。
  4. 一般函数：偏微分链式合成 dR = ∂f/∂x·dx + ∂f/∂y·dy + ∂f/∂z·dz。
- 书给出口袋公式表与两例：两表测串联分压 6.24±0.01V 与 14.3±0.2V，合成 20.5±0.2V；180Ω±5% 电阻通过 1.256±0.005A，电压 = 226.1V（不确定度按乘法规则合成）。

**对本项目的启示（附录B）**
- 载流计算器与阻抗估算器（IPC-2141）应输出**带不确定度的结果**：输入侧聚合电阻公差、介质常数偏差、蚀刻线宽公差，按"乘除=相对误差合成（平方和开方）"给 ±X% 区间，比单点数值可信得多。
- "忌两大数相减"提醒：任何"测量值-基准值"型检查（DRC裕量）在裕量很小时应明示不确定度，避免伪通过/伪失败。
