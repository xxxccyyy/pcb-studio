## 分章笔记

### 第1章 库编辑器（p4—23）
- 库分三类：原理图库 *.SchLib、PCB封装库 *.PcbLib、集成库 *.IntLib。集成库是编译后的二进制包，不能直接编辑，打开时提示解压还原为源库（p5, p27—28）。
- 关键术语（p6）：部件（多部件器件中的一路，如7404的一个反相器）；Part Zero（多部件器件的隐形部件，其管脚自动加到每个部件，常用于隐藏电源脚）；别名（74LS04/74ACT04 共享同一图形以压缩库）；显示方式（一个器件最多255种显示形态）。
- 器件类型字段有特殊值（p9）：Graphical 型不进 BOM；Mechanical 型需原理图与 PCB 同时存在才同步；Net Tie 型用于在板上短接两个网络（如模拟地/数字地单点连接）。
- 封装创建四途径（p12—14）：Component Wizard、IPC Footprint Wizard（按 IPC 算法直接用器件本体尺寸而非封装尺寸，支持 BGA/QFN/SOIC/SOT23 等20余类，含3种板密度变量）、IPC 批量生成器（Excel/CSV 输入文件驱动批量产出）、手动放置。
- 手动建封装要点（p15）：轮廓画在丝印层；首个焊盘设为1号后指示器自动递增；(0,0) 是放置保持点，用 Edit»Set Reference 调整参考点。
- 不规则焊盘的重要规则（p18—19）：不规则铜形若用"焊盘对象"拼成，阻焊/助焊开窗自动匹配生成；若用线轨/填充/圆弧拼成，必须手工在掩模层放置扩展后的对象，否则没有阻焊开窗。
- 器件参数与参数管理器（p19—23）：参数可挂任意信息（额定值、价格、装配要求、HelpURL 指向数据表 PDF）；Parameter Table Editor 类电子表格跨器件批量编辑，所有改动经 ECO（工程变更单）流程，可选择性执行并出报告。

**对本项目的启示**：元件库 schema 可参照"符号+封装+参数+模型四件套 + 管脚-焊盘映射"建模；Net Tie/Mechanical 器件类型提示 BOM 与装配输出需支持类型区分；"焊盘对象自动推导阻焊"对应本项目 Gerber 导出时 mask 层应由 pad 几何加扩展值生成，而非独立绘制。

### 第2章 添加模型信息到元件（p24—28）
- 加模型的三个入口：器件属性对话框、工作区底部 Models 区、Model Manager（跨器件批量管理，p24）。
- 符号→封装的解析方式三档（p25）：Any（任意已装库）、Library Name（指定库）、Library Path（指定路径）；管脚号与焊盘号不一致时用 Pin Map 显式映射。
- 集成库优缺点（p27）：体积约为源文档的 1/8—1/10，库更新/PCB更新更快，可放网络盘集中管控；缺点是编辑前必须解压，管理不当流程易乱。

**对本项目的启示**：封装匹配可设计为 Any→指定库→指定路径的 fallback 链；模型结构需支持符号管脚号≠封装焊盘号的显式映射表。

### 第3章 完成原理图设计并更新器件（p29—31）
- 原理图侧 Tools»Update From Libraries 按差异比对更新，慎用"整板符号替换"；PCB 侧 Tools»Update from PCB Libraries 比对封装图元差异，默认公差 imperial/0.001mil，可只比信号层（p29—30）。
- 差异分级思想（p30）：关键差异是 Model Values（封装或管脚映射变化）与 Part Symbol（管脚属性变化）；参数/注释差异多为放置后的合法定制，可排除。
- PCB 本身的设计规则会覆盖库中的设置（如阻焊扩展）；封装更新后必须跑一次批量 DRC 确认版图完整性（p31）。

**对本项目的启示**：差异分级 + ECO 确认后执行的范式，可用于本项目网表/库变更的增量更新流程。

### 第4章 PCB编辑基础（p32—37）
- 视图与跳转快捷键体系（p32—36）：VD/VF/VA/VP/VE/VI/VO/VZ/VR；Jump 子菜单可跳到绝对/相对原点、坐标、器件（JC）、网络（JN）、焊盘（JP）、DRC 错误标记（JE）。
- 语义化选择（p34—35）：Edit»Select 支持按网络、连接铜、层、板外对象、锁外对象、离格焊盘等条件选择。
- 特色功能（p36）：Board Insight 光标处动态信息；板卡翻转编辑（双面布局体验一致）；True Type/Unicode 字体嵌入保证跨机可移植。

**对本项目的启示**：若做 CLI/AI 无头接口，"语义查询（按网络/层/连接性）+ 定位 DRC 错误"正对应 Filter/Select/Jump 能力清单。

### 第5章 创建PCB设计文件（p38—52）
- 栅格体系（p38—41）：捕捉栅格、器件栅格、可视栅格（两组）相互独立；电气栅格是"吸附范围"，光标呈八边形时表示已吸到电气对象，Shift+E 或按住 Ctrl 临时关闭。绝对原点在左下角，可另设相对原点，Q 键切换公/英制。
- 板框来源（p41—45）：新建默认 6×4in、模板、向导；外形可由 DXF/DWG 导入到机械层后用 Board Shape»Define from selected objects 生成，也可由 3D STEP 模型选面生成。
- 层体系（p47—48）：信号层最多32；内电层（Internal Planes）16个，整片铜膜、可分区；机械层16个；丝印/阻焊/助焊各2；另有钻孔视图层、钻孔引导层、Keep-Out、Multi-layer。
- 层叠管理器（p48—50）：定义层序、铜厚、介质类型（Core/Prepreg）、厚度与介电常数；Drill Pairs 定义盲埋孔的起止层对。层对（Layer Pairs）让机械层图形在器件翻面时自动换到配对层（p40, p50）。
- 内电层（p51）：最多16个电源层；每层设一个网络名，同网络焊盘/过孔以预拉线预示连接；连接方式由 Power Plane Connect Style 规则定义，隔离间距由 Power Plane Clearance 规则定义。
- 内电层分割（p51—52）：在内电层上放置线（Place»Line）划分区域，线宽即两区域间的安全间距；系统自动分析闭合区域，双击区域赋网络，PCB 面板切换为 Split Plane Editor 模式；区域内可再分割；移动或删除边界线即可重定义/删除区域。

**对本项目的启示**：层叠数据（Core/Prepreg、铜厚、介电常数、钻孔对）是本项目阻抗计算与 Gerber/钻孔输出的底层输入；"画线定界→自动识别闭合区域→区域赋网络"的分割算法可直接移植到覆铜/电源平面模块，分割线宽即隔离间距。

### 第6章 将设计更新到PCB以及设计同步（p53—57）
- 同步三件套（p53—54）：差异比较引擎（可比较原理图↔PCB、PCB↔PCB、网表↔PCB 等任意组合的器件与连接信息）、差异对话框（双向选择更新方向）、ECO 对话框（生成变更单并执行出报告）。
- 同步错误两大类（p54）：缺封装（器件无封装/库未装/库中无此封装）；引脚号与焊盘号不匹配（用 Pin Map 解决）。大规模网络更新后执行 Update Free Primitives from Component Pads 恢复已布线的网络归属。
- 直连同步用 UID（唯一识别码）匹配器件、支持双向；网表方式退化为按位号匹配，能力较弱（p55—56）。
- 一次完整更新的 ECO 内容（p57）：20 器件、22 网络、5 器件类、1 网络类、3 条设计规则——同步不仅传器件与网络，也传类与规则。

**对本项目的启示**：导入/同步时应把"器件+网络+类+规则"作为一批校验；匹配策略 UID 优先、位号兜底。

### 第7章 PCB设计对象（p58—68）
- 通用交互（p58）：放置中 TAB 改属性，双击编辑，F11 Inspector 批量编辑；对象落在当前层。
- 导线（Interactive Routing, p59—60）：5种拐角模式（任意角/45°/45°弧/90°/90°弧，Shift+Space 切换）、起始/收尾模式空格切换；* 换层自动放过孔；TAB 可设线宽并受规则约束。
- 焊盘（p60—61）：支持逐层堆叠定义（Full Stack）各层尺寸形状；可标记为测试点；可设是否镀锡（塞孔）。
- 过孔（p62）：属性含直径/孔径/网络/起止层，设定起止层即成盲埋孔；交互布线中按 "/" 键直接打孔落到内电层；阻焊扩展可脱离规则单独指定；Tenting（盖油）可忽略规则取消开窗。
- 实心区 Solid Region（p65—66）：多边形实心可放任意层；Polygon cutout（板形剪切块）轨迹可输出 Gerber/ODB++。
- Keepout 属性可赋予已有导线/填充/弧，定义布线壁垒，且输出出图时被忽略（p67）；特殊粘贴支持粘贴到当前层、保留网络名、位号递增/重复（p67—68）。

**对本项目的启示**："/ 键落内电层"的语义即回流/散热过孔直连平面，对应本项目缝合孔与回流地孔检查；Tenting 与阻焊扩展的对象级覆盖提示 DRC 与 Gerber 输出需要"对象级例外"机制。

### 第8章 PCB查询、全局编辑与设计复用（p69—75）
- 数据编辑三视图（p69—72）：图形视图、Inspector（F11，跨类型批量改属性）、List（Shift+F12，电子表格式，可与 Excel 互拷）；过滤引擎统一驱动 Mask/Select/Zoom。
- 查询语言（p71）：如 IsComment or IsDesignator；Query Helper 列全部关键字；Find Similar Objects 右键按属性相似批量选中。基本方法即 Select→Inspect→Edit 三步（p69）。
- 复用设施（p72—73）：Clipboard 面板、Snippets 片段面板（普通文件夹存储，可网络共享团队；建片段前先复位位号防冲突）、Favorites 收藏夹。
- 全局编辑示例（p74—75）：批量改注释可见性、IsDesignator or IsComment 批量改文字高度 40mil、按层批量改中间层走线/圆弧宽度。

**对本项目的启示**："查询表达式→选中集→批量改属性"是低成本实现 AI 无头编辑接口的原语。

### 第9章 设计规则（p76—80）
- 规则定位（p76）：定义设计需求（线宽、隔离间距、内电层连接风格、过孔风格等），既支持布线中实时检查，也支持批量检查并生成错误报告。
- 架构关键（p76）：规则不是 PCB 对象的属性，而是独立对象；每条规则面向一个作用域（对象集）；用"作用域 + 优先级"组合即可覆盖全板每个对象。
- 规则分两类（p76）：一元规则约束单个对象集内每个对象（如线宽）；二元规则约束两个对象集之间的电气关系（如两组铜的间距），需两段查询分别定义两个作用域。
- 作用域由查询语言描述（p77—78）：可手写、可用构造器；语法错误的规则在树中标红，且会显著拖慢在线实时检查。
- 实战示例（p78—80）：新建 Polygon Connect Style 规则，作用域填 IsVia，连接方式选 direct connect，保存后 Repour all polygons——实现覆铜上过孔直连、SMD 焊盘仍为热焊盘（花孔）。
- 优先级（p80）：规则列表顺序即优先级，最前最高；右键工作区对象选 Applicable Rules 可查看该对象命中的规则链。

**对本项目的启示**：本章与本项目最相关——规则 = 类型（一元/二元）+ 作用域查询表达式 + 约束值 + 优先级，这套四元组可直接作为本项目 DRC 与布线约束的数据模型；间距/3W 检查天然是二元规则（网络类对网络类）；"坏规则拖慢实时检查"提示布线前要做规则静态校验。

### 第10章 PCB布局（p81—83）
- 找器件（p81）：直接拖动；Edit»Move»Component 空点后按列表选；原理图选中后 Tools»Select PCB Components 联动；Navigator 按住 Alt 从原理图探针到 PCB（需先编译）。
- 移动行为（p81）：拖动时该元件飞线随动、其余飞线消失，飞线动态按最短拓扑重算；N 键隐藏飞线，L 键翻面，Alt 约束水平/垂直。
- 组合 Union 捆绑多器件移动（p81—82）；器件栅格独立于捕捉栅格（p82）。
- 半自动布局（p82—83）：Align 对齐、Spacing 等间距/增减间距、Arrange（Room 内排列/矩形区内排列/板外重排）、Move To Grid 全部吸附到器件栅格。

**对本项目的启示**："移动时飞线实时最短化"与本项目 RMST 动态重算同源，佐证模拟退火布局以半周长/飞线长度为目标；Room 内排列可对应本项目按功能分区的布局约束。

### 第11章 PCB布线（p84—102）
- 交互布线要点（p84—89）：飞线拓扑默认最短、由 Routing Topology 规则决定（p84）；线宽/过孔尺寸四种来源——User Choice（收藏宽度表 Shift+W）、Rule Min/Preferred/Max，布线中按 3/4 切换，超范围自动钳到规则界限（p84—85）；冲突处理四模式——None（可压线但高亮报警）、Push（推挤让位）、Walkaround（绕障）、Hug and Push（贴墙+推挤），Shift+R 循环（p86）；Auto Complete（Ctrl+点飞线自动完成整网）、自动收尾、自动去回路（重走即替换，可按网络关闭）、贴随已有走线（p86—87）；loop removal 支持含跨层过孔的复杂路线整体替换，Ctrl 拖线保持45°（p87—89）。
- 布线小提示（p90）：两层板一层水平、一层垂直走线较好；推荐 5mil 格点；Ctrl+点击网络高亮并可调 Mask 级别。
- 差分对（p92—93）：原理图定义差分对，PCB 上两线同时布放。多重布线/总线（p93—95）：从焊盘群拖出多线，TAB 设总线间距，逗号/句号增减，反斜杠换收尾样式。
- 交互式长度调谐（p95—97）：等长蛇形插入，目标长度可来自规则/参考/手输；三种样式（斜接线、斜接弧、全弧）；游标黄色示可达最小/最大长度、绿色示目标长度。
- 测试点（p97—98）：规则驱动，Find and Set Testpoints 自动按规则挑选最优 pad/via；自动布线器不再自动放测试点，需手动或规则驱动；Clear all Testpoints 一键清除。
- 泪滴（p98—99）：分弧形/线段两种；强制补泪滴可造成 DRC 失效；官方承认的缺陷——弧形泪滴与多边形敷铜求交时，弧段轮廓互相交错抵消导致旁边铜皮脱落，建议改用线段式泪滴。
- Situs 自动布线（p99—102）：拓扑式自动布线；遵守设计规则（圆角规则除外），支持差分对自动布线（p99）。前提清单：Keep-Out 必须封闭；规则必须正确定义，否则违反规则的连线无法连通；每层布线方向必须人工确认（Edit Layer Directions）；Lock All Pre-routes 保护已布线/扇出；信号层禁布区封锁所有层、布线层禁布区只封该层；很小的角度连线会让布线器敏感，需对齐器件（p99）。策略：预设策略不可改，需复制为自定义策略；可控制过孔数量、走线角度（选 orthogonal 必须追加 Recorner 算子）与转角方式（p100—101）。BGA 扇出（p102）：内部焊盘先经狗骨（短线+过孔）换层，再从过孔扇出引至 BGA 边缘可达位置；扇出后自动出报告列出未成功管脚，点击可跳转定位。

**对本项目的启示**：Push/Walkaround/Hug&Push 与 PathFinder 协商是同一问题的两种解法（几何推挤 vs 代价+谈判迭代），可借鉴"模式可切换"输出不同风格；"违反规则的线宁可不连"说明规则可行性必须作为自动布线的硬性前置校验；弧形泪滴与覆铜布尔冲突的教训直接适用于本项目"覆铜+缝合孔"模块（避免多边形布尔碎片化，或用线段近似）；BGA 扇出两阶段流程与双层板横竖分层偏置都可落地。

## 可操作改进建议

1. 【规则模型 p76-80】将 DRC/布线约束统一为"规则四元组"：类型（一元/二元）+ 作用域（net/class/层查询表达式）+ 约束值（min/preferred/max）+ 优先级；间距与 3W 检查按二元规则实现两个独立作用域。
2. 【规则静态校验 p78, p80】布线前编译规则：检查作用域语法、空作用域、互相冲突的规则，提前报错；提供"查看某对象命中的规则链"调试输出（对应 Applicable Rules）。
3. 【约束钳位 p84-85】改线宽/过孔时按规则 min/max 钳位；区分 preferred 与 max 场景（电源类网络默认用 max）。
4. 【布线前置检查 p99】自动布线前校验板框/KeepOut 封闭性、层方向偏好、规则完备性；不满足给明确错误而非静默失败；违反规则的失败连接单独报告。
5. 【增量保护 p99】实现 lock pre-routes 等价物：已布线/锁定对象在重布与退火中不动，支持只对指定网络重布。
6. 【覆铜/平面分割 p51-52】采用"分割线→闭合区域识别→区域赋网络"流程，分割线宽即区域隔离间距；支持区域内再分割与分割编辑面板。
7. 【过孔连接风格 p78-80】覆铜对过孔/SMD 的连接方式做成规则可配（direct/relief/none），支持"过孔直连、SMD 花焊盘"混合策略；改规则后自动触发 repour。
8. 【泪滴实现 p98-99】泪滴用线段边近似而非圆弧拼接，避免与覆铜布尔求交时轮廓抵消导致铜皮缺失；强制模式需标记"可能引发 DRC 失效"。
9. 【缝合孔/回流地孔 p62】回流/散热孔语义为"直连平面层"（对应交互布线 "/" 键），换层处自动生成并纳入回流路径检查。
10. 【BGA 扇出 p102】实现两阶段扇出：内圈焊盘狗骨换层，再扇出至 BGA 边缘可达位置；输出未成功管脚报告并支持定位。
11. 【层方向代价 p90, p99】网格 A* 按层施加方向偏置（两层板默认一层横一层竖），减少拥挤与过孔数；层方向作为可配置的布线前置项。
12. 【等长/蛇形 p95-97】为高速网络提供长度调谐：目标长度取自规则或参考网络，支持斜接线/斜接弧/全弧三种样式，并输出长度余量指示（黄/绿游标语义）。
13. 【Gerber 掩模层 p18, p31, p62】阻焊/助焊由焊盘几何自动推导，支持对象级扩展值覆盖与过孔盖油（tenting）标记；对象级设置优先于全局规则（与 p31 的"PCB规则覆盖库设置"一致）。
14. 【层叠与阻抗 p48-50】层叠模型纳入 Core/Prepreg、铜厚、介电常数与钻孔对（盲埋孔起止层），作为阻抗计算与钻孔文件输出的数据源。
15. 【变更同步 p29-31, p53-57】导入/更新采用"差异引擎 + ECO 清单"：先列差异（器件/网络/类/规则），分级标记关键差异（封装、管脚映射），确认后批量执行并出报告；匹配用 UID 优先、位号兜底（p55-56）。
