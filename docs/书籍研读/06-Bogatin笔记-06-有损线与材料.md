## 分章笔记

### 9.0 引言：损耗使上升边变长（p219）
- 实测示例（图 9.1）：上升边 50ps 的信号经 FR4 上 36in 长 50Ω 走线后，输出上升边拉长到约 1ns。根源是信号的高频分量衰减比低频分量大得多，带宽降低、上升边增长。
- 适用判断：时钟频率高于 1GHz 且线长超过 10in 的信号（高速链路、千兆以太网），损耗是首要信号完整性问题。
- 方法论：损耗机理在频域理解最简单，但后果（ISI、眼图）必须在时域评估。
- **对本项目的启示**：工具的 SI 报告对"长线 + 高速"组合需要增加"损耗"维度，而不是只做反射/串扰检查。

### 9.1 有损线的不良影响：ISI 与眼图（p219-221）
- 关键区分：若损耗与频率无关，各频率等比衰减，上升边不变（图 9.2），接收端加增益即可补偿。**只有与频率相关的损耗才引起上升边退化、符号间干扰（ISI）、眼图塌陷和确定性抖动**。
- ISI 机理：当退化后的上升边与单位间隔（UI）可比时，当前位的电平取决于之前位模式的"历史"（图 9.3，5Gbps 伪随机位流仿真）；信号到达开关阈值的时间随历史数据变化，这本身就是抖动的重要来源。
- 眼图（图 9.4）：伪随机位流以时钟触发叠加而成；眼张开度是误码率（BER）的度量，垂直/水平"掩模"内落入电压即可能误码，两眼交叉区水平宽度度量抖动。
- **对本项目的启示**：损耗检查的输出形式可以归结为两个数——奈奎斯特频率处总衰减（dB）与输出上升边（ps），再与 UI 比较，即可判 ISI 风险，无需完整仿真。

### 9.2 传输线中的损耗：五种能量损失途径（p221-222）
- 无损 n 节 LC 模型只有特性阻抗和时延，不含衰减。信号沿线能量损失的五种途径：①辐射损耗（总量极小，不影响接收信号，但对 EMI 重要）；②耦合到相邻走线（串扰问题，归第 10 章）；③阻抗不匹配（反射回源端的高频分量最终被端接电阻或驱动器内阻吸收——即使无损耗线，容性/感性突变也退化上升边）；④导线损耗（信号/返回导体的串联电阻发热）；⑤介质损耗（材料耗散因子引起）。
- 本章"衰减"专指④⑤两类"能量损失在传输线材料中"的机制；串扰与反射已在各自章节处理，不重复计入。
- 容性突变算例（图 9.5）：5Gbps 信号过 4 个 1pF 过孔焊盘（共 4pF），上升边退化约 0.5×Z0×C ≈ 0.5×50×4p = 100ps，恰为半个位周期（UI=200ps）（OCR 此处含糊，按图 9.5 语境与第 8 章公式推定）。
- 分界线：FR4 上 8mil 宽 50Ω 走线，约 1GHz 以上介质损耗超过导线损耗；2.5Gbps 及以上介质损耗主导，**叠层材料的耗散因子成为关键材料参数**。
- **对本项目的启示**：工具的"损耗模型"只含导体损+介质损两项，反射（第 8 章笔记）、串扰（3W 扫描）分别报告，避免把不同根源混成笼统的"衰减"。

### 9.3 损耗源一：导线电阻与趋肤效应（p222-225）
- 直流电阻（式 9.1）：R = ρ·Len/(w·t)，铜的体电阻率 ρ = 0.72×10⁻⁶ Ω·in。算例：5mil 宽、1.4mil 厚（1 盎司铜）、1in 长 → 0.72e-6/(0.005×0.0014) ≈ 0.1Ω/in（验算 0.103，吻合）。返回平面直流电阻可忽略。
- 铜等金属的体电阻率到约 100GHz 都是常数；随频率变化的是**电流流过的有效横截面**。
- 集肤深度（式 9.2/9.34，数值已验算）：**δ[μm] = 66/√f[MHz]**。1GHz → 2.1μm；10MHz → 21μm；10GHz → 0.66μm。（p223 正文把单位标成 GHz，但数字只有按 MHz 才自洽，以 p233 的式 9.34 为准。）1 盎司铜几何厚度约 35μm，频率高于 10MHz 后 δ < 铜厚。
- 电流分布遵循"最小阻抗路径"：横向扩展使自感最小、反向电流贴近使互感最大。微带线信号电流在导线上下两面都有（两面并联，式 9.3 取系数 0.5）；返回平面电流集中在迹线正下方，微带返回电流分布宽度约为信号线宽的 3 倍（图 9.6，2D 场求解器）。
- 高于 10MHz 时微带总电阻（信号 0.5 + 返回 0.3，式 9.4）：**R ≈ 0.8·ρ·Len/(w·δ)**；带状线略低（图 9.7 一阶模型与 2D 场求解器结果在 10MHz 以上频段吻合良好）。
- **对本项目的启示**：acTraceR 的 δ 公式与 66/√f 校核一致；返回路径电阻系数（微带 0.8）可作校准点；"返回电流集中在约 3 倍线宽内"是回流地孔检查与缝合孔密度设计的量化依据。

### 9.4 损耗源二：介质（p225-227)
- 理想电容器电流超前电压 90°，不耗能；填充理想介质后电容量变为 εr 倍，仍不耗能。实际介质有两种漏电流：①离子运动（直流主导；绝缘体中载流子密度小、迁移率低，故直流漏电极小）；②**永久偶极子随外加场重取向**（图 9.8）——正弦场下偶极子来回旋转形成同相交流电流，频率越高旋转越快、电流越大，交流电导率随频率上升。
- FR4 体电导率（图 9.9）：直流至约 10Hz 转折频率内为常数（离子导电），之后与频率成正比（偶极子导电）。
- 直流/发热量级：10in 长 50Ω 微带线，直流漏电阻约 10¹¹Ω 量级、功耗 <1mW；即使 1GHz 交流漏电阻也在 kΩ 量级、功耗 <10mW——发热可忽略，但这些能量足以造成远端信号衰减。微波炉中水分子强烈吸收 2.45GHz 辐射是介质损耗的极端示例。
- 漏电阻（平行板近似，式 9.6-9.7）：R_leak = ρ·h/(Len·w)（电流路径长 h、截面 Len×w）。
- **对本项目的启示**：IR-drop 与绝缘类检查可放心忽略介质直流漏电；损耗建模的重心应放在交流（偶极子）项，即 Df。

### 9.5 介质耗散因子（p227-228）
- 描述偶极子损耗的材料参数（式 9.9/9.23）：**σ_ac = 2πf·ε0·εr·tan(δ)**，其中 ε0 = 8.89×10⁻¹⁴ F/cm。tan(δ)（又称耗散因子 Df）度量偶极子数目密度×偶极矩×电场中旋转角度（式 9.10）。
- 工程事实：大多数互连材料的 Df 在宽频段内近似常数（微弱频变可忽略）；不同批次、不同板之间、甚至同一块板上会有偏差。聚合物交联度越高偶极子压合越紧，εr 和 Df 都越低；低 εr 材料（特氟龙、硅橡胶、聚乙烯）Df 也低。
- 常用材料表（图 9.10，OCR 不全处以 (?) 标注）：FR4 玻纤板 εr≈4.0/Df≈0.02/相对成本 1；DriClad(IBM) 4.7/0.011/1.4；GETek 3.6~4.2/0.013/5；双马来酰亚胺三嗪 ≈3.36/0.013(?)；聚酰亚胺/玻璃 Df≈0.014；氰酸酯、Nelco N6000SI、Rogers 低损材料 Df≈0.0009~0.003(?)。
- 吸湿效应：材料从潮湿空气吸水后 Df 增大；聚酰亚胺/Kapton 柔性膜的 Df 可因湿度加倍甚至更高。
- **对本项目的启示**：DIELECTRICS 预设应补 Df 字段（目前只有 εr 一类参数），并给低损材料标注成本量级与吸湿警示。

### 9.6 耗散因子的真实含义：复介电常数（p228-230）
- 复介电常数 εr* = εr' − i·εr''（虚部按惯例取负号，使同相电流为正值）。实部就是平时简称的"介电常数"（增大电容、降低材料中光速）；虚部产生与电压同相的电流（像电阻一样耗能）。
- 损耗角 δ 是复平面上介电常数向量与实轴的夹角，**tan(δ) = εr''/εr' = Df**（式 9.17-9.18）。它与趋肤深度用同一个希腊字母纯属巧合，两者完全无关。
- 几何反比关系（式 9.19-9.22）：同一几何下 R_leak = 1/(ω·tanδ·C)——电容越大漏电阻越小，两者相乘消去几何，得到 σ_ac = 2πf·ε0·εr'·tanδ，与几何无关。
- **对本项目的启示**：阻抗估算器若扩展频变模型，复介电常数（εr'、Df 两个数）是标准输入接口，也正好对应 DIELECTRICS 每预设两个字段的方案。

### 9.7 有损传输线建模：RLGC 模型（p230-232）
- 理想有损分布式线 = 无损模型 + 两个频变耗散元件：串联电阻 R ∝ √f（趋肤效应），并联电导 G ∝ f（偶极子旋转）。这是多数仿真器有损线模型的基础。
- n 节集总 RLGC 近似的节数（式 9.25）：**n = 10 × BW[GHz] × TD[ns]**。算例：带宽 2GHz、时延 1ns → 20 节（验算吻合）。
- 四个线参数都与线长成正比，故并联用 G = 1/R 表示：**G = ω·tan(δ)·C**（式 9.26-9.27，线长加倍时 C、L、R 加倍而 R_leak 减半、G 加倍）。
- 无损时 Z0 = √(L_L/C_L)、v = 1/√(L_L·C_L)；加入 R、G 后出现三个新特征：Z0 变为复数且频变、速度频变、新增与频率相关的单位长度衰减 α。
- **对本项目的启示**：若后续做损耗感知的通道估算，节数公式与 G=ω·tanδ·C 可直接搬用；这也是校核外部仿真结果的最小模型。

### 9.8 有损传输线的特性阻抗（p232-235）
- 精确解（式 9.30）：Z0 = √((R_L+iωL_L)/(G_L+iωC_L))，实部/虚部表达式繁琐（式 9.39-9.41），工程价值低。
- 低损耗近似条件：R_L << ωL_L 且 G_L << ωC_L（等价于 Df << 1）。用 50Ω 线 L≈9nH/in 与直流电阻验算：3mil 线的低损耗区起始频率 ≈ R_dc/(2πL) ≈ 0.17/(2π×9e-9) ≈ 3MHz，书中取约 2MHz；线宽越大起始频率越低（约 9/w[MHz] 量级）。所有互连材料 Df < 0.02，故信号的主要频率分量几乎总在低损耗区。
- 低损耗区内（式 9.42-9.43）：Re(Z0) ≈ √(L_L/C_L)、Imag(Z0) ≈ 0。图 9.14：FR4 上 3mil 50Ω 微带线（最差情况），频率高于 10MHz 后复特性阻抗与无损值几乎重合；1% 精度要求下 3mil 线需高于约 20MHz。
- 结论：**低损耗区（>10MHz）中损耗对特性阻抗没有影响**；实际互连中电感/电容的弱频变对 Z0 的影响也不明显。
- **对本项目的启示**：现有阻抗估算器采用无损公式是正确的，无需加损耗修正；只需在极窄线（<3mil）+低频场合注明适用边界。

### 9.9 有损传输线中的信号速度与色散（p235-236）
- 低损耗区速度（式 9.46）：v = 1/√(L_L·C_L)，与无损线相同、与频率无关。
- 损耗引起的色散：低频时串联电阻阻抗占比大，低频分量速度降低；高频分量先到、低频尾巴拖后，也会拉长上升边。但 FR4 最差情况（3mil 线）在 10MHz 以上色散可忽略（图 9.15），且**衰减对上升边的直接影响远大于色散**。
- 色散的另一来源是反射往返造成的"异常相移"（异常色散）。
- **对本项目的启示**：飞行时间/时延计算不需要引入损耗修正项；项目已有的"反射引起时延抖动"检查覆盖了异常色散。

### 9.10 衰减与 dB（p237-240）
- 正弦波幅度沿线指数下降。neper 基（式 9.47-9.48）：V(d) = V0·e^(−α_n·d)；1 neper → 输出 37%（验算 e⁻¹=0.368），2 neper → 13%（e⁻²=0.135）。1 neper = 8.68 dB（验算 20·lg0.368 = −8.68，吻合）。
- dB 的来历与规则（事实，完整记录）：Bel = lg(P1/P0)，1 Bel = 10 dB。dB 永远指两个功率之比的对数：功率比用 10·lg，幅度比（电压/电流）用 20·lg（因 P ∝ V²）。常用换算：3dB = 功率×2 = 电压×1.4；6dB = 电压×2；20dB = 电压×10；−40dB = 电压×1%。
- 图 9.17 对照表：电压比 1.4/2/10/100/0.1/0.01 ↔ 3/6/20/40/−20/−40 dB。
- **对本项目的启示**：报告中统一用 dB/in 表示单位长度衰减、用 dB 表示通道余量，与业界（如 PCIe/以太网损耗预算）口径一致。

### 9.11 有损线上的衰减：两个核心公式（p240-243）
- 总衰减 = 导线损耗 + 介质损耗。低损耗近似（式 9.55/9.58）：α_nep ≈ ½(R_L/Z0 + G_L·Z0)，即 **α_dB = 4.34·(R_L/Z0 + G_L·Z0)**。
- 导线损耗衰减（带状线近似，式 9.62-9.65，频率 ≥10MHz，f 单位 GHz、w 单位 mil）：**α_cond[dB/in] ≈ 36·√f/(w·Z0)**。算例：1GHz、10mil、50Ω → 36/(10×50)×√1 = 0.072 ≈ 0.07dB/in（书中原例，吻合）；36in 背板总衰减 0.07×36 = 2.5dB → 输出幅度 10^(−2.5/20) = 75%（验算吻合）。
- 校准说明：式 9.62 的 0.5 系数指信号路径两个表面电流相等（仅信号路径 0.5·ρ/(w·δ)），而衰减算例的常数 36 等效于按"单面全电流"值 ρ/(w·δ) 计（4.34×8.3≈36，即已并入返回路径电阻）。实现 acTraceR 时以算例常数 36 校准，微带（系数 0.8）约对应 30·√f/(w·Z0)。
- 介质损耗衰减（式 9.66-9.69）：**α_diel[dB/in] ≈ 2.3·f[GHz]·Df·√εr**，与走线几何完全无关（G ∝ C 增加但 Z0 反向缩小，两者抵消），是纯材料品质因数。算例：FR4（εr≈4.3，Df≈0.02）@1GHz → 2.3×1×0.02×√4.3 = 0.095 ≈ 0.1dB/in（书中原例，吻合）。
- 经验法则：FR4 介质损耗 ≈ **0.1dB/in/GHz**，与阻抗和几何无关；典型通道合计 **0.1~0.2dB/in/GHz**（窄线时导线损贡献可观）。1GHz 时介质损略大于导线损；频率更高时差距拉大（∝f vs ∝√f）。8mil/50Ω FR4 的转折频率 <1GHz（图 9.19）。
- 表面粗糙度：铜箔典型粗糙度约 2μm（OCR 数字存疑），当其与集肤深度同量级时（数 GHz 以上）粗糙面串联电阻加倍；铜箔仅一面粗糙，故整体电阻比光滑估计值约高 35%。
- **对本项目的启示**：这两个公式就是"损耗预算计算器"的全部核心；按通道长度×奈奎斯特频率即可快速给出 dB 预算。

### 术语辨析（p244）
- 书中给出的术语精确含义（事实，完整记录）：**损耗**（总称）；**衰减**（传输线上总衰减的度量，dB 度量时随长度线性增长，幅度比度量时按指数递减）；**单位长度衰减**（把长度归一化的互连固有特性）；**耗散因子**（介质固有材料特性，度量偶极子数目与可移动程度）；**损耗角**（复介电常数向量与实轴夹角）；**tan(δ)**（损耗角正切 = 虚部/实部 = Df）；**介电常数实部**（增大电容、降低光速）；**介电常数虚部**（从电场吸收能量的程度）；**复介电常数**（基本材料特性，实部管电容、虚部管并联漏电阻）。
- 衰减与频率相关，而材料 Df/εr 仅随频率缓慢变化；了解的唯一途径是测量实际材料。
- **对本项目的启示**：工具报告字段命名按此表统一（loss/attenuation/α_per_length/Df），避免混用。

### 9.12 频域中有损线特性的度量（p244-247）
- 测量方法：叠层上构建（最好带状线，介质均匀）带过孔的传输线，用矢量网络分析仪（VNA）+ 微探针测 S11（反射损耗）与 S21（插入损耗），两端 50Ω 源/负载。
- 过孔用 π 形 C-L-C 简单模型纳入：实测 4in 长 50Ω 带状线拟合出 C1=0.025pF、L_via=0.211nH、C2=0.125pF、Z0=51.2Ω、εr=4.05、Df=0.015，且假设 10GHz 带宽内为常数时测量与仿真吻合（图 9.22）。
- 模型带宽上限：扩展到 20GHz 后发现约 14GHz 之前材料特性仍可视为常数，14GHz 以上实测 Df 微升、εr 微降（图 9.23）——**对该 FR4 样本，"材料特性恒定"假设的有效上限约 14GHz**。
- **对本项目的启示**：DIELECTRICS 每个预设可带"频率适用上限"元数据；FR4 类常规材料标 ≤14GHz，提醒 25Gbps+ NRZ（奈奎斯特>14GHz）场景需实测数据。

### 9.13 互连的带宽与上升边退化（p247-249）
- 3dB 本征带宽（介质损主导区，式 9.70-9.71，Len 单位 in）：由 3dB = 2.3·f·Df·√εr·Len 解出 **BW_TL ≈ 1.3/(Df·√εr·Len) [GHz]**。线越长、Df 越大，带宽越窄。
- 本征上升边（式 9.72-9.73）：RT_TL = 0.35/BW_TL ≈ **0.27·Df·√εr·Len**。验算 FR4：0.27×0.02×2.07×1 ≈ 11ps ≈ **10ps/in**（书中经验法则，吻合）；10in 线把 1ps 输入边沿拉长到约 100ps。
- 输出上升边（高斯边沿 RSS 近似，式 9.74）：**RT_out = √(RT_in² + RT_TL²)**。书中 18in 例：RT_TL=180ps，实测输出约 150ps，量级吻合。
- 图 9.24 材料表（单位长度上升边退化）：FR4 10、DriClad 7、GETek 7 ps/in（三值已用公式反推核对），BMI/聚酰亚胺约 8，氰酸酯~2、N6000SI/Rogers 类低损材料约 0.9~2（OCR 不全，按 0.27·Df·√εr 推算）。
- 25% 判据（式 9.76-9.79）：要使输出上升边退化不超过 25%，需 RT_TL < 0.5×RT_in。代入 FR4 的 0.01ns/in 得简单法则：**Len[in] > 50 × RT[ns] 时损耗开始成为问题**。算例：1ns → 50in；0.1ns → 5in；背板 36in + 0.1ns 边沿 → 损耗主导性能。
- **对本项目的启示**：与 criticalLineLen 的 1/6 反射判据并列，增加"损耗判据"；两判据取更严者，每 net 报告 RT_out 估计值。

### 9.14 有损线的时域行为（p249-251）
- 有损线输出边沿不是高斯形：初始部分快、带长尾巴，10%-90% 上升边的表征意义下降（图 9.26，15in FR4 实测）。
- 仿真器判别标准（重要）：**电阻值不随频率变化的"理想电阻器"模型不能仿真有损线**——常量电阻只造成等比幅度下降，不产生上升边退化。有效模型必须 R ∝ √f、G ∝ f。
- 仿真示例：图 9.27（30in，无损耗/仅导线损耗/导线+介质三种曲线）；图 9.28（1Gbps，20in 与 40in）；图 9.29（FR4 背板 36in 4mil 5Gbps 眼图，依次加入导线损耗、介质损耗、两端各 0.5pF 过孔后，眼图塌陷到不可用）。
- **对本项目的启示**：AI 无头接口若要声明"有损线仿真"能力，必须满足频变 R/G；否则诚实定位为"损耗估算器"，用 9.11/9.13 的公式给出预算而非波形。

### 9.15 改善传输线眼图（p251-253）
- 板级影响眼图的三因素：①过孔桩线突变；②导线损耗；③介质损耗。
- 过孔优化：最大影响在**桩线**——桩线长度降到 10mil 以下，即使频率高于 10GHz 过孔也近乎"透明"；手段为限制层间切换、盲孔/埋孔、背钻长桩线；再减小捕获焊盘、加大反焊盘（出砂孔）使过孔阻抗向 50Ω 靠拢。
- 线宽窗口：加宽走线降低导线损耗（需同步加厚介质保持阻抗，常受叠层限制）。FR4 上最优线宽 **5~10mil**（图 9.30）：<5mil 导线损耗显著；>10mil 后收益被介质损耗掩盖。低损材料上，线宽超过约 20mil 后衰减由材料决定（图 9.31，两种 Df 材料对比）。
- **对本项目的启示**：DFM/SI 规则可直接落地——高速阻抗线的线宽下限 5mil、上限 10mil（FR4）；过孔桩线长度检查阈值 10mil 级。

### 9.16 多大的衰减算大 + 均衡技术（p254-255）
- 参照频率取**奈奎斯特频率 = 数据率/2**（如 2Gbps → 1GHz）：奈奎斯特是通道中最高的正弦分量，其 3 次谐波衰减是其 3 倍，无指望。
- 经验法则：**奈奎斯特频率处总衰减约 10dB 时眼图彻底闭合，是不加均衡的上限**。算例：20in 通道、0.2dB/in/GHz → 最高奈奎斯特频率 = 10/(20×0.2) = 2.5GHz，对应 5Gbps（验算吻合）。
- 三类均衡（预失真补偿）：**CTLE**（连续时间线性均衡器，接收/通道级高通补偿低频，可恢复约 15dB 奈奎斯特衰减）；**FFE**（前馈均衡，发送端预加重/去加重，预抬高频分量）；**DFE**（判决反馈均衡，接收端扣除历史位干扰）。三者合用可容忍 25~35dB。
- 均衡的前提：衰减失真可预测且可重复——即叠层材料特性必须已知、稳定。
- **对本项目的启示**：工具按奈奎斯特衰减分级：<3dB 无忧；3~10dB 标注警告；>10dB 判失败并建议"缩短线长/换低 Df 材料/依赖芯片均衡"，把均衡余量写进报告。

### 小结与复习题（p255-256）
- 小结 10 条（事实，完整记录要点）：①有损线的根本问题是上升边退化→ISI；②板级与频率相关损耗=导线损耗+介质损耗；③高频衰减快→带宽下降、上升边增大；④约 1GHz 时 8mil 线两种损耗相当，更高频时介质损 ∝f、导线损 ∝√f；⑤几 MHz 以上特性阻抗与速度不受损耗影响；⑥1GHz 以上介质损主导，Df 是最重要材料指标，FR4（Df=0.02）最差；⑦有损线模型（R∝√f、G∝f）可准确预估损耗与 ISI；⑧阻抗突变（尤其过孔桩线）同样引起上升边退化与 ISI，清除桩线后过孔近似消失；⑨FR4 上升边退化约 10ps/in，10in 后增至 100ps；⑩奈奎斯特衰减 10dB 是无均衡上限，CTLE 约 15dB，CTLE+FFE+DFE 合用约 35dB。
- 复习题 33 问覆盖：等衰减传输的后果、ISI 两种根源、眼图塌陷、趋肤效应起源、介质损耗起源、理想电容/电阻的电流相位与功耗、Df=0.02 电容器实/虚电流比、n 节数计算（2ns 时延/10GHz 带宽）、5mil 与 10mil 线 1GHz/5GHz 导线损、奈奎斯特 5Gbps 时两类损耗占比、1GHz 与 10GHz 集肤深度、5Gbps 的 UI 与 25ps 边沿的 ISI 判断（按 50×RT 法则约 1.25in 即受影响）、1/2 盎司铜 5mil 线直流与 1GHz 电阻、3mil 线低损耗频率、高/低损耗对 Z0 与速度的影响、dB 与幅度比互算、降阻抗对导线损的影响、材料 FoM（每 GHz 每英寸介质衰减：FR4≈0.1，"美创6"疑为 Panasonic Megtron 6 ≈0.01）、理想电阻器损耗模型的缺陷、10dB 门限、5Gbps/10Gbps 的 FR4 最长不均衡长度。
- **对本项目的启示**：复习题 9.31 的 FoM = 2.3·Df·√εr [dB/in/GHz] 可直接作为 DIELECTRICS 预设的排序指标展示给用户。
