## 分章笔记

### 第5章 电容的物理基础（p96-110）

#### 5.0 引论：电容的定义与本质（p96）
- 电容 = 一对导体在给定电压下存储电荷能力的度量，定义式 C = Q/V。电容只取决于导体几何结构与介质材料，与电压大小无关（电压加倍→电荷加倍→比值不变）。
- 几何规律：间距越小、重叠面积越大，电容越大。
- 任何两个导体间都存在电容（边缘电场无处不在），所以信号完整性领域没有真正的"开路"——两条毫无直流连接的信号线之间照样有容性通路，这是串扰的物理根源之一。

#### 5.1 电容器中的电流流动（p96-97）
- 流过电容的电流 I = C·dV/dt：电压变化率一定时，电容越大电流越大；时域里电容越大阻抗越小。
- 介质中没有真实电荷穿过，但"看起来"有电流——这就是麦克斯韦引入的"位移电流"。书中区分三种电流：传导电流（自由电荷运动）、极化电流（介质束缚电荷随电场变化而移动）、位移电流（真空中电场变化引起的等效电流）。
- 实用图像：边缘电场的每条电力线上都可以想象有位移电流在流动。

#### 5.2 球面电容（p97-98）
- 同心球面有精确解；当外半径≥10倍内半径时，C ≈ 4πε₀·r，ε₀=0.089 pF/cm = 0.225 pF/in。
- 经验法则：直径1 in的孤立球约2 pF（书中算例1.8 pF）。孤立导体必有最小电容，靠近其它表面后电容只会增大。
- 应用直觉：机箱外几英寸长的线扎至少2 pF杂散电容，1 GHz时对地阻抗约100 Ω——高频下"悬空"结构并不悬空。

#### 5.3 平行板近似（p98-99）
- C = ε₀·εr·A/h。算例：1分硬币大小（1 cm²）、间距1 mm、空气介质 → 约0.9 pF，即"1 pF ≈ 硬币大小平板"。
- 平行板近似忽略边缘场，结果是低估。经验法则：当间距等于板宽（正立方体）时，实际电容约为近似值的2倍——边缘场贡献与垂直场贡献相当。板越大、间距越小，近似越好。

#### 5.4 介电常数（p99-100）
- εr（Dk）= C(填充介质)/C(空气)，无单位，是材料固有属性，与导体形状无关。
- 典型值（书p99表，OCR数字已核对）：空气1、特氟龙约2（同质固体最低约2）、聚乙烯~3.5、FR4约4~4.5、玻璃约6、氧化铝约9~10、水>80、钛酸钡高达5000、泡沫接近1。规律：偶极子越多越大。
- FR4的Dk与环氧/玻璃配比有关且随频率略变：1 kHz→4.8，10 MHz→4.4，1~10 GHz基本稳定。要求准确度优于10%就必须实测样品。
- 因果材料模型：Dk随频率对数变化，Df（耗散因子）是该变化的斜率度量；只要给定1 GHz处Dk和Df，即可推出全频段。

#### 5.5 电源/地平面与去耦电容（p100-101）★重点
- 去耦维持时间：t = C × 0.05 × V²/P（容许5%跌落、芯片功耗P、电压V）。算例：1 nF、1 W、3.3 V → 仅0.5 ns；通常需撑到稳压器接管（约5 μs量级），需要约10 μF——差4个数量级。
- 平面对单位面积电容（FR4，εr=4）：约 1 nF/in² 每 mil 介质厚（即 1000 pF/in² / h[mil]，OCR"1開0 pF/h"核对为1000）。常见 h=10 mil → 仅约100 pF/in²。
- 算例：4 in²芯片区域、10 mil介质 → 仅0.4 nF，去耦时间0.2 ns，且还要经过封装引线电感才到芯片——几乎无用。芯片内电容通常是这个平板电容的100倍以上。
- 核心结论：板上平面对电容太小，对去耦基本无贡献；电源/地平面的真正作用是为芯片与去耦电容之间提供低电感路径。
- 想加大平面电容只有两条路：更薄介质+更高Dk。最薄FR4约2 mil → 约500 pF/in²；2 in见方→2 nF→仅1 ns。3M C-Ply（Dk=20、h=0.33 mil，OCR对"8"存疑）→约14 nF/in²，4 in²→56 nF→数十μs（OCR约28 μs）量级，这才开始有用。

#### 5.6 单位长度电容（p102-104）
- 均匀横截面互连：C = CL × Len，用单位长度电容描述。只有三种结构有精确解析式：同轴、平行双圆杆、圆杆-平面；它们是校准场求解器的标准结构。
- 同轴：CL = 2πε₀εr / ln(b/a)。RG58（b/a=3、εr=2.3）→ 2.9 pF/in。
- 双圆杆（s≫r）：CL ≈ πε₀εr / ln(s/r)。空气中键合线（r=0.5 mil、中心距5 mil）→ 0.3 pF/in；40 mil长→0.012 pF。
- 圆杆-平面（h≫r）：CL ≈ 2πε₀εr / ln(2h/r)（原书式5.15，OCR截断，按算例核对）。
- 微带线/带状线IPC近似式（5.16/5.17，含线宽w、介质厚h或b、铜厚t）。算例：50 Ω微带（w=2h、εr=4）→ CL≈2.7 pF/in；50 Ω带状线（b=2w）→ 3.8 pF/in。
- 经验法则：FR4上50 Ω传输线的单位长度电容约3.5 pF/in。算例：BT基板（εr≈3.9）0.5 in走线→1.7 pF，加2 pF输入栅电容→接收器总负载约3.7 pF。

#### 5.7 二维场求解器（p104-106）
- 工作原理：导体加1 V边界条件，解拉普拉斯方程求电场，再积分得电荷，电容=电荷/电压。
- 验证方法：用有精确解的结构（同轴、双圆杆）对比。验证过的2D场求解器误差≤1%。
- IPC近似式实战精度：有的情况误差5%，有的>20%（p105图5.8）——不要未经验证就相信近似式优于10%。
- 二阶效应：铜厚从0.1 mil加到3 mil（2盎司），微带线电容仅增约3%；近似式连这个都估不准。方法论：用场求解器前先按"伯格丁第9条规则"手算预测预期结果。

#### 5.8 有效介电常数（p107-108）
- εeff = Cfilled / C0（实际介质分布下的电容/全空气电容）。它直接决定传输线信号速度。
- 微带线介质不均匀：宽线→场线大部分在板内→εeff→εr(4)；窄线→大部分场在空气→εeff<3。2D场求解器是准确计算εeff的唯一方法。
- 嵌入程度：部分嵌入（如阻焊层）→电容增加；顶层覆盖同Dk材料厚度≈线宽时边缘场被完全包裹，电容增约20%，再厚不再变化（全嵌入后与厚度无关）。

#### 5.9-5.10 小结与复习题（p109-110）
- 小结12条核心：电容=存储电荷效率；dV/dt一定时电容决定电流；除三种结构外全是近似式（精度要求<10~20%就得用场求解器）；间距↑电容↓、面积↑电容↑；Dk是材料属性；平面对电容可忽略、平面价值是低电感路径；IPC近似不可靠；验证过的2D场求解器<1%；铜厚效应约3%；覆盖层≈线宽时电容+20%；εeff决定信号速度。
- 复习题覆盖：杂散电容的1 GHz阻抗、位移电流、平面对电容三要素、Dk与偶极子、εeff随覆盖层变化、片上0.1 μm介质vs板上10 mil（每平方英寸电容差数千倍）等——用于自测概念。

#### 第5章对本项目的启示
- 本项目阻抗估算器/传输线1/6判据若用IPC近似式，误差可能>20%（p105），文档里要声明精度边界；50 Ω≈3.5 pF/in 可作为快速自检锚点。
- 表层微带线的εeff明显低于叠层Dk（窄线时<3，p108），阻抗估算若直接用Dk会算错速度与阻抗；阻焊/覆盖层会使电容增加最多20%（覆盖层厚≈线宽时饱和）。
- powerDrop/PDN语境下不要把板级平面对电容当去耦资源（10 mil FR4仅~100 pF/in²，p100-101）；平面的价值是低电感路径，这与第6章衔接。
- 去耦时间公式 t = C·0.05·V²/P 可直接移植为工具里的"去耦校验"规则。
- 任何"两导体无连接=无耦合"的假设都不成立——串扰扫描的容性耦合项有普遍物理依据。

### 第6章 电感的物理基础（p111-143）★全书最重要的章

#### 6.1-6.2 法则一：电流周围总是形成闭合磁力线匝（p111-113）
- 电感影响几乎所有SI问题：线间耦合、PDN、EMI；有的场合要减小电感（互感、PDN回路电感、返回平面有效电感），有的场合要优化它（目标阻抗）。
- 传统"线圈+磁场积分"式定义对互连分析无用，作者改用三条法则重建直觉。
- 法则一：磁力线匝（环形）总是完整闭合、总是包围电流，方向遵守右手法则；计数单位为韦伯（Wb）。
- 影响某导体周围磁力线匝数的因素：①电流大小（加倍→匝数加倍）；②导线长度；③横截面（二阶效应，加粗→匝数略减）；④附近其它电流——尤其返回电流靠近时，其反向磁力线匝会抵消部分匝数，总匝数变少；⑤介质材料完全无影响（磁场不与电介质相互作用，特氟龙/钛酸钡都一样）；⑥导体材料：只有铁磁金属（铁、钴、镍及其合金如合金42、Kovar）影响，且仅影响导体内部的磁力线匝。

#### 6.3 法则二：电感 = 流过1A时周围的磁力线匝数（p113-114）
- L = N/I，单位 Wb/A = 亨利（H），互连常用 nH。电流加倍→匝数加倍→比值不变，电感与电流大小完全无关（0 A时电感照样存在）。
- 电感是"导体产生磁力线匝的效率"，唯一决定因素是几何结构（铁磁材料再加磁导率）。它不涉及磁场强度绝对值、也不涉及磁场储能多少。
- 单说"电感"是模糊的，必须加限定词——这是全章的方法论核心：按源头分自感/互感，按范围分局部电感/回路电感，按计入范围分总（净/有效）电感，组合后还有等效电感。

#### 6.4 自感与互感（p114-115）
- 自磁力线匝：仅由导体自身电流产生；互磁力线匝：由邻近电流产生，必然同时"链接"两个导体。
- 两导体电流同向→匝数相加；反向→相减。自感与其它导线无关；互感随距离拉近而增大。
- 互感两个微妙特性：①对称性 M_ab = M_ba，与在哪条线加电流无关，即使两导体几何完全不同（窄线vs宽平面）；②互感必小于两者自感的最小值。

#### 6.5 法则三：磁力线匝数变化→感应电压（p115-116）★一切的原动力
- V = ΔN/Δt；自感情形 V = L·dI/dt，互感情形 Vnoise = M·dI/dt（串扰）。
- 感应电压是电感在SI中举足轻重的唯一原因：传输线突变、串扰、开关噪声、轨道塌陷、地弹、多数EMI都源于此。感应电压极性使感应电流阻碍原电流变化——"电感阻止电流变化"的实质。
- 开关噪声/SSN/地弹都是"dI/dt在电感上产生电压"的不同场景表述。

#### 6.6 局部电感（p116-119）
- 局部电感 = 假设回路其余部分不存在电流时，某一段导体单独表现的电感（思想实验：在段两端放垂直大平板，电流从一端注入另一端消失）。它是纯数学构造、不可测量，但极其有用——封装/连接器模型、3D场求解器输出、SPICE模型都建立在局部电感上。
- 圆杆局部自感近似（原书式6.6，OCR截断，按算例反推核对）：L ≈ 5·Len·[ln(2Len/r) − 1]（nH，Len与r同单位）。算例：30 AWG（d≈10 mil）长1 in → 约25~26 nH。
- 经验法则：导线局部自感约25 nH/in（1 nH/mm）。长度加倍→局部自感增长超2倍（新增匝数中还叠加其它段的互感匝）；截面加大→电流扩散→局部电感略减（只随半径对数变化）。
- 快速估算：50 mil表面走线→1.2 nH；63 mil板厚过孔（OCR存疑）→约1.6 nH。1 mil键合线的经验式/近似式/3D场求解器三者吻合（约100 mil长键合线）。
- 局部互感近似（一阶式6.9）：两段间距≫长度时可忽略。经验法则：**间距大于导线长度时，互感<自感的10%，可忽略**——两个20 mil过孔中心距>20 mil即几乎无耦合。

#### 6.7 有效（净/总）电感与地弹（p119-123）★地弹公式
- 回路中a、b两支路电流等大反向：某支路周围的净磁力线匝 = 自匝 − 互匝，即 N = (Lb − M)·I。这个 L_net = Lb − M 就是该支路的有效/净/总电感。
- **地弹**：返回路径上的电压降 V_gb = (Lb − M)·dI/dt（式6.11）。减小地弹只有两条路：①减小dI/dt（降边沿率、限制共用返回路径的信号数、差分信令）；②减小净电感 = 减小局部自感（短而宽、用平面）+ 增大互感（返回路径尽量贴近信号路径）。
- 键合线算例（1 mil直径、100 mil长、自感约2.5 nH）：间距>100 mil→净电感≈自感；间距5 mil→净电感1.3 nH（降>50%）。地弹：100 mA/1 ns切换，2.5 nH→250 mV，1.3 nH→130 mV。**设计规则：让返回电流尽量挤近信号电流。**
- 同向电流（两条电源键合线）：净电感 = L + M，互感是帮凶——**设计规则：同向平行电流间距应大于其长度**（100 mil长的电源键合线至少间隔100 mil）。
- 双键合线并联（同向电源电流）：每条净电感 L+M，并联等效 = (L+M)/2。算例：50 mil长、5 mil间距→L=1.25 nH、M≈0.5 nH→等效0.88 nH < 单条1.25 nH，并联有净收益。
- 电容焊盘多过孔：同向电流的过孔中心距应>过孔长度（互感可忽略，等效电感按并联数目下降）；电源过孔与地过孔（反向电流）应尽量近（间距<过孔长度），互感抵消自感、净电感减小。多过孔的另一大优点：加大与平面的接触面积→降低扩散电感，有时比降过孔电感更重要。

#### 6.8 回路自感与回路互感（p123-125）
- 回路自感（整条回路的自感）：L_loop = La + Lb − 2·Lab（式6.12；式中全是局部电感——很多教材没写明，是困惑之源）。两支路越近→M越大→回路电感越小。
- "回路电感正比于回路面积"的说法粗糙：面积相同、形状不同的回路电感可以不同；本质是每条支路周围净磁力线匝的累加。
- 环形线圈：L ≈ 32·R·ln(4R/d) nH（原书式6.13，OCR截断，按算例反推核对：30 AWG绕成直径1 in → 85 nH）。经验法则：拇指食指圈大小的回路≈85 nH，折合约27 nH/in圆周长。测量与近似误差仅百分之几。
- 平行双圆杆（一为返回）：L_loop = 10·Len·ln(s/r) nH（Len用in，s/r用mil；算例：键合线0.1 in长、s=5r → 2.3 nH，即23 nH/in）。回路电感与中心距的自然对数成正比（变化缓慢），与长度成正比。扁平电缆（r=10 mil、s=50 mil）→16 nH/in。
- 均匀横截面互连的单位长度回路电感恒定——这是后续特性阻抗讨论的基础。

#### 6.9 PDN与回路电感（p125-127）★
- PDN目标：每个芯片电源-地焊盘间维持恒定电压（约0.8~2.5 V量级，OCR存疑），噪声预算≤5%。稳压器反应慢（"嘴唇要频频舔杯子"类比），中间的过孔/平面/引线/键合线在电流突变时产生轨道塌陷。
- PDN低阻抗两原则：低频时加低回路电感的去耦电容；高频时使电容到芯片焊盘的回路电感最小。
- 去耦电容估算：C ≈ P·Δt / (0.05·V²)（由 t = 0.05·C·V²/P 反推）。算例：1 W、3.3 V、稳压器10 μs无响应 → 需约20 μF。
- 实际电容有等效串联电感（ESL，本质是安装回路的回路电感）：阻抗低频随频率下降，过自谐振点后上升；**SRF以上阻抗与电容量无关、只由回路电感决定**——高频减小阻抗的唯一方法是减小回路电感，不是加大容量。
- 实测佐证（图6.14/6.15）：6个容量10 pF~1 μF（OCR存疑）的0603，装连结构相同→高频阻抗趋于一致。
- 减小去耦电容回路电感四法：①电源/地平面靠近表层（缩短过孔）；②用小尺寸电容；③焊盘到过孔连线尽量短；④多电容并联。算例：单个2 nH、容许0.1 nH→至少并联20个。平面对是回路电感最低的互连结构。

#### 6.10 每方块回路电感（p128-129）
- 宽平面对（w≫h）、电流均匀从一边流向另一边：L_loop ≈ μ₀·h·Len/w，μ₀ = 32 pH/mil（原书单位表述）。
- 正方形区域（Len=w）的回路电感与边长无关：100 mil见方和1 in见方一样。这就是"每方块电感"（sheet inductance）的由来。
- 算例：最薄介质2 mil → 64 pH/方块；5 mil → 160 pH/方块。介质越厚→互感抵消越弱→回路电感越大→轨道塌陷、地弹、EMI全部恶化。**结论：电源/地平面尽量靠近。**

#### 6.11 平面对、过孔接触与扩散电感（p129-130）
- 实际电流经过孔点接触进入平面，不是均匀流动；均匀假设只为得到简单近似。
- 3D场求解器对比（1 in²平面、2 mil间距）：边沿接触→62 pH（与近似式64 pH吻合）；过孔点接触→252 pH，约4倍。这个增大叫**扩散电感**（spreading inductance）：接触点限制电流流动→电流密度高→局部自感增大。
- 规律：接触面积越大→扩散电感越小；含扩散电感的回路电感仍与介质厚度成正比。
- 与去耦电容相关的平面对回路电感主要由扩散电感决定，与电容距芯片远近关系较弱；但电容靠近芯片能把高频返回电流局限在芯片附近、远离I/O区，从而降低驱动外线电缆的共模电流和EMI。

#### 6.12 出砂孔（antipad）区域的影响（p130-131）
- 场求解器算例：0.25 in²平面、2 mil间距、孔径20 mil、antipad外径25 mil、空闲面积50%：无出砂孔→192 pH；有出砂孔→243 pH，约+25%。
- 出砂孔确实增大回路电感（电流被挤进孔间窄通道），但远没有传说中的"瑞士奶酪效应"那么可怕，增幅可控在2倍以内。
- 对策：出砂孔尽量小；缩小平面间距。最优电源-地互连=尽可能宽+尽可能近的平面对。

#### 6.13 回路互感与开关噪声（p131-132）
- 两独立回路间：Vnoise = L_m·dI/dt（式6.24），只在动态回路电流变化时出现——开关噪声/SSN。
- 减小途径：拉大两回路距离；或减小回路自感（因为互感≤两者自感的最小值）。这是第11章传输线串扰的伏笔。

#### 6.14 多个电感器的等效电感（p132-133）
- 必须计入互感：串联（同向电流）L_series = L1 + L2 + 2M；并联（同向电流）L_parallel = (L·L' − M²)/(L + L' − 2M)；等值特例 L_parallel = (L + M)/2（式6.27，与双键合线算例0.88 nH吻合）。
- 反直觉点：同向并联的两条路径靠得越近（M越大），等效电感越大；要减小并联等效电感应减小互感（拉开间距）。与双键合线"信号-返回反向靠近"的规则正好相反，勿混淆。

#### 6.15 电感分类（p133）——术语速查（事实性内容，完整记录）
1. 电感：流过单位安培电流时环绕导体的磁力线匝数（总称，需限定词）。
2. 自感：自身1 A电流环绕自身导体的匝数。
3. 互感：一条导体1 A电流环绕另一条导体的匝数。
4. 回路电感：环绕整个电流回路的匝数。
5. 回路自感：完整回路1 A电流环绕回路自身的匝数。
6. 回路互感：一个回路1 A电流环绕另一个回路的匝数。
7. 局部电感：假设其它地方无电流时某段导体的匝数。
8. 局部自感：仅一段导体有1 A电流、其它无电流时环绕自身的匝数。
9. 局部互感：仅一段导体有1 A电流时环绕另一段导体的匝数。
10. 有效/净/总电感：整个回路1 A电流时环绕某段导体的总匝数（含回路所有部分贡献）。
11. 等效电感：多个电感器串/并联组合后的单一电感值（含互感）。

#### 6.16 电流分布与集肤深度（p134-138）
- 直流时电流均匀分布；自感分内部自感与外部自感。外磁力线匝不随频率变化；电流集中于中心比分布于表面时匝数更多（内部匝贡献大）→电流越向外扩散，自感越小。
- 交流电流走最低阻抗路径：频率越高，内部（高电感）路径阻抗相对越大→电流趋向两个方向重新分布：①每根导体内向外表面集中；②信号与返回电流互相挤近。二者平衡决定最终分布（只能用2D场求解器算）。
- 圆柱导体电流密度从表面向中心指数衰减，等效为均匀厚度δ=集肤深度：δ = 1/√(π·f·μ₀·μr·σ)（式6.28）。铜（σ=5.6×10⁷ S/m、μr=1）：δ[μm] ≈ 66/√f[MHz]（式6.29，OCR原形；1 MHz→66 μm）。
- 经验法则：1盎司铜（约34 μm厚）在 f≥10 MHz 时趋肤效应主导电流分布。20 mil圆线约100 kHz起重新分布；1盎司铜微带线1 MHz仍均匀、10 MHz起重新分布。
- 电阻：高频时有效导电厚度≈δ，R_HF ∝ ρ/(w·δ) ∝ √f（式6.31）。1 GHz时δ≈2 μm，1盎司铜高频电阻约为直流的15倍（OCR"30/2=15"存疑，按34 μm计约17倍，量级一致）。22 AWG线圈实测电阻随√f上升（图6.25）。
- 电感随频率：低频 L = L_internal + L_external；高频只剩外部自感，内部自感趋于0 → 回路自感随频率升高而减小（微带线在略高于100 MHz后基本稳定，图6.26）。"高频"的工程定义：高于趋肤深度≪几何厚度的那个频率。

#### 6.17 高磁导率材料（p139）
- 只有铁、钴、镍（及合金42、Kovar等，μr约100~500，OCR存疑；铁氧体>1000）是铁磁体。μr>1只影响导体**内部**磁力线匝；外部匝穿过空气（μr=1）不变。
- 铁磁导线低频电感很大；约1 MHz以上内部匝消失，回路电感与同尺寸铜线相当。镍的集肤深度约为铜的1/5（μr≈100），电阻更高：实测镍线圈电阻是同频率铜的10倍，且随√f上升。
- 工程应用：合金42/Kovar引脚高频电阻高，故常镀银——让最高频分量走外表面高电导非铁磁层。

#### 6.18 涡流与镜像电流（p140-142）
- 导体电流变化→邻近大导电表面（平面/金属壳，可以完全悬空、不需要任何电气连接）感应电压→涡流→涡流的磁效应等价于平面下方等距处的**镜像电流**（大小相等、方向相反）。
- 镜像电流的互磁力线匝反向抵消→**悬空平面的存在本身就会减小回路的回路电感**；导线离平面越近，效果越强。
- 经验法则：电流回路与悬空平面的距离小于两导线总跨度（例：线宽5 mil、间距10 mil、跨度20 mil）时，涡流效应显著起作用。邻近平面总是减小回路电感。

#### 6.19-6.20 小结与复习题（p142-143）
- 小结10条与上文一致，最浓缩的两句：电感一切重要性源于感应电压 V=dN/dt；地弹=返回路径净电感上的 dI/dt 压降，解法是"短而宽的返回路径+信号贴近返回"。
- 复习题涵盖：电感定义自测、N=LI数值题、地弹估算（5 nH、20 mA、1 ns→100 mV量级）、多信号共用返回引脚的处理、1 GHz集肤深度、方块电感（40 mil介质→1280 pH/方块）与2 nH电容安装电感的对比等。

#### 第6章对本项目的启示
- **viaLoopInductanceNanohenry**：过孔≈圆杆局部自感，经验值25 nH/in（1 nH/mm）；63 mil板厚通孔≈1.6 nH（p117-118）。项目数值应与此对齐，且注意长度加倍增长超线性（含对数因子）。
- **回流地孔检查**：理论依据正是净电感 L−M 与镜像电流——回流地孔要"挤近"信号过孔（间距<过孔长度/板厚量级）才能有效抵消磁力线匝；间距大于长度时互感<10%、回流孔形同虚设（p118、p121-122）。
- **缝合孔阵列**：同向电流孔（同一网络的多个过孔）中心距>孔长即可，无需更密；电源孔与地孔（反向）应成对贴近。去耦电容焊盘下多打孔既降过孔并联电感又降扩散电感（p122、p129-130）。
- **覆铜+PDN**：方块电感 = 32 pH/mil × 介质厚度（2 mil→64 pH/方块），与方块边长无关（p128-129）；出砂孔空闲面积50%→回路电感+25%，DRC/DFM可对电源平面antipad密度设告警（p131）。
- **3W+串扰扫描**：互感噪声 V=M·dI/dt，且互感随间距超过导线长度后<10%自感——3W规则的物理下界其实是"间距 vs 导线长度"而非固定3W（p118、p131-132）。
- **powerDrop/IR-drop**：去耦时间公式与ESL主导的高频阻抗（并联N个电容→ESL/N）可写进PDN校验；扩散电感意味着电容焊盘接触面积是PDN设计变量（p126-130）。
- **载流计算器**：≥10 MHz（1盎司铜）时趋肤效应使有效截面收缩、电阻随√f上升（1 GHz时约15~17倍直流），基于直流截面的载流表在高频会过于乐观（p134-137）。

## 可操作改进建议

1. 【p104-105】阻抗估算器文档：声明IPC微带/带状线近似式误差可达20%，建议内置"50 Ω微带CL≈2.7 pF/in、带状线≈3.8 pF/in、经验3.5 pF/in"锚点用于结果自检；精度要求高的场景提示用户该用场求解器类工具。
2. 【p108】阻抗估算器/传输线1/6判据：表层走线的信号速度应使用εeff（窄微带线可<3，而非叠层Dk≈4）；如工具未建模覆盖层，注明阻焊层会使电容最多+20%（覆盖厚≈线宽时饱和）。
3. 【p100-101】powerDrop/DFM：把"板级平面对电容≈1000/h(mil) pF/in²（FR4）"作为去耦预算中的"可忽略项"明确标注，避免用户误以为平面电容可供电；平面定位为低电感通路。
4. 【p100-101、p126】载流/powerDrop工具：加入去耦时间校验 t = C·0.05·V²/P（或 C_min = P·Δt/(0.05·V²)），并给出"稳压器响应时间内电容需撑住5%跌落"的检查报告项。
5. 【p117-118】viaLoopInductanceNanohenry：以25 nH/in（1 nH/mm）和63 mil通孔≈1.6 nH作为基准回归值写进单元测试或注释；长导线电感用含 ln(2Len/r) 的近似而非纯线性外推。
6. 【p121-122】回流地孔检查：新增/调整规则——回流地孔与信号孔的间距阈值与过孔长度（≈板厚）挂钩：间距<孔长才显著降低净电感；间距>孔长的孤立地孔在报告中降权或提示"互感抵消不足"。
7. 【p122】缝合孔算法：同网络（同向电流）缝合孔间距>孔长即可（互感<10%自感）；电源-地成对孔（反向电流）尽量靠近；电容焊盘下允许/鼓励多孔并联（等效电感≈(L+M)/N量级下降，且降低扩散电感）。
8. 【p128-129】powerDrop/PDN报告：用"方块电感=32 pH/mil×介质厚"快速估算平面对电感（2 mil→64 pH、5 mil→160 pH），与叠层厚度联动输出。
9. 【p130-131】DRC/DFM新增检查项：电源/地平面上的antipad（出砂孔）密度——空闲面积约50%时回路电感+25%，可对高电流区域的antipad重叠/密度给出告警，建议孔径尽量小。
10. 【p131-132】串扰扫描：在3W判据外补充物理判据——两线间距大于其并行长度时互感<自感10%（可忽略）；对并行长段输出 V≈M·dI/dt 的开关噪声量级估算。
11. 【p134-137】载流计算器：对高频场景（≥10 MHz，1盎司铜）标注趋肤效应修正——有效厚度≈δ（δ[μm]=66/√f[MHz]），电阻随√f上升；避免高频载流评估直接用直流截面。
12. 【p127】PDN文档/工具提示：去耦电容高频阻抗只取决于安装回路电感（ESL）——输出"并联电容数下限 = 单个ESL/容许ESL"的快速估算（例：2 nH/0.1 nH→20个），并建议小封装、短焊盘引出、平面靠近表层。
