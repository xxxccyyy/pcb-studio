## 阅读方法

- 文本型 PDF：PyMuPDF 逐页提取文本（含 `===== 第N页 =====` 页标记），子代理逐页精读。
- 扫描型 PDF（Bogatin 第3版，521 页无文本层）：PyMuPDF 200dpi 逐页渲染 → Windows 内置
  OCR（zh-CN）逐页识别 → 子代理读 OCR 文本（代理们总结出 OCR 错字规律——"巧"≈5、
  "佣/開"≈000、"斡"≈µs、"gF"≈µF——关键数值全部用书中算例反推核验后才采信）。
- 笔记纪律：全部用自己的话归纳转述；事实性公式/数值/规则可记录；不整段照抄原文；
  每份笔记带"阅读覆盖声明"（页码覆盖 + 与预期章节差异的如实说明）。
