## 分章笔记

### 一、RC/RL/RLC 滤波器与衰减器（p241-252）

- 一阶 RC/RL 低通/高通：截止频率处输出衰减为 1/√2（半功率点）、相移 45°；RC 低通 fC=1/(2πRC)，RL 低通 fC=R/(2πL)。各级的输入阻抗最小值、输出阻抗最大值决定级联好不好：**前级 Zout,max ≪ 后级 Zin,min 才有好的电压耦合**。
- 接负载的代价（p242、p244、p246-247）：负载与 R 并联成 R' 后，RC 低通增益降为 R'/R 且截止频率上移，RL 低通截止频率下移。结论：滤波器参数必须按"带负载"状态设计，否则调好的截止点会漂。
- RLC 带通/带阻（p248-250）：f0=1/(2π√LC)，Q=XL/RT，BW=f0/Q；负载并联拉低总电阻 RT，Q 下降、带宽展宽。书中算例：500Ω 并 60Ω 负载得 54Ω，f0≈2055Hz。
- 补偿衰减器（p251-252）：电阻分压器在高频被寄生电容破坏；取 **R1C1=R2C2**（式2.91）可使衰减比与频率无关，其中一只电容做成可调以吸收杂散——这正是示波器 10:1 无源探头的补偿原理。

**对本项目的启示**：
1. "Zout≪Zin 才好耦合"是阻抗知识库条目的雏形：自动布线报告可对"高输出阻抗级驱动低输入阻抗级"的连接给出提示（不仿真也能按元件类型给出静态建议）。
2. R1C1=R2C2 体现"用可调参数吸收寄生"的思想——阻抗估算器也应开放校准入口（用厂家 L'/C' 实测值修正理论模型），与 p293 的 Z0=√(L'/C') 直接呼应。

### 二、瞬态电路（p252-264）

- 三条"突变规则"（p257）：电阻的电压/电流可瞬间跳变；**电容电压不能突变**（t=0+ 时表现为恒压源/开路）；**电感电流不能突变**（t=0+ 时表现为短路）。0-/0+ 初始条件法是解题核心。
- 通用解法：全响应 = 强制响应 + 自然响应，用初始条件定常数。四个可背公式（p255）：RC 充电 VC=VS(1−e^(−t/RC))、RC 放电 VC=VS·e^(−t/RC)、RL 励磁 I=(VS/R)(1−e^(−Rt/L))、RL 去磁 I=(VS/R)e^(−Rt/L)。
- 二阶串联 RLC（p260-264）按 R² 与 4L/C 的大小分三态：过阻尼（缓慢无过冲）、临界阻尼（R²=4L/C，最快回到零且不过冲）、欠阻尼（R²<4L/C，衰减振荡，ω≈1/√LC）。能量在 C 与 L 之间来回搬运、被 R 逐步消耗——即"阻尼谐振子"，与机械减振器同构。
- 该方程在工程中的化身：继电器线圈断电尖峰（后见 p327）、开关电源振铃、感性负载反电动势。

**对本项目的启示**：
1. V=L·dI/dt 给出"开关回路面积最小化"的理论根据：大 di/dt 环路的寄生电感直接产生尖峰与 EMI。模拟退火布局的目标函数可加入"高 di/dt 网络环路面积"惩罚项，DRC 可输出环路面积报告。
2. 欠阻尼振铃提示：快速开关沿 + 走线电感 = 振铃。工具可在高速开关网络（MOSFET/继电器/电机）附近建议预留 RC snubber 位置（snubber 元件值可参考 p327 的 100Ω+0.05µF 起点）。

### 三、傅里叶级数与非周期源（p265-273）

- 周期非正弦信号（方波/三角/锯齿）= 正弦叠加（傅里叶级数，式2.98-2.104）：对每个谐波分量用复阻抗单独求解、再叠加（叠加定理）即可避免解微分方程。**半波对称的波形只含奇次谐波**（方波是典型）。
- 方波激励 RC 电路的两种等价解法（p270-271）：谐波逐项叠加，或按半周期分段解瞬态方程再周期延拓。
- 非周期信号 → 傅里叶变换（式2.105-2.107）：I(ω)=V(ω)/Z(ω)，分析套路为"时域→频域→除阻抗→逆变换"。矩形脉冲的频谱能量集中在约 1/τ 带宽内（p273，τ 为脉宽）——脉冲越窄、沿越陡，频谱越宽。

**对本项目的启示**：
1. "边沿速率决定有效频率"是 3W/阻抗/载流检查取频率的依据：数字信号的有效频率由边沿（脉宽倒数思想）而非时钟频率决定。AI 接口回答"3W 检查按什么频率算"时，应取由 tr 推得的谐波上限。
2. 方波过 RC 变圆、过 LC 振铃：与上节一起支撑"高速线长控制 + 端接"建议的物理背景。

### 四、SPICE 电路仿真原理（p274-280）

- 历史（p274）：CANCER → SPICE1（1972，节点分析）→ SPICE2（1975，改进节点分析 MNA，纳入电压源与电感）→ SPICE3（1985，C 语言、图形界面）。商业分支有 HSPICE/PSPICE 等。
- 核心算法（p276-278）：KCL 列节点方程，改用电导 G=1/R 记账更整洁；矩阵化 **G·v = i，解 v = G⁻¹·i**（式2.108-2.110）。DC/AC/瞬态分析的内核都是这步节点求解，区别只在把元件如何折算进 G 与 i。
- 局限（p278）：精度受限于器件模型；默认不含噪声、串扰、干扰（除非显式建模）；不能预测元件失效；书中原话精神：**仿真不能替代实物样机**。

**对本项目的启示**：
1. v=G⁻¹·i 是本分册对项目最值钱的算法：把电源平面/走线/过孔按网格离散为电阻网络，叠加各 IC 的静态电流，即可做 **PDN IR-drop 分析**——零依赖 JS 完全可实现（稀疏矩阵 + 高斯消去或共轭梯度），产出压降热图与电流密度热图，成为嘉立创 DFM 之外的自有检查亮点。
2. PathFinder 的"代价协商"与 MNA 的"约束转方程迭代"哲学一致，可互为文档类比。
3. 书中"SPICE 默认不给"的清单（串扰/压降/失效）恰是本工具的差异化卖点清单：3W、IR-drop、载流检查要显式做。

### 五、导线、电缆、连接器与传输线（p282-300）

- AWG 线规表（表3.1，p283-284）：号数越大线越细、电阻越大、载流越小。摘录：10AWG≈2.59mm/14.8A/3.28Ω/km；12AWG≈9.3A/5.21Ω/km；18AWG≈2.3A；22AWG≈0.64mm/0.91A/53Ω/km。橡胶绝缘线载流再降 30%。实心线易折断，绞线柔性好且表面积大，编织线常用作屏蔽。
- **趋肤效应**（p291-292）：高频下电子被推向导体表面、中心失去导电电子，AC/DC 电阻比随频率急剧上升（表3.2：22AWG 在 1MHz/10MHz/100MHz/1GHz 分别为 6.9/21.7/68.6/217 倍；10AWG 在 1GHz 达 873 倍）。对策是绞线（增大总表面积）。
- 传输线模型（p292-294）：电缆等效为单位长度 L'、C' 的分布网络，特征阻抗 **Z0=√(L'/C')**（纯实数，表现为纯阻性）。同轴 Z0=(138/√k)·log(b/a)，平行双线 Z0=(276/√k)·log(D/a)。介电常数表（表3.3）：空气 1.0、聚四氟乙烯 2.1、聚乙烯 2.3、纸 3.0、石英 3.8、派热克斯玻璃 4.8、云母 5.4、聚苯乙烯 5.1-5.9。算例：RG-11AU（21.0pF/ft、0.112µH/ft）→ Z0=73Ω；RG-8A/U 53Ω；300Ω 扁馈线。
- 失配与反射（p295-298）：用"低密度绳接高密度绳"类比反射与波长变化。VSWR=Vmax/Vmin=(VF+VR)/(VF−VR)；纯阻负载时 VSWR=ZL/Z0 或 Z0/ZL（取大于 1 者）；**反射功率%=((VSWR−1)/(VSWR+1))²×100%**。算例：50Ω 线接 200Ω 负载 → VSWR=4，36% 反射、64% 吸收。
- 匹配手段（p299-300）：电阻 L-pad（R_A=Z1·√(1−Z2/Z1)，R_B=Z2/√(1−Z2/Z1)，Z1 为高阻侧，有固有插损）、变压器匹配 NP/NS=√(Z0/ZL)（例：800Ω 匹配 8Ω，匝比 10:1）、宽带传输线变压器（0.1-500MHz 损耗<1dB）、**1/4 波长段** Zsec=√(Z0·ZL)，长度 λ/4，波速 v=c/√k（例：50Ω 匹配 200Ω@100MHz、k=1 → 段长 0.75m、Zsec=100Ω）、开路/短路短截线（stub）并联调匹配。
- 工程口径（p298）：信号波长远大于线长的低频场合无需匹配；匹配主要是高频需求。

**对本项目的启示**：
1. AWG 表的"线径-电阻-载流"三元组是 PCB 走线的宏观镜像：载流计算器结果可附"相当于 X AWG 导线"的旁证，便于工程师直觉校验。
2. 趋肤效应表（表3.2）是高频载流修正的现成数据源（建议1）。
3. 介电常数表 + Z0=√(L'/C') 双通道校准可补强阻抗估算器（建议3）。
4. VSWR/反射公式、L-pad、1/4 波长段、stub 是从"连通"升级到"信号完整性"的增值检查素材（建议4、5）。
5. 双绞（磁场抵消）、同轴（几何限场）、平衡电缆屏蔽层只屏蔽不载流（p286-287）→ 差分对、地保护线、缝合孔的知识库条目（建议11）。

### 六、电池（p300-319）

- 电化学原理（铅酸示例，p302-303）：两种化学性质不同的电极 + 电解液，放电生成硫酸铅晶体，充电逆向；晶体脱落成"沉泥"、过充失液是老化和容量衰减的根源。
- 一次电池对比（表3.5，p307）：碳锌 1.5V（廉价但易漏液、电压持续下滑）、碱性 1.5V（内阻很低、通用主力）、锂锰 3.0V（自放电极低、货架期约 10 年）、锌空 1.45V（能量密度高、撕开封条激活、工作约 60 天）等。
- 二次电池对比（表3.6，p313）：SLA 2.0V（最便宜、自放电约 5%/月、必须满电存放否则硫酸盐化、充 8-16h）、NiCad 1.2V（耐深循环约 1000 次、有记忆效应）、NiMH 1.2V（比 NiCad 容量高 30-40%、部分记忆效应）、Li-ion 3.6V（能量密度最高、无记忆、必须带保护板：充电截止约 4.30V/cell、90°C 温度断开、过流压力开关）、NiZn 1.65V、NiFe（寿命 30-80 年但笨重）。锂电池不可浮充/涓流充。
- 超级电容（p314-315）：0.22F 至数 F；串联 3-4 只以上必须加均压；能量密度约为电池的 1/5-1/10，自放电显著；最佳用法是与电池并联滤除脉冲负载电流。
- 容量与 C 倍率（p316-318）：理想放电时间 t=容量/负载电流（1800mAh@120mA→15h）；C 倍率下 t=1h·C/C率（1C 放 1 小时、2C 放 0.5 小时）；大电流下实际容量低于标称（内阻损耗 + Peukert 效应），必须查厂家放电曲线。
- 内阻典型值（p318-319）：AA 碱性 0.15Ω（新）→0.30Ω（50% 放电）→0.75Ω（90% 放电）；9V 碱性 1-2Ω；AA NiMH 0.02Ω；D NiCad 0.009Ω；D SLA 0.006Ω。内阻决定大电流脉冲供给能力，端电压 = 开路电压 × RL/(RL+Rin)。

**对本项目的启示**：
- 与布线直接相关度不高，但"内阻→压降→大电流能力"链条支撑电源路径压降预算检查（建议10）：大脉冲负载（电机、功放、射频）的供电路径应按最坏内阻 + 走线电阻核算电压裕量，这类网络在布局中应短粗优先。

### 七、开关与继电器（p319-328）

- 开关命名：极（pole）×掷（throw），SPST/SPDT/DPDT/3P6T；瞬时触点分常开（NO）/常闭（NC），转换开关可有中位 off。类型涵盖拨动、按钮、微动、旋转、磁簧、DIP、水银倾斜、二进制编码开关等（p321-323）。
- 继电器三类（p324-326）：机械式（2-15A、10-100ms、线圈激励 6/12/24VDC 或 110/240VAC）、干簧式（0.5-1A、0.2-2ms、PCB 安装）、固态 SSR（光耦 + Triac/MOSFET 或 IGBT，µA 至 100A、1-100ns，控制侧与负载侧电气隔离，AC 型过零导通）。
- 使用要点（p327）：线圈电压须在额定 **±25%** 内（过高烧线圈、过低抖动）；**线圈即电感，断流瞬间磁场坍缩产生尖峰，可达 1000V**，会击坏开关触点、晶体管并干扰邻近电路。
- 抑制手段（p327，图3.45）：DC 线圈并联续流二极管（通用 1N4004，须能承受线圈最大电流）；AC 线圈不能只并二极管（会半周短路导通），应并 RC 串联网络（R=100Ω、C=0.05µF 起步，耐压按线路电压选）或双向 TVS/MOV。继电器驱动典型电路：2N2222 NPN + 基极限流电阻 + 续流二极管（p328，图3.46）。

**对本项目的启示**：
- 这是 DRC/DFM 新规则的最佳素材（建议7）：识别继电器/线圈/螺线管/电机网络 → 检查驱动回路是否就近放置反向续流二极管或 RC 缓冲 → 检查该强电回路面积是否最小。书中连器件型号与参数起点都给出了，规则可直接写成检查项与提示文案。

### 八、电阻器（p328-352）

- 基本功能与功率（p329-331）：限流、定电平；P=IV=I²R=V²/R。算例：12V/100Ω → 1.44W；**经验规则：额定功率取计算值的 2-4 倍**（本书两处分别说"至少 2 倍"与"2-4 倍"，取保守）。环境温度、封闭、成组、脉冲都会改变所需额定值。
- 串并联、分压/分流、KVL/KCL（p331-333）：基础公式，用于快速校核。
- 标识（p333-334）：色环 4/5 环制；SMD 三位/四位数字码，R 表小数点（1R0=1.0Ω），尾字母表容差（F=±1%）。**警告：白/蓝本体是不可燃或可熔断电阻，维修时严禁用普通电阻替换，否则有火灾风险**。
- 真实特性（p335-342）：
  - 额定电压 V=√(P·R)；1/2W 常见额定仅 250-350V，高压场合需选专用高压电阻。
  - 容差谱系：碳合成 5-20% → 碳膜 1-5% → 金属膜 ~1% → 精密金属膜 0.1% → 精密线绕 ±0.005% → 箔电阻 0.0005%。
  - 功率降额：额定在 +25°C 标定，超过后按厂家降额曲线线性下降；温度反复变化会永久改变阻值。
  - 温度系数 TCR：碳膜 500-800ppm/°C（且为负）、金属膜 50-100、精密膜 2-20、箔 0.2、精密线绕低至 3ppm/°C。精密场合匹配 TCR 比绝对值更重要。
  - 频率响应：线绕电阻因线圈电感 50kHz 以上即不可用；膜类最稳（约至 100MHz 阻抗不变）；高频优选小尺寸、长径比 4:1-10:1。
  - 噪声三类：热噪声 Vrms=√(4kRTΔf)（k=1.38e-23，与材料无关，唯一手段是减小阻值）；接触噪声（1/f，正比于直流电流，**加大瓦数/体积可降低**）；散粒噪声（正比于直流电流）。低噪声首选精密线绕与精密膜，碳合成最差。
- 类型速览（p343-348）：精密线绕（DC 精密基准）、功率线绕（底盘安装带散热鳍可达 5 倍额定）、金属膜（综合最优，快沿/高频首选）、碳膜（最普及但漂移大）、碳合成（容差差噪声大，但耐短时过压冲击，适合高压电容放电回路）、箔、厚/薄膜（厚膜耐浪涌能力高出 1-2 个数量级）、金属氧化膜（耐脉冲、阻燃、snubber 用）、**可熔断电阻（熔断特性与安装/散热方式强相关）**、排阻、水泥电阻（1-20W）、**0Ω 跳线（p348）：贴片机友好、跳线间电容极低、适合高速数据线跨线、改善布板性能**。
- 电位器（p349-352）：线型/对数抽头（音量用对数）、多圈精调、联动双联；分辨力、接触电阻、hop-on/off；新编码 A=对数、B=线性（旧编码 A=线性、C=对数，极易混淆）；**功率额定按整个电阻体均匀发热假设——若只用 1/4 行程承担额定功率会迅速烧毁；碳膜电位器滑触点忌通过直流（电迁移导致开路/噪声）**。数字电位器=码控电阻阵列，可做增益/截止频率程控。

**对本项目的启示**：
1. 功率降额曲线与成组/封闭/风冷修正系数（F1-F7，p338 图3.55，例：4 只 115W 密闭于 50°C 需按 2.64 倍选 304W 额定）是布局热规则最具体的量化依据（建议6）。
2. 噪声条目 → 低噪声模拟前级布局知识（前级用金属膜、大瓦数=大面积=低接触噪声、远离数字走线）。
3. 0Ω 跳线的官方背书 → 自动布线失败时的跨线方案（建议9）。
4. 白/蓝本体可熔断电阻警告、可熔断电阻安装方式影响熔断电流 → 写入 AI 使用手册知识库与 DFM 提示。

### 九、电容器（p353-360）

- 四大用途（p354）：储能/定时（RC 充放电）、隔直通交（耦合电容）、并联到地泄放高频（去耦/旁路）、滤波/谐振/RC snubber。
- 串并联（p355-356）：并联容量相加（耐压取决于最低那只）；串联容量倒数相加（总耐压相加，但电压按容比分配不均——**均压措施：每只并约 100Ω/V 的均衡电阻**，且真实漏电差异对分压影响可能大于容量差异）。
- RC 时间常数（p356-357）：τ=RC；1τ 充到 63.2%、2τ 86.5%、3τ 95%、**5τ=99.24% 视为充满**；放电对称。
- 容抗 XC=1/(2πfC)（p357-358）：纯电抗不耗能，每周期储能还给电路。
- 真实电容四参数（p358-360，图3.64 等效模型）：
  - 漏电 RL：电解电容 5-20nA/µF（不适合储能与高阻节点），聚丙烯/聚苯乙烯膜绝缘电阻 >10⁶ MΩ；
  - **ESR**：ESR=XC/Q=XC·DF，发热 P=I²rms·ESR——大纹波电流场合（电源去耦、滤波）必须低 ESR，mica 与膜类最低；
  - **ESL**：卷绕结构（电解/纸/薄膜）在几 MHz 以上自感显著、"更像电感"；**多层独石陶瓷**（金属膜并联汇流而非卷绕串联）是高频去耦首选；盘式陶瓷反而常偏感性；引线长度决定自谐振频率；
  - 介质吸收 DA：类似迟滞的"充电记忆"，独石陶瓷 DA 大，不能做采样保持电容。
- DF（损耗因数）=1/Q，必须指明频率才有意义。

**对本项目的启示**：
- 去耦/旁路的机制与 ESL 结论直接支撑布局规则（建议8）：去耦电容"就近 + 低感回路（短引线、少过孔、宽线）"；大容量电解负责储能、小容量多层陶瓷负责高频，软件可按网络类型（电源入口/IC 引脚）给出不同容量与数量建议，并把回流路径长度计入等效 ESL。
- 串联电容均压电阻（约 100Ω/V）→ 高压板设计检查条目。

## 可操作改进建议

1. **载流计算器增加趋肤效应修正**（p291-292，表3.2）：高频交流电流集中于导体表层，AC/DC 电阻比随频率陡增（22AWG：1MHz 6.9 倍 → 1GHz 217 倍）。对高速信号线发热/载流评估，按趋肤深度 δ=√(2ρ/ωμ) 或内置比值表折算有效截面，并在报告中标注"DC 载流 / 高频有效载流"两档。→ 载流计算器
2. **新增电源网络 IR-drop 求解器（节点电导矩阵）**（p276-278）：移植 SPICE 核心 v=G⁻¹·i：把电源平面/走线/过孔按网格离散为电阻网络，输入各 IC 静态/峰值电流，稀疏高斯消去求解，输出压降热图与电流密度热点。零依赖 JS 可行，是区别于普通 DRC 的自有亮点检查。→ 新检查器
3. **阻抗估算器补充介质库与双参数校准**（p293-294）：内置介电常数表（空气 1.0、PTFE 2.1、聚乙烯 2.3、纸 3.0、石英 3.8、玻璃 4.8、云母 5.4），允许自定义板材 k；支持厂家给的单位长度 C'(pF/长度) 与 L'(µH/长度) 经 Z0=√(L'/C') 反推校准，与 IPC-2141 微带/带状线公式互校。→ 阻抗估算器
4. **高速网络反射/失配检查**（p295-299）：对长线或无端接网络，按 VSWR=ZL/Z0 与反射功率公式 ((VSWR−1)/(VSWR+1))² 估算失配损耗；报告建议串联源端匹配电阻或 L-pad/戴维南端接，并注明"波长远大于线长的低频网无需匹配"（p298）以免误报。→ 新检查器
5. **残桩（stub）长度检查**（p300）：开路/短路短线在 λ/4 处呈极端阻抗，是高频灾害源。对高速网络的分支与过孔残桩，当 l≈λ/4（λ=v/f，v=c/√k）量级时告警，建议改拓扑或缩短残桩。→ 布线拓扑检查
6. **布局热降额规则**（p331-338，图3.55）：功率元件功耗按 P=I²R 计算，额定裕量 2-4 倍；环境 >25°C 线性降额；成组/密闭/无风冷按修正系数放大（书例：4 只 115W 密闭 50°C → 每只按 304W 选型）。布局阶段为高功耗元件自动建议散热铜皮扩展、加大间距或靠板边，退火目标函数加入局部热密度项。→ 布局器 + DRC
7. **感性负载驱动检查（续流二极管/RC 缓冲）**（p327-328）：识别继电器/线圈/电机网络，检查驱动回路是否就近放置反向续流二极管（DC，如 1N4004）或 RC 缓冲（AC，100Ω+0.05µF 起步）或 TVS/MOV；同时检查该回路面积最小。提示文案可直接引用书中的 1000V 尖峰数据。→ DRC 新规则
8. **去耦电容规则库与检查**（p354，p359-360）：按 ESL/ESR 结论分级建议——IC 电源引脚就近多层独石陶瓷（低 ESL）、电源入口大容量电解/薄膜（储能）；回流回路（引线+过孔）长度计入等效 ESL；大纹波去耦按 P=I²rms·ESR 校核发热；提示盘式陶瓷偏感性、卷绕电容几 MHz 以上失效。→ DFM/布局提示
9. **0Ω 跳线/跨线支持**（p348）：自动布线失败时按序尝试插入 0Ω 电阻跨线（书证其跨线间电容低、适合高速数据线、贴片机友好），在 Gerber/BOM/贴片坐标中输出跳线位号，布线器把跳线视为可跨越障碍的"桥"。→ 布线器 + 交付输出
10. **电源路径压降预算检查**（p318-319，p283-284 表3.1）：以典型内阻（AA 碱性 0.15Ω→0.75Ω、9V 碱性 1-2Ω、D NiCad 0.009Ω、D SLA 0.006Ω）与导线电阻（22AWG≈53Ω/km、10AWG≈3.3Ω/km）为参数，对"电源入口→稳压器→大负载"路径按最坏情形做电压裕量核算，不足则建议加宽/加铜。→ 载流计算器扩展
11. **差分/敏感线知识库条目**（p286-287）：双绞靠磁场抵消、同轴靠几何限场、屏蔽层只作屏蔽不载流、屏蔽层接地才有效——映射为：差分对等长等距紧耦合、敏感模拟线两侧地保护线、覆铜+缝合孔形成屏蔽（项目已有缝合孔功能，可把"屏蔽区独立回流"写进其放置准则）。→ 布线规则 + 文档
12. **上电/开关瞬态提示**（p252-258，p357）：电容电压不能突变、电感电流不能突变——大容量储能电容的热插拔浪涌路径建议限流元件并远离敏感走线；RC 时间常数表（1τ 63.2%、5τ 99.24%）用于复位/上电时序类网络的说明文案；"强制响应+自然响应"框架可写进 AI 接口的知识问答库。→ AI 接口知识库
