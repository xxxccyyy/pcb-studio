# PCB Studio 引擎能力白皮书

> 版本 0.1.0 · 2026-11-08
> 本文档的全部结论来自 11 轮 / 182 个实战项目的实测记录（docs/第十一轮实测报告.md 及其前十轮），
> 每一项都可在 projects/ 目录下复现。数据驱动，不含营销性表述。

## 1. 这是什么

一个零依赖、纯本地运行的 PCB 自动布局/布线/检查/交付引擎，三种形态同一内核：

| 形态 | 入口 | 用户 |
|---|---|---|
| 桌面工具 | 双击 index.html（浏览器工作台） | 人工设计 |
| 无头 CLI | `node ai/pcb.mjs <命令>` | AI 代理 / 脚本流水线 |
| 可嵌入引擎 | `import { placeAndRoute, checkDRC, … } from 'engine.mjs'` | 二次开发 |

### 2.2 规模与密度（定量曲线，第十一轮）

| 维度 | 已验证范围 | 曲线/结论 |

## 3. 质量体系（为什么可以信它的 DRC）

```
spec 门（六项前置拦截：坏引用/单脚网/空网/同元件间距/出板含半孔豁免/THT 环宽/零格覆盖）
  → 布线（协商 + 历史最优保留 + 停滞自适应 + 几何间距修正回路）
    → DRC（多层语义 + DFM 铜厚感知 + 间距精确线段审查）
      → verify 写后回读对账 → render 视觉自检
        → 261+ 项回归（含 22 项优化锁定测试、模糊测试、深度校验）
```

- **11 轮 182 项目**：每轮报告含失败与返工的诚实记录（docs/）。
- **修复=定理+测试**：22 项优化锁定测试（罚金下限/口袋罚/孔边距/弦拉直精确化/
  圆焊盘方形化/禁布缓冲/薄焊盘格心…），每项都有 A/B 验证记录。
- **影响区模型六件套**与 DRC 契约逐一对齐（焊盘 halfClr / 圆外接方 / 禁布缓冲 /
  板边带 / 真铜属主 / 零格保障）——布线合法 ⊆ DRC 合法。
- **证伪留档**：启发式缓存（命中率 1.3%）、密度自适应罚、影响区墙理论、
  铺铜契约假设——四个被实验推翻的方向均有记录，防止重复踩坑。

## 5. 工艺口径（嘉立创）

DFM 锚点全部内建：1oz 双面线宽 0.10（多层 0.09）、过孔 0.15/0.25、环宽 0.18、
孔边距 0.20、阻焊桥 0.10、线宽公差 ±20%。OSHPark/PCBWay 预设同源。
载流按 IPC-2152 口径内插；阻抗一阶估算（微带/带状线）；20H/直角/3W 等按
"可靠/有条件/勿信"三级知识库给出证据（books 研读，页码可查）。

## 6. 接口

- CLI：`node ai/pcb.mjs schema|rules|spec|erc|place|autopcb|route|drc|advise|verify|pour|drop|pdn|render|bom|pos|device|part|schem|export`
- 互通：KiCad .kicad_pcb 导入；Specctra DSN 导出/SES 回读（Freerouting）；
  嘉立创EDA PCB+原理图 JSON；Gerber/Excellon/IPC-356A
- 嵌入：`import { placeAndRoute, checkDRC, … } from './src/engine.mjs'`
