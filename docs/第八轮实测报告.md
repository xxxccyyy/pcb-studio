## 二、已验证教训（先实验验证再记录）

### L26 圆焊盘影响区弦缺口 → 引擎修复（本轮核心）

- **现象**（n103）：DRC 报「走线距焊盘 L1-3 过近 0.39 < 0.40」——差 0.01mm。布线器格点模型判定合法。
- **根因**：圆焊盘影响区按**圆弧**逐格标记。格点中心采样在弧线两格之间留出**弦缺口**（本例格点余量仅 0.006mm），走线弦恰好从缺口穿过：格点合法 ⊉ 段合法。矩形焊盘无此问题（影响区是矩形，斜移"占用两个正交格"规则恰好封死切角路径——可证）。**圆弧是唯一没有这类几何保护的形状。**
- **修复**（engine.mjs buildModel）：圆焊盘影响区改用**外接方形**（distToRect 方形）——方形享受矩形防切角定理，布线合法 ⊆ DRC 合法；**起始格（padCells）保持圆真值**——格心必须真落在铜上才算连通（否则假连通）。
- **A/B**：n103 修复前 1 错 → 修复后 **0 错**；255 项回归全过；THT 重灾项目复测（n61 CAN/DIP-8、n83 PLC/DIP-4×8、n92 胆座/圆周 THT、n57）全部无回退。
- **永久测试 17ab**：模型级（弧缺口格被覆盖 + 圆外角格不得为起始格）+ 行为级（圆焊盘密集板布线后走线-焊盘 0 违规）。
- **泛化**：L21 教训的推广——**凸障碍的影响区标记必须与线段几何的保护定理匹配**：矩形有斜移守卫，圆没有；给圆换上矩形的形状，就继承了保护。这是 H1/L7/L13/L21/L22/L26 六例"近似判断当精确判断用"的谱系。

### L27 铸铜半孔的环宽口径（n110，spec 级修复）

- **现象**：20 个邮票孔报「环宽 0.00mm < 0.18」——半孔（castellated）圆心在板边，孔一半在板外，按全孔口径环宽为 0。
- **定性**：DRC 环宽检查假定全孔；半孔工艺实际只需板内半环，**是 DRC 契约的已知空档**（如实记录，本轮不改契约）。
- **spec 级解法（已验证）**：孔 0.7 / 盘 1.1 → 环宽 0.2 满足全孔口径，半孔照常工作（106 焊盘全绿）。roadmap：DRC 环宽检查对「圆心距板边 < holeR」的 castellated 特征按半环计算。
- **连带发现**：spec 门与生成器自检需对半孔豁免"出板"（圆心距板边 < holeR 的圆形带孔焊盘 = 铸铜特征）——已同步实现于两处。

### L28 L1 对照表第四连证（n110）

- **现象**：LQFP48（0.5mm 节距）在 grid 0.5/halfClr 0.3 下：**45% 布通 + 32 DRC 错**——引脚侧向全部封死。
- **A/B**：按 L1 表 0.5 QFN/LQFP 档（grid 0.25/线 0.15/距 0.1/孔 0.5·0.25）→ **98/98 全绿（112.9s）**。
- 第五轮 L1 表连续第四轮（R5 n44/n48、R6 n64/n68、R7 隐性、R8 n110）证明：**细间距 spec 必查表，凭感觉选 grid 就是封死引脚**。

### L29 D-sub 类大孔三联动（n99，L15 家族）

- **现象**：DB-9 信号孔 1.0mm/盘 1.25mm → 环宽 0.125 < 0.18，9 错。
- **修复**：盘 1.4×1.8 → 环宽 0.2 ✓（节距 2.84 间隙仍 1.44 ✓）。A/B：9 错 → 0。
- 连同 R5 环宽、R6 to92、R7 spec 门，**THT 三约束（孔径/环宽/间隙）联立解已是第四次出现**——spec 门（L25）已内置环宽检查，本轮 n99 是首个被"本可由 spec 门拦截却漏跑"的案例（生成器自检没跑环宽项——已同步补上）。

### L30 正收益：结构与拓扑新维度首测全过

- **保护环（n109）**：manual gnd 环围绕敏感走线、右侧留 2.2mm 环口——布线器从环口进入完成 in_sig 布线，**固定铜环几何全可用**（1s 全绿）。高阻前端布局约束（guard ring）从此可表达。
- **BLDC 霍尔换相全链（n108）**：TQFP32 + 3× 霍尔 + 6× SOT-89 三相桥 + 相线端子——传感+功率全链 73/73 全绿（31s）。
- **THT 功率谐振（n104/n105/n106）**：Royer 变压器谐振、ZVS 全桥大电流、多绕组 PSU（大电解+桥堆）——THT 功率拓扑全过。
- **开尔文四线（n101）**：shunt 4 端结构（force/sense 并排）修复后 0 过孔直连——Kelvin 采样走线与大电流路径自然分离。
- **异形连接器全家**：D-sub D 形双排（DB-9/15）、SD 卡座单侧+检测脚、U.FL 0.35mm 微焊盘、SMA、EC11 非对称、拨动/轻触开关——12 种连接器/开关形态零引擎改动。
