## 2. 优化内容（全部位级一致）

### T1-1 堆 push/pop 局部变量化（astar 内闭包）
heapStates/heapCosts/heapSize 拷贝进局部：push/pop 各自入口完成唯一一次 heapSize
增减后，筛化循环内以局部快照 hs 与局部数组引用读写，消除逐层上下文槽读。
**位级依据**：筛化算法逐行一致 → 弹出序逐位一致（堆 tie-break 语义未动——4-ary 化/
懒删除都会改等值弹出序，禁止，见 §4）。

### T1-2 邻居环 enterOK 内联 + 会话常量外提
astar 邻居环的 `enterOK(net,ns,hard)` 闭包调用展开为逐字段同序的直读链
（pairBand → blocked → scoped → fixedOwner → padOwner → viaInf → hard）；
`S.pairBand`/`model.scopedBlocked` 外提为 astar 局部常量。
**位级依据**：字段判定序与 enterOK/passable 逐行同源；hard 段 own 判定
`net.cells.has(s)` 与 `ownStamp[s]===gen` 在本次 astar 生命周期内恒等
（ownStamp 入口自 net.cells 全量置位，commit/rip 均发生在 astar 之外）；
外提常量会话内不变。纯读判定无副作用，短路结果逐位一致。

### T1-3 斜向双正交格 passable 内联
`if(!passable(net,s1)||!passable(net,s2))` 同口径展开（passable 段无 pairBand/hard）。
**位级依据**：同 T1-2。

### T1-4 pairBonusGet 邻居环内联
`pairBonusGet(ns)` 闭包调用 → typed 直读 + Map 回退原样。
**位级依据**：pairBonusTyped 会话内只增不减，非空性环外可判定；回退路径保留。

## 4. 评估后放弃（留档防重踩）

1. **H 距离图会话缓存**：第九轮已证伪（engine.mjs computeH 注释留档：命中率 1.3%——
   RMST 逐边目标集含动态布线格，键几乎不重复）——不重踩。
2. **过孔环缓存跨 astar 调用持久化**：环值内嵌本网 own 调整 → 跨网不能复用（键需含网
   身份），仅 ≥3 焊盘网第 2 条边起有收益；预估总收益 2-4%，代价是全 usage 变异点
   脏标记 + 测试契约重写（via-ring-cache 测试锁定"gen 变化即失效"口径）。收益/风险比
   不足，放弃。
3. **4-ary 堆 / 懒删除堆**：改变等值键 tie-break 弹出序 → 非位级一致，禁止。
4. **fillDistanceMap gen-stamp 替代 fill**：不可达格读旧值 <BIG → 启发式口径漂移 →
   搜索序变化，非位级一致，禁止。
5. **viaLegal/segDist/shpBuildGraph**：已是快路径或冷路径（合计 <8%），剩余空间薄。
