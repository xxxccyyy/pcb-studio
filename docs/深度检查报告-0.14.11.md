## 检查项与结果

### 1. 保序性论证（逐步复核）——成立

- **pad-pad 捕获完备性**：桶边长 ≥ _padR2 时，|dx| ≤ _padR2 的对满足 b ∈ [a−c,a+c]
  ⊆ [a−cell′,a+cell′] → floor(b/cell′) ∈ {ca′−1, ca′, ca′+1}（区间论证，含边界）→
  ±1 邻桶扫描捕获全部存活对 ✓；候选按 j 升序 = 原内层序；逐对检查链（netId→
  external→bbox→layer→gap）与原序一致 → findings 序逐位一致 ✓。
- **桶索引 clamp 安全性**：板外焊盘（x<0 / x>width）clamp 到边缘桶——clamp 只会把
  越界 cell 移到 0 或 _nbX−1，而 |dx|≤c 的对若一方越界则另一方必在 ca=0/_nbX−1 →
  clamp 后仍相邻 ✓（分类讨论验证）。
- **seg-pad 按层桶化**：padOnLayer 展开到层号与原循环的逐段层检查同集合；候选按
  pad 索引升序 + 首违 break = 原语义 ✓；cell′ ≥ 所有段的 _sR 上界（half≤maxTrackW/2）
  → bbox+margin 覆盖桶范围完整 ✓。
- **add() 200 条封顶交互**：封顶只截断 push、家族循环仍完整求值 → 总数 = min(200,
  Σ家族 findings)；桶格求值序 = 原序 → 被截断的前 200 条逐位相同 → 封顶态的
  error 计数逐位一致 ✓。

### 2. 实质发现：稠密桶分配无上界（已修复）

桶数组按 ceil(width/_padR2)×ceil(height/_padR2) 稠密分配——**"每次调用重建 O(P)
微秒级"的声称在该维度不实**：81,757 焊盘 × 400×300mm 板 × clearance 0.05 实测
_padR2=0.191 → 3.28M 槽 ≈ **26MB/次调用**（283ms 中相当部分为分配与填充）；
空焊盘 + 小 clearance 的退化域更差。

**修复**：桶边长取 max(过滤界, 板宽高/512) → 维度上限 512²（≤2MB）。完备性保持：
cell′ ≥ c 时区间论证仍闭合（候选仍为保守超集）。修复后：

- 压力用例（81k 焊盘）：283 → 251ms（分配消除，余下为 81k×候选的真实求值成本；
  对照：0.14.10 无桶格口径在该板为 O(P²)=3.3G 对、不可行）
- **密集封顶用例**（7,373 焊盘、>200 findings 触发封顶）：ref 522ms → cur 73ms
  （**7.2×**），findings **逐字节一致**（含封顶态 error 计数=200 的饱和行为）
- 180 板×多采样态差分重跑：**0 处不一致**（403k 字节）
