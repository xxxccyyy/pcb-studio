## 发现 1（实质）：0.14.9 的"一致性"声称错误——掩码场非一致场

**0.14.8 无问题**：别名化不变量（探针 C）与堆 hole 法等价（43a 锁 + 数学复核：子选择
平手取左、终止条件、最终布局逐位一致的证明逐 case 复核成立）全部站得住。

**0.14.9 文档声称过头**：当时写"h 可采纳+一致且逐点支配盲口径"。深检证明：

- **可采纳性成立**（构造论证）：每个场值 = min_k(reach_k + |k−l|·viaH)，每一项都对应
  一条放松的真实路径（平面步 mask 恰=真实可通行集、diag 计 1≤√2、过孔计 viaH≤viaCost），
  故 h ≤ 真实代价。探针 B1 的支配性 0 违反佐证。
- **一致性不成立**：盲场全层可达，argmin 层上必有平面 +1 边 → 逐层 Lipschitz + min
  论证给出一致（探针 B3 = 0 违反印证）。掩码场在"跨层掩码不对称"处失效：相邻格 t、t2
  （层 0 均 mask=1），t2 的 argmin 层是层 1（t2 层 1 mask=1、t 层 1 mask=0）——t2 的
  h 走层 1 捷径（8.5 = reach₁+viaH），t 只能走层 0（11），|11−8.5|>1。实测样本
  （seed 40 n0：t=2130 hM=11/hB=9.5，t2=2131 hM=hB=8.5）与论证吻合。
- **后果**：A* first-pop 终止 + 非一致 h ⇒ obstacleH 模式可能接受**轻度次优路径**
  （一致场下 first-pop 即最优；非一致场下最优路径可能在 goal 弹出后才被松弛到）。
  这是硬板质量偏移（fable-03 线长 +21%、icebreaker 连通 −11）的**第二机制候选**
  （第一候选：漏斗效应降低协商路径多样性）。
- **默认路径不受影响**：盲口径保持原有一致场与全部性质。
- **已修正**：引擎 `fillDistanceMap` 头注、verify-optimizations 45 系列头注、CHANGELOG
  0.14.9 三处改为如实口径（可采纳+支配 ✓；非一致 ✗ 及其后果）。

## 发现 2（口径）：修复探针插桩的两个自身 bug（记录以防误导复用）

- 首版探针 C 的 replace 把 `if(found<0) return null;` 误改为无条件 return → astar 全部
  短路，会话未真实布线（首轮 A/B 探针只覆盖初始态）——修正为仅包裹返回值后重跑，
  3930 次真实调用全部通过。
- 一致性测量初版把 h=BIG 的 mask=1 格（从目标不可达，A* 会剪枝）计入比较，产生 1e9
  量纲假违反——排除 BIG 后得到真实数字 43240/76.5。BIG 格不构成搜索边，不是缺陷。

## 发现 3（复核确认，无改动）

- 0.14.8 堆 hole 法：筛上（父>携带元素才下移）与筛下（min-child 平手取左、≥携带元素
  即停）与 swap 法逐 case 等价成立；43a 永久锁 50k 混合操作（含平手簇）背书。
- buildPassMask 的 AND 链求值序与 passable 不同（else-if/if(ok) 链）——纯 AND 谓词
  结果与求值序无关；探针 A 在 blocked/scoped/fixed/pad/viaInf/pairBand/prefL/hard 全
  分支覆盖下 0 不一致。
- prefL 分支掩码三段填充（<off、[off,off+NC)、≥off+NC）索引核对无误；未规范化的越界
  prefL（不经 normalizeDesign 直造会话）与旧 passable 同为全格拒绝，行为一致。
- gen++/ownStamp 戳位前移：gen 仅被 gVal/gStamp/closed/ownStamp 四戳数组消费，
  computeH 只写 hMap，交换无交互；掩码 hard-usage 判定依赖的正是前移后的新 gen 戳。
- bench-heuristic 直驱 fillDistanceMap（全通掩码）：跨版本场值断言有效（旧签名忽略
  第 7 参，全通掩码 ≡ 盲口径）。
- joint-reroute 存档测试断言强于 0.14.1 文档化契约 [-drcE, conn] 的发现（0.14.9
  CHANGELOG 已留档）维持原判：默认路径位级一致后测试自然通过，测试未改。

## 结论

- **0.14.8：全部声称经独立验证成立，无发现。**
- **0.14.9：默认路径（位级一致）无发现；obstacleH 模式的"一致性"声称错误已修正——
  代码行为无缺陷（可采纳、支配、剪枝正确），但 opt-in 用户应知：该模式可能接受轻度
  次优路径，与协商多样性下降共同构成硬板质量偏移的两个机制候选。**
- 后续算法轮（带多样性保持的感知 h）应同时处理：①掩码场一致性（精确 Dijkstra 场或
  传播后平面 settle，代价 +2-3ms/次调用需 A/B）②漏斗效应（逐网 h 偏置/候选走廊多样性）。

## 不应夸大的结论

- 探针覆盖 40 板 × 410 组态（每网 × hard/soft），不是全输入形式化证明。
- "第二机制候选"是基于实测一致性与质量数据的归因假设，未经受控实验分离两机制贡献。
- 0.14.8/0.14.9 的速度与质量数字均为单机单跑/有限轮次中位数，非统计显著性结论。
