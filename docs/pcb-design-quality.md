# PCB 设计质量改进（2026-11-08）

本轮改进面向软件的自动布局与设计规则检查能力，不是对某一具体 PCB 工程的改板，也不修改参考源码或已有设计文件。没有新增运行依赖。

## 1. 自动布局：正确恢复状态、保留原布局候选

退火的代价计算读取焊盘世界坐标缓存，而不直接读取元件状态。此前多重启只恢复了元件位置/旋转，没有同步恢复坐标缓存，下一次代价计算可能基于上一次尝试的残留状态。现在每次恢复都重建对应的世界坐标。

初始输入布局也作为最优候选保留，不再被货架排布无条件覆盖。一个两焊盘案例的初始连接代价为 2.0，旧版在零次退火时返回 2.5；新版保留原位置，返回 2.0。这是已复现的候选丢失修复，不意味着所有板子的最终线长都会减少。

最终重叠修复直接移动写回的焊盘；现在也会同步更新代价缓存，使返回的 `after` 对应实际写回几何。仍保留整组件旋转、封装内部节距和锚定约束。

## 2. 焊盘铜间距：设计规则与板厂规则分开

- 不同网络、具有共同铜层的焊盘按实际圆形/矩形距离检查 `design.clearance`，不再仅检查重叠。
- 例如实际铜间距 0.15 mm、要求 0.20 mm，现在会产生「焊盘间距」错误；恰好 0.20 mm 按浮点容差通过。
- 同网铜连接豁免；两个不同焊盘均未分配网络时不视为同网。
- 顶层与底层表贴焊盘之间不进行同层铜间距检查；通孔焊盘则参与它实际占有的各层。
- 板厂最小间距提醒改用同样的精确几何与层过滤，避免对角分离圆焊盘、矩形角点和顶底层焊盘的包围盒误报。
- `dfm:false` 仅禁用板厂 DFM 提醒，不禁用用户指定的铜间距规则。自动布局布线的候选评分因此也能识别这类真实设计错误。

## 3. 物理孔与板边

- 物理孔列表统一包含插件孔、布线过孔和缝合孔；插件孔按每焊盘 `holeR`，未指定时与制造导出一致，回退到全局 `viaDrill/2`。显式 `holeR:0` 不钻孔，表贴焊盘不当成通孔。
- 孔边距按实际钻孔半径计算，不再把铜盘外径当作钻孔直径。同网络不豁免物理钻孔间距，并补齐插件孔与过孔/缝合孔的组合检查。
- 例如同网两个插件孔半径均为 0.45 mm、中心距 1.00 mm，实际孔边距只有 0.10 mm。旧版漏检，现在 DRC 报「孔边距」错误，投板检查表也显示 0.10 mm / fail。
- 过孔铜盘直径 0.80 mm、钻孔直径 0.40 mm、中心距 0.65 mm 时，物理孔边距是 0.25 mm。旧版用铜外径错误报警；新版不报低于 0.20 mm 极限，但检查表仍提醒未达到 0.30 mm 建议值。
- 板边按实际铜边计算。矩形焊盘分别考虑宽高，圆形焊盘统一按直径；走线采用每网实际线宽，过孔/缝合孔按铜环外径检查。仅有焊盘、尚未布线时，检查表也会列出实际孔距和板边项目。
- 例如全局线宽 0.30 mm、电源网络线宽 1.00 mm，走线中心距板边 0.60 mm，实际铜边距是 0.10 mm。旧检查表错误显示 0.45 mm / ok；新版显示 0.10 mm / fail，并给出 DFM 板边提醒。

保留现有严重度约定：涉及插件孔的不足孔距为错误；过孔之间的工艺孔距与铜到板边的工艺限值仍为 DFM 提醒，检查表可标记 fail。`dfm:false` 会禁用这些 DFM 提醒，但不禁用涉及插件孔的物理孔距错误。DRC 与检查表共享几何口径，并不意味着所有项目的严重度名称相同。

## 验证与边界

本轮新增 **16 项回归**：6 项布局/焊盘测试覆盖设计间距临界值、层隔离、圆形/矩形对角几何、同网例外、原始布局候选、多种种子下最终代价一致性；10 项制造测试覆盖物理孔与板边边界，并核对 DRC 与投板检查表的几何口径一致。

最终在 Windows / Node v24.21.0 运行 `npm.cmd test`：**243 项检查全部通过**（80 核心、64 几何/可靠性/HTTP/搜索/设计、48 书籍规则、15 CLI、17 畸形输入、7 导出语法、12 优化验证）。三个内置示例仍 100% 布通且 DRC 无错误，CLI 自动布局布线及制造文件导出回归均通过。独立单文件应用已重建，并通过源码一致性检查。本轮未重跑真实浏览器交互测试、未测量性能变化，也未进行实物制造或外部 EDA 签核。

后续独立审计又补齐了同物理孔去重、零孔径/缺省孔径导出一致性，以及精确锚定写回，修复后完整测试为 250 项通过。上方 243 项是本轮最初验证的历史记录，不能视为所有边界已覆盖；发现、修复和未覆盖限制见 [两轮优化正确性复查](optimization-audit.md)。

更严格的规则可能让旧工程出现此前漏检的错误；这不表示旧工程已被自动修复，应在投板前重新检查并处理。

这些改进不能代替外部 EDA 的最终 DRC、板厂工艺审核和硬件验证。当前模型仍是矩形板框、圆形钻孔、轴对齐矩形/圆形焊盘；没有完整器件本体/庭院层、任意板框、槽孔或高压爬电距离求解。差分对和高速规则仍是行为级辅助与提醒，不等同于阻抗场求解或 SI/PI 签核。
