## 二、已验证教训（先实验验证再记录）

### L35 禁布区没有影响区缓冲 → 引擎修复（本轮核心）

- **现象**（n145）：三分区板的双禁布带，DRC 报 2 处「走线穿越禁布区」——走线在距禁布区边缘 **0.1mm** 的格行上平行通过，格点模型判定合法（格心在禁布外），但走线铜皮（半宽 0.2）入侵禁布区 0.1mm。
- **根因**：焊盘有 halfClr 影响区（防贴边入侵），**禁布区没有**——阻挡仅覆盖自身矩形内的格点。这是 R8 L26（圆焊盘弦缺口）的姊妹例：**障碍模型的边缘语义必须与 DRC 契约对齐**——DRC 要求线段-矩形距离 ≥ w/2，模型却允许 0。
- **修复**（engine.mjs buildModel）：禁布阻挡区外扩 **maxTrackW/2 缓冲带**——格心 ≥ maxTrackW/2 ≥ 任意网 w/2 → 铜皮不出界（DRC 同口径）；**焊盘真铜格豁免**（pad 本体落在禁布内/旁仍可达，可达性由 spec/DRC warn 负责）。外扩后的阻挡区仍是矩形，继续享受斜移防切角定理。
- **A/B**：n145 修复前 2 错 → 修复后 **0 错（complete 42/42, 9.9s）**；259 项回归全过；禁布相关历史项目复测（R6 n65 隔离带、R8 n109 保护环）零回退。
- **永久测试 18ab**：模型级（缓冲带内格阻挡/外空闲/真铜格豁免）+ 行为级（分区禁布板 0 冲突）。
- **泛化**：影响区家族现在完整——焊盘（halfClr）、圆焊盘（外接方形）、禁布区（maxTrackW/2 缓冲）、板边（0.2 固定带）四类障碍的边缘语义各自与 DRC 对齐。

### L36 协商收敛边界：n148 案例的诚实画像

- **现象**：LQFP64 双电源域（86 焊盘 45 网 + 32-pin 扇出排针）在 0.25 grid（123k 格）跑了 **12168s（3.4h）**——达成 134/134 全连通，但残留 2 处间距冲突（同一热点 (29.9, 16.1)，LQFP 左缘扇出区）。
- **对照**：n52（R5，LQFP100+TSOP44，166p）2.1h 收敛；n130（R9，BTB 60×2）15.6min 收敛；n91（R8）35min 收敛。n148 的 45 网 × 高扇出 × 双域构成十轮最重协商。
- **定性**：非 bug——协商在历史最优保留（L2）下不退步，但热点处的多网竞争未能在预算内压到零。**连通 100% + 2 处冲突 = 交付前 DRC 拦截的典型案例**（N10 家族）。
- **操作规程**：此类板先看 advise 的热点定位；补救顺序 = rounds 提升 → 扇出排针锚定到板边（缩短走廊）→ 板幅加大。3.4h 的墙钟成本也是诚实边界的一部分（性能 roadmap 见 R9 L32）。

### L37 宽走线的节距封死效应（n146 设计规避，规则化确认）

- **推导**：nets[].w=1.2 → maxTrackW=1.2 → minimumRoutingGrid=1.4 → halfClr=0.8。5mm 端子（盘 r1.1）影响半径 1.1+0.8=1.9，相邻 5mm > 3.8 ✓ 可布；**若混入 2.54 排针（r0.85）：0.85+0.8=1.65×2=3.3 > 2.54 → 排针封死**。
- **验证**：n146 全 5mm 端子 + w1.2 汇流 → 28/28 全绿（2s）。与 R5 L1「细间距板禁宽线」互为逆定理：**maxTrackW 是全板量——宽线要求全板节距 ≥ 2×(padR + maxTrackW/2 + clearance)**。已写入手册决策表。

### L38 null-net 焊盘即"结构件"原语（n147）

- 工装孔（null-net 镀孔近似 NPTH）、基准点（null-net 光点）用 `netId: null` 焊盘表达——布线器视为固定障碍、DRC 不报未连通、导出含焊盘不含网。24/24 全绿。
- **边界声明**：真 NPTH（非金属化孔）无法表达——工具所有 holeR 均按镀孔处理（钻孔文件按孔径出刀，镀层假设需板厂确认）。roadmap：pad 增加 `npth: true` 标记（钻孔出刀但铜层排除）。
